## 目標體驗(本輪釐清)
- 「我希望達成的感覺是"玩家透過某種方式對表演過程做控場",所以不一定是節目表」
- 「我覺得不錯的體驗在於,玩家雖然沒有直接在場上控場,但仍有其他方式在表演過程中控場」
- 下一輪三款要用**三種不同的方式**讓玩家在表演過程中間接控場; 節目表是其中一種可行解, 但不必三款都是節目表。「除了節目表以外,你也可以發想看看有沒有其他達到一樣效果的設計」

## 使用者指定的改動(下一輪每款都必須有)
1. **寬畫面**: 「我不太喜歡這種直式的畫面,我比較喜歡寬畫面」 → 改橫向寬畫面
2. **怪物多樣性, 各款不同**: 「我希望接下來你也可以針對怪物去各產出不同的設計,每一款遊戲都固定是水母,火蜥蜴,雷鳥那些,感覺是可以再針對怪物的多樣性去挖掘」 → 三款的魔物陣容與魔物設計各自不同, 不再沿用水母 / 火蜥蜴 / 雷鳥 / 刺蝟 / 石像鬼 / 幽靈這組
3. **初期戰鬥降低難度**: 「初期戰鬥太困難了,很容易被水母打死」
4. deepen-1 回饋列的使用者指定改動(方向鍵 + Z/X、武器、捕捉流程、失控標記、布置階段、3 座地下城、7 天)照舊保留

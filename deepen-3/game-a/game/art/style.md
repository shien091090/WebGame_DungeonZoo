**已知張力(驗收用最差組合)**:
- 規則紅 `#ff2f5a`(348°)與火蜥蜴 `#e8432e`(7°)只差 19°、灰階同為 114。分法走類別層: 規則紅只出現在線與記號, 火蜥蜴紅只在本體與火圈面; 失控外圈是**鋸齒線 + 半透明面**, 紅區下限線中間夾一條白細芯。驗收: 「失控中的火蜥蜴」與「怒氣在紅區的火蜥蜴」那一幀。
- 升怒 `ignite` 落在火蜥蜴(7°)與雷鳥(52°)之間, 降怒 `douse` 與水母同色名。主通道是**方向**(升怒 = 三支往上竄的圓頭箭頭; 降怒 = 三顆往下滴的水滴), 一律帶深色外描, 顏色只是第二通道。驗收: 「被點燃的雷鳥」「被澆熄的水母」。

## 3. 形狀語言

生物 = 圓潤剪影 + 深色外描 + 地上影子(立體); 地面與地板 = 平塗、無外描、無影子、低明度; 危險 = 鋸齒 / 尖角; 功能記號一律用圓頭箭頭(彈跳板不用朝上的尖)。

## 4. 理念落實

- **P0 辨識度先於好看**: 六種魔物同時用色相 + 剪影區分(蜥蜴長身帶尾、水母圓頂觸手、雷鳥圓身帶翅冠、刺蝟背刺半圓、石像鬼方身雙角、幽靈波浪下擺); 四種地板同時用底色 + 圖案區分(辣椒 / 冰裂雪花 / 同心圈 / 木板聚光星)。
- **P1 視覺權重跟著決策迫切度走**: 表演場 12 格地板會鋪滿整片場地, 地板一律低明度平塗、圖案半透明, 魔物與怒氣條永遠最亮; 地下城的技能預警(會打到你)比武器特效(你打出去的)更飽和。
- **P2 規則上存在的東西畫面上就存在**: 怒氣條上同時標「50 表演門檻」白刻度與「紅區下限」紅線; 失控標記畫 5 格(第 5 格空框是紅邊 = 滿了就失控), 最後一顆實心標記上畫「離自動 −1 還多久」的白色扇形; 套索畫出繞圈進度、時限與繩子張力; 範圍技能的虛線外框就是判定外緣。
- **P3 一個意義一種長相**: 玩家色 `#ff4fd8` 只代表「你這邊的東西」; 白粗框只代表「游標 / 選中」; 規則紅只代表「紅區 / 失控」; 預警一律「虛線外框 + 由中心長大的填色, 長滿 = 生效」。說明頁所有物件都直接呼叫遊戲內函式。
- **P4 關鍵區分走兩條通道**: 升怒 / 降怒 = 方向 + 顏色; 敵方投射物 / 被打回的投射物 = 種類色實心 + 深外描 vs 白芯 + 玩家色粗外框 + 玩家色尾巴; 已開放 / 未開放卡 = 「已開放」綠標 vs 鎖頭 + 小景蓋暗。
- **P7 每個元素都要掙得版面**: 失控標記列只在 marks > 0 時出現; 地板不畫字(圖案即種類); 魔物身上不重寫怒氣數字(條已給)。
- **P9 以最混亂的那一刻驗收**: 所有魔物、技能與飄字都帶深色外描, 疊在任何地板上都讀得到。
- **P13 事件要排隊**: 魔物周圍分帶 — 框頂 = 怒氣條、其下 = 失控標記列、身上 = 升 / 降怒回饋、框底右 = Lv; 飄字由 RD 依序丟, 美術只負責上浮淡出(1 秒內最後 40% 淡出)。
- **P15 回饋強度與份量成正比**: 飄字分級 — 一般金幣 24px 黑描 < 紅區金幣 30px 紅描 = 連鎖 30px 玩家色描; 地板觸發只在自己那一格; 震地圈是唯一跨格的地面演出。
- **P17 圖形與數字分工**: HUD 計時條給比例、條上數字給秒數; 失控標記給「幾個」, 扇形給「最後一顆還多久消」; X 冷卻用鍵帽由上往下的暗幕(剩餘比例)。
- **P18 重要資訊不能只閃一下**: 收服 / 等級 +1 飄字之後, 等級常駐在陣容卡、表演魔物「Lv N」與怒氣條紅區寬度上。
- **P19 資訊貼著物件**: 怒氣條、失控標記、Lv 都在魔物自己的框內; 「準備捕捉」字與環在魔物身上; 套索進度環圍在被套的魔物身上。
- **P21 示意圖選分岔的例子**: 說明第 4 頁畫「4 個標記(還沒失控)→ 衝圍欄(標記消失)」, 不畫「5 個標記」; 第 2 頁準備捕捉沒有星星、套索中才有。

### 判讀約定(Hazard / SlamFx, 請 RD 照這個算判定)

- 火圈、落雷: `radius` = 實心圓**外緣**; 虛線框畫在外緣內側, 畫面邊界 = 判定邊界。
- 震波: `radius` = 環**中線**, 判定帶 = [radius − 15, radius + 15]; 畫的灰褐帶就是這一段(照 interface notes)。
- 投射物: 圓的半徑 = `radius`(判定半徑); 尾巴只往後拖、不往前長。
- 震地圈: `radius` = 外緣 110, 外緣虛線一直在; 動態波不會超出。

# 玩具球亂鬥秀(玩具球: 魔物踢、技能打, 球滾到誰就作用在誰)

## 概述
全程只用方向鍵 + Z、X。白天進地下城: 方向鍵走位, Z 是武器普攻、X 是武器專屬技能(棍棒 / 劍 / 長槍 / 長鞭, 商店購買切換); 把魔物打到殘血後站到牠身上, 跑完「準備捕捉」圓圈就套上套索, 被套的魔物暈眩不能出招, 繞牠一圈收服——也可以選擇直接打死。晚上表演前是「布置階段」: 選要上場的魔物、買玩具球, 把魔物和球擺在表演場的格子上; 開演後玩家不能干涉。表演場上每種魔物都會主動去找別隻(追、繞、衝、滾、瞬移), 身體相撞會互相挑釁, 技能互相點燃 / 澆熄, 被點燃進紅區的魔物會立刻接著表演。怒氣在紅區表演金幣加倍; 怒氣滿了不會馬上失控, 而是開始累積失控標記, 滿 5 個才失控。
**本款的新機制——玩具球**: 機關是**會滾動的球**。魔物走過去碰到就把球踢出去, 魔物的技能打到球也會把球轟出去; 球在場上滾、撞邊界反彈, **滾到哪隻魔物身上就作用在那一隻**: 火辣球讓牠生氣、冰涼球讓牠冷靜、鈴鐺球讓牠立刻表演、毛線球滾動時附近的魔物都會追著它跑。玩家的布置是在「擺球」: 想好球會被誰踢、被哪一招轟、滾去撞誰。7 天後依名聲評星。
驗證假設: H01、H04、H05、H06、H28、H50、H114~H120、H133~H135、H140、H141。

## 核心循環
挑一座地下城 → 用手上武器閃招、看清每種魔物的技能範圍與動法, 把想要的打到殘血, 站上去套索、繞一圈收服(不要的就打死換金幣)→ 新種加入陣容, 同種提高等級(紅區變寬 + 馴獸師加成), 收服數累積解鎖新地下城 → 布置階段挑魔物、買球: 把火辣球擺在火蜥蜴火圈會轟到的地方、冰涼球擺在容易爆的那隻會經過的路上 → 開演看球在場上被踢來轟去、一路撞出連鎖, 賺金幣與名聲 → 商店買武器與強化 → 隔天。

## 規則

### 流程
1. 開始畫面顯示說明頁(共 5 頁), 按 Z 翻頁, 最後一頁按 Z 進入第 1 天的地下城選擇
2. 每天依序: 地下城選擇 → 地下城(60 秒)→ 布置階段 → 表演場(45 秒)→ 商店; 第 7 天表演結束後不進商店, 直接進結算
3. 開局: 金幣 30、名聲 0、武器棍棒(只擁有棍棒)、陣容火蜥蜴與水母(都是等級 0、收服數 0)
4. 結算後按 Z 重來, 回到第 1 天地下城選擇(不再顯示說明頁), 所有數值重置

### 地下城選擇
5. 畫面列 3 張地下城卡(由上到下: 濕熱洞窟、雷鳴崖、古代遺跡), ↑↓ 移動選擇框, 按 Z:

   - 未開放且條件達成 → 扣金幣、開放(卡片變成已開放), 不進入; 再按一次 Z 才進入
   - 未開放且條件未達成 → 不反應
6. 卡片顯示: 名稱、住的兩種魔物、未開放時顯示條件與進度(例「金幣 60 + 收服水母 1/2」)

### 地下城(即時, 60 秒)
15. 方向鍵移動馴獸師, 可斜走(速度不變); 放開就停。面向 = 最後一次移動的方向(8 方向)。撞牆 / 石柱擋住(圓形判定半徑 18, 可沿牆滑動); 站在水上移速減半(魔物不受地形影響); 碰到熔岩算被打中一次
16. 地下城裡習性的對象是馴獸師。馴獸師距離 ≥ 320 時, 火蜥蜴、水母、石像鬼改在房間內隨機走動(火蜥蜴、水母 40 像素/秒, 石像鬼 25 像素/秒, 每 2~3 秒換方向); 雷鳥、刺蝟、幽靈照習性(本來就不看對象); 幽靈瞬移的落點是自己房間內、離馴獸師 ≥ 120 的隨機地板
17. 馴獸師距離 < 320 時, 魔物依間隔施放技能, 瞄準對象是馴獸師(水彈、落雷、鬼火); 施放預警期間照常移動
18. 每個巢穴開局各生 1 隻該種魔物; 魔物被收服或打倒後, 該巢穴 8 秒後再生 1 隻
19. 武器(見武器表): Z 普攻、X 武器技; 各自有冷卻。攻擊判定朝面向
20. 魔物被攻擊命中: 扣血(武器傷害 + 攻擊力強化等級), 受擊閃白 0.1 秒。被套索套住的魔物不受傷害
21. 魔物血量 ≤ 最大值 30%: 「殘血」——身上冒虛弱記號, 移動速度 ×0.5、施放間隔 ×1.5
22. 血量歸零: 打倒, 魔物消失, 得該種打倒金幣
23. 被技能或熔岩打中(突進無敵中除外): 扣 1 顆心, 之後無敵 1 秒(閃爍)
24. 心歸零或 60 秒到: 地下城結束, 進布置階段; 已收服的保留
25. 每天進地下城時: 心補滿、捕獸繩補到上限、所有冷卻歸零, 馴獸師在起點、面向上

### 捕捉
29. 準備捕捉: 馴獸師中心與一隻殘血魔物中心距離 ≤ 40、捕獸繩 > 0、目前沒有套索時, 那隻魔物身上出現「準備捕捉」字樣與圓圈進度條, 在 0.8 秒內填滿(水母加成會縮短, 最低 0.35 秒); 離開 40 範圍或被打中就歸零。同時有多隻符合時取最近的一隻。準備期間魔物照常移動與施放
30. 圓圈填滿 → 套上套索: 被套的魔物「暈眩」——停止移動、不施放技能(預警中的取消)、不受傷害; 馴獸師與牠之間畫一條繩
31. 繞圈進度: 每幀計算「馴獸師相對魔物的角度」變化量(取 −180°~180°), 累加成有正負號的總和; 進度 = |總和| / 360°。順時針、逆時針都算, 中途反方向會倒扣
32. 進度達 1: 收服——繩 −1, 魔物離場, 飄字「收服!」, 該種收服數 +1, 該巢穴 8 秒後再生
33. 套索斷掉(魔物維持殘血、解除暈眩; 要重新準備捕捉, 進度從 0 開始)的情況:
    - 套索計時達時限(5 秒, 幽靈加成會延長)
    - 馴獸師與魔物距離 > 220
    - 馴獸師被其他魔物的技能或熔岩打中(長槍突進無敵中不算)
34. 套索中可以移動與使用 Z、X 攻擊其他魔物
35. 收服的結果: 陣容沒有此種 → 加入陣容, 等級 0; 已有 → 該種等級 +1(最多 3), 飄字「等級 +1」; 已是 3 級 → 金幣 +20, 飄字「+20」
36. 等級的兩個效果, 收服當下立刻生效:
    - 紅區變寬: 該種在表演場的紅區下限 = 80 − 5 × 等級(80 / 75 / 70 / 65)
    - 馴獸師加成(地下城用, 每級疊加):
      | 種類 | 加成 | 每級 |
      |---|---|---|
      | 火蜥蜴 | 烈火 | Z 普攻範圍(半徑或長度)+10% |
      | 水母 | 柔水 | 準備捕捉時間 −0.15 秒 |
      | 雷鳥 | 迅雷 | 移速 +25 |
      | 刺蝟 | 尖刺 | X 武器技冷卻 −15% |
      | 石像鬼 | 石膚 | 心 +1 |
      | 幽靈 | 幽影 | 套索時限 +1 秒 |

### 布置階段
37. 第 1 步「選上場」: 陣容每種一張卡(種類、等級), ↑↓←→ 移動選擇框, 按 Z 切換選 / 不選(最多 4 種上場); 選擇框移到「下一步」按 Z 進第 2 步(至少選 1 種才反應)
38. 第 2 步「擺放」: 畫面是表演場, 場地上疊 3 欄 × 4 列共 12 個格子; ↑↓←→ 移動格子游標, 從最下一列再按 ↓ 移到「開演」按鈕(按 ↑ 回格子)

42. 球被推出去的三種方式(推出去後速度方向依下列, 上一個推動者、帶的段數同時更新):
    - **踢**: 魔物中心與球中心距離 ≤ 64, 且球不在滾動中 → 球以 320 像素/秒、方向 = 魔物 → 球 滾出; 推動者 = 這隻, 段數 = 0
    - **範圍技能轟**: 火圈生效時球在半徑 120 內、落雷落下時球在半徑 70 內、震波環(中線 ± 15)掃過球 → 球以 380 像素/秒、方向 = 技能中心 → 球 滾出(球剛好在中心就隨機方向); 推動者 = 施放者, 段數 = 那次表演的段數。同一次施放對同一顆球只算一次
    - **投射物打中**: 水彈、尖刺、鬼火碰到球(距離 ≤ 24 + 投射物判定半徑)→ 投射物消失, 球以 380 像素/秒、沿投射物飛行方向滾出; 推動者 = 施放者, 段數 = 那次表演的段數
43. 撞中: 滾動中的球碰到(中心距離 ≤ 64)一隻魔物, 且這隻不是上一個推動者(或被牠推出已過 0.5 秒)→ 依球種作用在這隻(第 40 條), 球沿碰撞法線反彈、速度 ×0.8; 推動者改成這隻, 段數不變。同一顆球對同一隻魔物 1 秒內只作用一次(期間碰到也只反彈)
44. 失控中(含衝欄)的魔物不踢球、不被球撞; 球不會被破壞、不是技能的瞄準對象

### 表演場(即時, 45 秒, 玩家不能操作)
45. 場地與觀眾席: 上下兩側觀眾席, 各 6 段圍欄與 6 名觀眾(版面見數值表)

## 範圍邊界
- 只做這 7 天、三張固定地圖, 不做難度曲線、存檔、音效
- 陣容每種最多一隻(同種再收服變等級), 不做出售、放生
- 球只在布置階段擺, 表演中不能有任何操作; 不做馴獸師下場、吹哨、揮鞭激怒、大招、全場連擊計量
- 不做固定不動的機關、戰鼓 / 噴泉 / 肉塊或任何定時脈衝型機關
- 球與球不互撞、不做旋轉與摩擦以外的物理
- 不做門票與觀眾人數, 收益只來自表演與打倒魔物
- 不支援滑鼠

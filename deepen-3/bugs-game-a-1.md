# Bug 回報 deepen-3 game-a 第 1 次

## 現象(使用者原話)
「彈跳地板跳到怪身上之後,兩隻怪疊在一起,怒氣條不知道為什麼一直升高,但升高過門檻卻沒有觸發表演」

## 重現
1. 表演場鋪彈跳板, 讓魔物走上去
2. 被彈的魔物落在另一隻魔物身上(彈跳板的目標就是最近那隻的位置)
3. 兩隻魔物之後一直疊在一起不分開
4. 怒氣條持續上升, 超過表演門檻(怒氣 50)後仍不表演

## 規格對照(推論, 供修正參考)
- 第 50 條: 怒氣 ≥ 50 應該定時表演(4 秒 → 1.5 秒間隔)。超過門檻卻不表演, 違反規格
- 第 55 條相撞挑釁: 中心距離 ≤ 70 時同一對每 2 秒各 +8。兩隻疊著不分開就會一直觸發, 推測這就是怒氣一直升高的來源; 規格沒寫相撞後要分開, 疊在一起的魔物要能自然分開(或落點避開正上方), 不然會卡在不斷挑釁的狀態
- 可疑方向: 落地後的狀態(彈飛中暫停的施放 / 表演計時)沒有恢復; 或疊在一起時移動目標(最近的魔物)就是彼此、距離 0 導致移動與表演邏輯卡住

## 期望
- 彈跳板落地後魔物照常恢復習性、計時與表演
- 兩隻魔物不會長時間疊在一起
- 怒氣 ≥ 50 一定會照第 50 條定時表演

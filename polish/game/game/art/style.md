# 來馬戲團看一點大場面(打磨版第 5 輪)— 美術規格(style.md)

> RD 只讀這份。`index.html` 必須宣告 `<meta charset="utf-8">`(art.js 內有中文字串)。
> 函式名、參數、state 欄位全部照 `interface.json`, 一個不多一個不少(49 個函式)。所有函式自己 save / restore; 傳入表外值不會拋錯, 會畫成下表寫的「預設」。
> 沿用打磨第 4 輪的色票、形狀語言與物件畫法。本輪只改規格「本輪改動」表牽涉到美術的部分:
> **換武器視窗(新 drawWeaponPicker)**、**飛出去的捕捉繩(新 drawRopeThrow)**、**倒下暗角與原因框(新 drawDownFx)**、**drawCaptureRing 移除**;
> 馴獸師手上可拿捕捉繩 + 倒下動畫;野生魔物前搖(閃亮 +「!」+ 瞄準箭頭)與掙脫抖動;直線火柴(不旋轉、不折返);致命一擊高亮(Hazard / Blast 的 killer);
> 回血果子(心色 + 綠十字, 拿掉被吃動畫);地下城結算的倒下原因;HUD 繩列只在拿捕捉繩時畫;飄字新種類 escape / hint;
> **全遊戲按鍵提示改畫鍵帽**(共用的「一行含鍵帽的字」工具);教學重新編號 1~23;用詞「捕獸繩」→「捕捉繩」。

- **回血果子(心色)vs 標靶鸚鵡(#ec4f9c)**: 果子只有 17px 直徑、帶綠葉與綠十字, 地上還有綠色脈動光圈;鸚鵡 72px 剪影。尺寸 + 綠色記號兩條通道。

## 3. 形狀語言

圓潤扁平 + 深色描邊。**尖角 / 鋸齒只給危險**(傷害地形、爆炸桶火焰記號、失控鋸齒、失控橫幅、心列扣血的三角碎片、**前搖的瞄準箭頭**);其他記號一律圓頭(草叢圓葉、出口箭頭、沸騰觀眾與前搖「!」的驚嘆號都是圓頭)。**虛線框 + 由內長大的填色 = 「快生效了」**。**金色實線框 = 游標**,**金色虛線 = 你打得到的場景物**。**白色外擴環 = 表演**(地下城的倒下衝擊白環只在倒下 0.3 秒內、全場定格時出現)。**圖示下方一個白點 = 「1 隻」**。**畫面邊緣的紅色脈動 = 沸騰**。**按鍵一律是鍵帽**: 淺色圓角方塊 + 下緣厚邊 + 深色字 / 箭頭, 像實體鍵;全遊戲只有這一種按鍵長相(HUD、泡泡、結算、視窗、商店、開始畫面)。教學泡泡和全畫面面板明暗相反(淺紙底 + 深字), 只給教學用。

## 4. 理念落實

- P0 辨識度先於好看: 魔物種類靠剪影,狀態靠外形分,顏色當第二通道。本輪的捕捉繩用「一捲繩 + 垂下的小圈」剪影, 和三把武器(長條)一眼分開;回血果子用「心色 + 綠十字」直接說「吃了回心」。
- P1 視覺權重跟著決策迫切度走: **前搖是地下城裡最該閃避的一刻, 「!」用全畫面最強的危險紅實心牌**(比血條、虛弱記號都顯眼), 瞄準箭頭只在前搖 0.5~0.7 秒內出現;倒下定格時唯一在動的是致命那一下的脈動外圈;頭上心列平時 40% 不透明;繩列只在手上是捕捉繩時出現。
- P2 規則上存在的東西,畫面上就要存在: 掙脫(不扣繩)有自己的抖動 + 彈開弧 + 飄字, 和「套上」分得開;捕捉繩用完的卡畫暗 +「用完了」;果樹掉過果子就變成沒果子的樣子(只剩綠芽, 金虛線消失 = 打了也沒用);倒下的原因在定格框、原因框、結算三處都在。
- P3 一個意義一種長相: **按鍵 = 鍵帽**, 從 HUD 到教學泡泡到換武器卡同一個長相(教學大鍵帽只是放大 + 按過變綠);**〔原因〕標籤 = 危險紅圓角標籤**, 倒下原因框與地下城結算同一個長相(說明面板的〔效果〕標籤則依效果色, 同一個「〔 〕= 標籤」語法);**捕捉繩 = 繩色(rope)**, 飛出去的繩、套索、HUD 武器框、視窗卡、手上同色;回血 = 綠(心列光點、果子十字、地上果子光圈)。
- P4 關鍵區分走兩條通道: 前搖 = 頭上紅牌(形狀)+ 身體閃亮(亮度)+ 箭頭(方向);掙脫 vs 套上 = 抖動 + 彈開弧 + 黃字「掙脫了!」 vs 繩圈套在身上 + 繞圈進度環;換武器卡的選中 vs 使用中 = 金框 + 放大 vs 萊姆框 + 頂端小標。
- P7 每個元素都要掙得版面: 繩列只在拿捕捉繩時畫(拿武器時用不到);捕捉繩與棍棒沒有 X 技, HUD 整個 X 鍵帽不畫;前搖箭頭冰柱企鵝不畫(射線預警本身就指方向)。
- P9 以最混亂的那一刻驗收: 前搖「!」放在血條之上、本體框外(y − 64), 二十隻擠在一起時也不會壓在別隻身上的血條;掙脫特效全在本體框內。
- P12 遊戲區優先於 UI: 倒下原因框在馴獸師頭上(定格中沒有決策, 規格 P12 邊界內);換武器視窗是暫停中的全畫面選擇介面。
- P13 事件要排隊: 倒下 0~0.3 秒只畫衝擊白環, 0.3 秒後才壓暗、才彈原因框——一段一件事。
- P15 回饋強度和份量成正比: 掙脫(小, 本體框內抖)< 收服(飄字放大)< 爆炸桶 < 倒下(全畫面壓暗)< 失控。
- P16 每個狀態都有外觀, 包括過渡: 繩子飛出(張開繩圈 + 速度短線)/ 收回(繩圈收成小結)/ 套上(套索);馴獸師倒下分定格閃白 → 往後倒 → 躺平三段;前搖「!」前 15% 由小彈大。
- P17 進度的圖形與數字分工: 沿用(熱度表數字 + 刻度、表演時鐘扇形 + 秒數, 見上一版)。
- P18 重要資訊不能只存在一瞬間: 倒下原因在倒下動畫閃過後, 地下城結算標題下方再寫一次;收服頭像常駐 HUD 收服列。
- P19 資訊貼著物件: 前搖「!」與箭頭長在魔物身上;原因框在馴獸師頭上;心列在頭上;教學泡泡尾巴指著目標(第 3 階段指捕捉繩卡下緣、第 7 階段附註指繩列正中央);**擋下提示(hint)停在被擋的那個按鈕 / 面板上方, 不往上飄走**。
- P21 示意圖選對錯理解會分岔的例子: 本輪沒有說明頁。見習過場三步圖解沿用, 第一步文字改「選 2 隻上台」。

- Hazard 投射物 radius = 判定半徑(外緣);icebeam 從施放者中心起算, width 以中線左右各半。爆炸桶 / 爆炸 radius = 外緣。

- WildMonster: stunLeft > 0 或 lassoed 都畫暈眩;**暈眩中就算 windup 為 true 也不畫前搖**(規格: 前搖中被擊暈 / 套住即取消)。**aim 只有數字才畫箭頭**(null → 不畫);冰柱企鵝一律不畫箭頭。**掙脫只看 escapeT < escapeDur**;閒置請傳 escapeT = escapeDur(沒傳時當閒置)。
- **Tamer down 只認 true**;downDur 沒傳或 ≤ 0 → 1.5。down 中不讀 blink / dashing。
- **WeaponPicker**: options 照卡片由左到右;index 超出範圍 → 沒有卡被選中(不拋錯);disabled 只畫暗, 不擋選擇(擋選擇是 RD 的事)。
- **RopeThrow**: phase 只認 back, 其他當 out;out 時 t/dur 不影響繩圈大小(一直張開), back 時繩圈依 t/dur 收起。
- **DownFx**: 畫在地下城物件之上、drawHud 之下;cause 空字串時只畫暗角。
- HeartBar: delta 是正整數;hurt 時 hearts 已是扣完的值, heal 時 hearts 已是補完的值。
- Exit: armed 只認 true。ExitPrompt: choice 只認 0 = 離開。
- HeatMeter: 段名與顏色只看 tier。ShowClock: 美術不存狀態。Visitor: 動作只看 t 與 i。
- Hud caught: 依收服順序;收服列的「彈一下」靠美術比對上一幀長度。**Hud 繩列只看 weapon === 'rope'**。
- **所有字串裡的鍵帽標記照 §5.2**;RD 不用自己畫鍵帽。
- 動畫小細節(齒輪刃旋轉、暈眩星、虛線流動、無敵閃爍、出口箭頭浮動、結算「按 [Z]」閃爍、收服頭像彈跳、**前搖閃爍、致命高亮脈動、倒下後頭上轉星、地上果子光圈**)用 `performance.now()`;開始畫面、見習過場、觀眾、熱度表、沸騰警示由傳入的 t 驅動。
- 時長常數(一次性特效由傳入的 t/dur 決定): 節目浮字 0.8、飄字 1(unlock、**hint 1.5**)、反應 0.5、表演 0.5、冰柱預警 0.7 / 生效 0.2、引信 1.0、爆炸 0.3、失控收場 2.5、觀眾逃走 1.5、教學出現 0.25 / 完成 0.6、日曆翻頁 0.6、心列特效 2.0、出口詢問框彈出 0.2、**換武器視窗彈出 0.15(規格)**、**倒下 1.5(0.3 定格 + 1.2 倒下;原因框 0.3~0.5 彈出)**、**前搖 0.6 / 0.5 / 0.7(讀 windupT/windupDur)**、**掙脫 0.4(讀 escapeT/escapeDur)**、**繩子飛出 ≤ 0.31 / 收回 0.15(讀 t/dur)**、熱度換段彈跳 0.4、沸騰脈動 0.8、收服頭像彈跳 0.3、表演時鐘跳一下 0.15、最高標記閃爍 0.5。

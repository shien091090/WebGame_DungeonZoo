## 概述
橫向寬畫面(1280×720), 全程只用方向鍵 + Z、X。一共 **7 天**, 每天開始自己選要去哪: **地下城**(抓怪)、**表演**(賺觀眾滿意度 → 金幣與名聲)或**商店**(不花時間)。
地下城: 一張比畫面大的捲動地圖, 分成 6 個房間, 每座有兩種互動物件和一個出口; 方向鍵走位, Z 是武器普攻、X 是武器專屬技能(劍 / 長槍; 棍棒沒有); 只有 3 顆心; 把魔物打到殘血後站到牠身上, 跑完「準備捕捉」圓圈就套上套索, 被套的魔物暈眩不能出招, 繞牠一圈收服——也可以選擇直接打死。抓到的魔物一隻隻收進**怪物庫**, 表演最多上台 **20 隻**, 同種要放幾隻都行。
表演: 魔物在場上各自隨機亂走, 一律用遠距離技能表演, 打中別隻會惹牠生氣、讓牠冷靜或造成特殊效果(凍住、標靶、變走), 場面像彈幕大亂鬥。每次表演加**觀眾滿意度**, 生氣時表演加倍、連鎖加成; 全場平均怒氣顯示成**熱度**, 觀眾跟著熱度安靜 / 鼓掌 / 歡呼 / 沸騰; 怒氣滿了開始累積失控標記, 滿 5 個就失控——**全場觀眾逃走、表演立刻結束**。收場時觀眾滿意度換成金幣, 同時加進名聲。表演中玩家不操作, 靠事先排好的 **4 列暗號節目單**控場: 每列 = 一塊看全場狀態的暗號牌 + 一個節目, 全場符合目前這列的暗號就演這列的節目、換下一列, 依序循環。
本款魔物陣容: 鈴蘭精、火柴猴、齒輪甲蟲、標靶鸚鵡、冰柱企鵝、戲法狸。第 7 天結束後依總名聲評星。
驗證假設: H01、H04~H06、H50、H114~H117、H148、H168、H170~H174、H176、H177、H183~H188、H193、H200~H211。

## 用詞
玩家看得到的文字一律用左欄; 規格與程式也照這個稱呼。
| 用詞 | 意思 |
|---|---|
| 生氣 | 怒氣 ≥ 生氣門檻 80(`angryLow`, 固定 80)。有沒有失控標記都叫生氣 |
| 觀眾滿意度 | 一場表演中累積的分數; 收場時換成金幣、並加進名聲 |
| 名聲 | 跨天累計(總名聲), 決定地下城開放、商店上架與評星 |
| 熱度 | 表演中場上魔物怒氣的平均(0~100%), 只用來顯示, 不影響滿意度 |
| 上台 | 布置第 1 步選要參加表演的魔物 |
| 惹生氣 / 冷靜 | 效果分類; 程式內仍叫點燃型 / 澆熄型 |

## 核心循環
見習日(教學地下城 → 過場 → 教學表演)→ 第 1~7 天每天: 日曆過場 → 今天去哪? → 地下城: 挑一座、探索房間、利用互動物件、把想要的魔物打殘套索繞圈收服, 抓夠了可以走出口提早收工 → 收進怪物庫 → 過一天 / 表演: 選上台、排暗號節目單 → 開演看大亂鬥, 盯著熱度, 暗號一個個成立、節目接連發動, 別讓任何一隻失控 → 觀眾滿意度換金幣並加進名聲 → 過一天 / 商店: 買武器、強化、新暗號與節目 → 回到今天去哪(不過天)。名聲 + 收服指定魔物解鎖新地下城。

## 新手教學
提示是一個貼著目標物件的對話泡泡(文字一句 + 按鍵圖示), 泡泡尾巴指向目標。一次只顯示一個**主階段**; 主階段依「出現時機」第一次成立時出現, 做到「完成條件」就播完成特效(0.6 秒)後消失, **已完成的階段不再出現, 重來(總結算後按 Z)也不重置**(記在本次開啟網頁的記憶裡)。同時有兩個主階段的出現時機成立時, 表中編號小的先, 大的等前一個完成後才出現(條件到時已不成立的照樣排隊, 輪到時再看一次條件, 不成立就等下次成立)。標「附註」的階段(第 6 階段)不佔主階段的位置, 和主階段同時顯示。表演中玩家沒有操作, 表演中的階段以場上事件或顯示時間當完成條件。

**地下城的教學只在見習草地與鏡湖出現**; 齒輪鐘塔、雪境的爆炸桶、裂牆、傳送陣、回復泉不教, 讓玩家自己嘗試。武器技也不另教(HUD 右側按鍵提示已寫出「X 擊暈 / X 突進」)。

### 地下城的互動物件
17. 草叢(`G`, 鏡湖): 可以走。馴獸師中心所在的格是草叢 →「躲藏」: 魔物把他當成距離 ≥ 300(不瞄準、不對他施放, 已在預警中的照常落下; 移動改成隨機)。投射物照樣打得到他。走出草叢的瞬間算重新進入魔物的 300 範圍(第一次施放等一個完整間隔)。HUD 訊息改「躲藏中」
18. 誘餌果樹(`Y`, 鏡湖): 視同牆。每棵開局結 1 顆果子。被馴獸師的攻擊範圍蓋到樹格中心且樹上有果子 → 果子掉在樹下方那格中心, 樹 15 秒後重新結果
    - 果子掉落時, 同一房間裡的魔物(被套住、暈眩中的除外)不照自己的模式, 以 80 像素/秒走向果子; 離果子 ≤ 30 就停下來吃。走過去與吃的期間不施放技能(預警中的取消)
    - 第一隻開始吃之後 3 秒, 果子吃完消失, 所有魔物恢復原本的行動。馴獸師碰到果子沒有效果
19. 爆炸桶(`K`, 齒輪鐘塔): 擋路(視同半徑 22 的圓形障礙, 馴獸師與投射物都過不去)。被馴獸師的攻擊範圍蓋到桶中心, 或被魔物任何技能打到(投射物碰到、範圍蓋到桶中心)→ 點燃, 0.6 秒後爆炸: 以桶中心為圓心半徑 130(外緣)內的野生魔物各受 4 傷害(被套住的不受傷; 非殘血的照第 39 條保底), 馴獸師在範圍內(馴獸師圓與範圍重疊)扣 1 顆心(無敵中不扣); 範圍蓋到的裂牆格中心 → 裂痕 +1; 範圍內的其他爆炸桶也會被點燃(連環爆)。**爆炸後桶消失, 這趟地下城不再出現**(不再擋路, 原位變普通地板; 下次進地下城才恢復)。被炸死的魔物也算打倒、給金幣

## 勝負與結束
- 沒有失敗結局; 第 7 天的行動結束後進總結算, 以總名聲換評價星數
- 單場的「失敗」: 地下城心歸零(提早結束)、表演失控(提早結束、觀眾滿意度停在失控那刻)
- 總結算按 Z 重來

## 埋點
每局(開始畫面按 Z 起到總結算)記錄事件, 進總結算的瞬間自動下載 JSON, 檔名 `gamelog-WebGame_DungeonZoo-<YYYYMMDD-HHMMSS>.json`(時間 = 下載當下的本機時間)。用 Blob + `<a download>` 下載, 不用任何外部服務。
- **沒玩完的局**: 每記一筆事件就把整份紀錄寫進瀏覽器 `localStorage`(鍵 `gamelog-WebGame_DungeonZoo-pending`); 正常下載後清掉。下次開網頁、開始畫面按 Z 時, 若這個鍵還有紀錄 → 先把它補下載(檔名時間照下載當下, JSON 的 `finished` 為 false), 清掉後才開新局。`localStorage` 不能用(例如被瀏覽器擋)就略過, 不影響遊戲
- JSON 結構: `{ "game": "WebGame_DungeonZoo", "build": "polish-3", "startedAt": "<ISO 時間>", "finished": true|false, "events": [ ... ] }`; 每個事件都有 `t`(從開局起的秒數, 小數 2 位)、`type`, 其餘欄位如下:

| type | 何時 | 欄位 |
|---|---|---|
| session_start | 開始畫面按 Z | replay(是否為重來、跳過見習日) |
| tutorial_show | 教學階段出現 | stage(1~23)、day、scene(畫面) |
| tutorial_done | 教學階段完成 | stage、day、took(出現到完成的秒數) |
| intermission | 見習過場出現 / 按 Z 離開 | action(show / leave)、took(leave 時: 停留秒數) |
| day_start | 日曆過場開始 | day(0~7) |
| place_choose | 「今天去哪?」按 Z | day、place(dungeon / show / shop) |
| mute_toggle | 切靜音 | muted |
| dungeon_start | 進地下城 | day、dungeon、weapon、hearts、ropes |
| player_hit | 馴獸師扣心 | dungeon、source(技能代號 / hurt 地形 / blast)、x、y(世界座標)、heartsLeft、elapsed(進地下城後秒數) |
| player_down | 心歸零 | dungeon、x、y、elapsed |
| capture | 收服 | dungeon、species、num、elapsed、x、y |
| lasso_break | 套索斷掉 | dungeon、species、reason(timeout / distance / hit)、x、y |
| kill | 打倒魔物 | dungeon、species、by(weapon / blast / reflect)、x、y |
| object_use | 互動物件被用到 | dungeon、object(bush / fruit / keg / crackwall / portal / fountain)、action(hide / drop / blast / break / teleport / heal)、x、y |

| dungeon_end | 地下城結束 | day、dungeon、reason(time / down / exit / tutorial)、dur(秒, 不含詢問框暫停)、captures(種類陣列)、kills、heartsLost、gold |
| setup_back | 布置中返回 | day、from(setup2 / setup1)、to(setup1 / place) |
| setup_done | 開演 | day、roster(上台陣列: species、num)、rows(4 列: cue、program, 空為 "") |
| program_fire | 節目發動 | day、row(0~3)、cue、program、elapsed、targets(作用到的隻數) |

| mark_peak | 有一隻標記升到 3 以上 | day、species、num、marks、elapsed |
| show_end | 表演結束 | day、reason(time / loose)、dur(秒)、satisfaction、gold、fameGain、bestChain、performs(表演總次數)、angryPerforms、heatAvg(整場熱度平均, 整數)、heatMax、tierSec({quiet, clap, cheer, frenzy} 各段累計秒數, 小數 1 位)、looseSpecies、looseNum、looseX、looseY(失控時) |
| shop_buy | 商店購買 / 裝備 | day、item、cost、goldLeft |

可算出: 每關(每趟地下城 / 每場表演)通過時間 = dungeon_end.dur、show_end.dur; 失敗次數 = reason 為 down / loose 的次數; 卡關位置 = player_hit、player_down、lasso_break 的座標分布與 show_end 失控時的 elapsed、位置; 每個教學階段出現與完成時間 = tutorial_show / tutorial_done(took); 3 心難度是否合適 = player_down 次數與 dungeon_end.heartsLost; 出口使用率 = exit_prompt(leave / stay)與 dungeon_end reason exit; 熱度與失控的關係 = heat_tier 序列對照 show_end 的失控 elapsed、tierSec; 玩家有沒有用返回改主意 = setup_back; 中途離開的局 = finished 為 false 的檔與最後一筆事件。

## 範圍邊界
- 只做 7 天 + 見習日、4 張固定地圖; 不做存檔(教學完成記錄只留在本次開啟的網頁; 只有埋點紀錄會暫存在瀏覽器裡供補下載)
- 怪物庫每隻獨立; 不做升級、出售、放生、改名
- 表演中沒有任何操作; 不做馴獸師下場、準星、器材、大招、全場連擊計量; 熱度只顯示, 不影響結算
- 節目只看狀態挑對象, 不點名種類; 暗號只看全場
- 場地上不擺任何設施; 魔物開演位置照固定順序, 不做擺位
- 不做門票與觀眾人數; 金幣只來自表演結算與打倒魔物
- 地下城不做小地圖、迷霧、寶箱
- 不支援滑鼠

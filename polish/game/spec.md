## 概述
橫向寬畫面(1280×720), 全程只用鍵盤: 方向鍵 + Z、X, 地下城另有 C(換武器)。一共 **7 天**, 每天開始自己選要去哪: **地下城**(抓怪)、**表演**(賺觀眾滿意度 → 金幣與名聲)或**商店**(不花時間)。
地下城: 一張比畫面大的捲動地圖, 分成 6 個房間, 每座有兩種互動物件和一個出口; 方向鍵走位, Z 是武器普攻、X 是武器專屬技能(劍 / 長槍; 棍棒沒有), C 打開換武器視窗; 只有 3 顆心; 魔物出招前有前搖可以看; 把魔物打到虛弱後按 C 換成**捕捉繩**、按 Z 朝牠丟繩, 套上就暈眩不能出招, 繞牠一圈收服——也可以選擇直接打死; 沒虛弱就丟繩, 魔物會掙脫(不扣繩)。抓到的魔物一隻隻收進**怪物庫**, 表演最多上台 **20 隻**, 同種要放幾隻都行。
表演: 魔物在場上各自隨機亂走, 一律用遠距離技能表演, 打中別隻會惹牠生氣、讓牠冷靜或造成特殊效果(凍住、標靶、變走), 場面像彈幕大亂鬥。每次表演加**觀眾滿意度**, 生氣時表演加倍、連鎖加成; 全場平均怒氣顯示成**熱度**, 觀眾跟著熱度安靜 / 鼓掌 / 歡呼 / 沸騰; 熱度表旁另顯示場上最多的標記數; 怒氣滿了開始累積失控標記, 滿 5 個就失控——**全場觀眾逃走、表演立刻結束**。收場時觀眾滿意度換成金幣, 同時加進名聲。表演中玩家不操作, 靠事先排好的 **4 列暗號節目單**控場: 每列 = 一塊看全場狀態的暗號牌 + 一個節目, 全場符合目前這列的暗號就演這列的節目、換下一列, 依序循環。
本款魔物陣容: 鈴蘭精、火柴猴、齒輪甲蟲、標靶鸚鵡、冰柱企鵝、戲法狸。第 7 天結束後依總名聲評星。
驗證假設: H01、H04~H06、H50、H114~H117、H148、H168、H170~H174、H176、H177、H183~H188、H193、H200~H215。

## 用詞
玩家看得到的文字一律用左欄; 規格與程式也照這個稱呼。
| 用詞 | 意思 |
|---|---|
| 生氣 | 怒氣 ≥ 生氣門檻 80(`angryLow`, 固定 80)。有沒有失控標記都叫生氣 |
| 觀眾滿意度 | 一場表演中累積的分數; 收場時換成金幣、並加進名聲 |
| 名聲 | 跨天累計(總名聲), 決定地下城開放、商店上架與評星 |
| 熱度 | 表演中場上魔物怒氣的平均(0~100%), 只用來顯示, 不影響滿意度 |
| 上台 | 布置第 1 步選要參加表演的魔物 |
| 惹生氣 / 冷靜 | 效果分類; 程式內仍叫點燃型 / 澆熄型 |

## 核心循環
見習日(教學地下城 → 過場 → 教學表演)→ 第 1~7 天每天: 日曆過場 → 今天去哪? → 地下城: 挑一座、探索房間、利用互動物件、把想要的魔物打虛弱、換捕捉繩丟繩、繞圈收服, 抓夠了可以自己走出口提早收工 → 收進怪物庫 → 過一天 / 表演: 選上台、排暗號節目單 → 開演看大亂鬥, 盯著熱度, 暗號一個個成立、節目接連發動, 別讓任何一隻失控 → 觀眾滿意度換金幣並加進名聲 → 過一天 / 商店: 買武器、強化、新暗號與節目 → 回到今天去哪(不過天)。名聲 + 收服指定魔物解鎖新地下城。

## 開始畫面
1. 開啟網頁先顯示開始畫面(`drawTitle`): 遊戲名「來馬戲團看一點大場面」、幾隻魔物在背景走動放技能的小場景、下方閃爍「按 [Z] 開始」(Z 畫成鍵帽)。播標題音樂
2. 按 Z: 第一次玩 → 播見習日日曆過場 → 進教學地下城「見習草地」; 已完成過見習日(同一次開啟網頁內重來)→ 直接播第 1 天日曆過場。開始畫面只接受 Z, 方向鍵與 X 不反應
3. 打磨沒有說明頁; 規則都由新手教學在第一次碰到時教

## 新手教學
提示是一個貼著目標物件的對話泡泡(文字一句, 按鍵一律畫成鍵帽), 泡泡尾巴指向目標。泡泡文字裡的 `[Z]` `[C]` `[↓]` 等標記畫成鍵帽(和文字排在同一行); 第 1 階段的四個方向鍵與第 5 階段的繞圈示意另由 `keys` 畫成一組大鍵帽(第 1 階段按過的亮起)。一次只顯示一個**主階段**; 主階段依「出現時機」第一次成立時出現, 做到「完成條件」就播完成特效(0.6 秒)後消失, **已完成的階段不再出現, 重來(總結算後按 Z)也不重置**(記在本次開啟網頁的記憶裡)。同時有兩個主階段的出現時機成立時, 表中編號小的先, 大的等前一個完成後才出現(條件到時已不成立的照樣排隊, 輪到時再看一次條件, 不成立就等下次成立)。標「附註」的階段(第 7 階段)不佔主階段的位置, 和主階段同時顯示。表演中玩家沒有操作, 表演中的階段以場上事件或顯示時間當完成條件。

**地下城的教學只在見習草地與鏡湖出現**; 齒輪鐘塔、雪境的爆炸桶、裂牆、傳送陣、回復泉不教, 讓玩家自己嘗試。武器技也不另教(HUD 右側按鍵提示已畫出「[X] 擊暈 / [X] 突進」)。前搖不教(頭上「!」與方向箭頭本身就看得懂)。**教學只引導遊戲希望玩家做的事**: 地下城出口(提早收工)不教, 玩家碰到出口時詢問框本身就說明了。

## 埋點
每局(開始畫面按 Z 起到總結算)記錄事件, 進總結算的瞬間自動下載 JSON, 檔名 `gamelog-WebGame_DungeonZoo-<YYYYMMDD-HHMMSS>.json`(時間 = 下載當下的本機時間)。用 Blob + `<a download>` 下載, 不用任何外部服務。
- **沒玩完的局**: 每記一筆事件就把整份紀錄寫進瀏覽器 `localStorage`(鍵 `gamelog-WebGame_DungeonZoo-pending`); 正常下載後清掉。下次開網頁、開始畫面按 Z 時, 若這個鍵還有紀錄 → 先把它補下載(檔名時間照下載當下, JSON 的 `finished` 為 false), 清掉後才開新局。`localStorage` 不能用(例如被瀏覽器擋)就略過, 不影響遊戲
- JSON 結構: `{ "game": "WebGame_DungeonZoo", "build": "polish-5", "startedAt": "<ISO 時間>", "finished": true|false, "events": [ ... ] }`; 每個事件都有 `t`(從開局起的秒數, 小數 2 位)、`type`, 其餘欄位如下:

| type | 何時 | 欄位 |
|---|---|---|
| session_start | 開始畫面按 Z | replay(是否為重來、跳過見習日) |
| tutorial_show | 教學階段出現 | stage(1~23, 本輪重新編號)、day、scene(畫面) |
| tutorial_done | 教學階段完成 | stage、day、took(出現到完成的秒數)、cut(true = 表演收場時還沒做完、直接算完成; 平常 false) |
| intermission | 見習過場出現 / 按 Z 離開 | action(show / leave)、took(leave 時: 停留秒數) |
| day_start | 日曆過場開始 | day(0~7) |
| place_choose | 「今天去哪?」按 Z | day、place(dungeon / show / shop) |
| mute_toggle | 切靜音 | muted |
| dungeon_start | 進地下城 | day、dungeon、weapon、hearts、ropes |
| player_hit | 馴獸師扣心 | dungeon、source(技能代號 / hurt 地形 / blast)、x、y(世界座標)、heartsLeft、elapsed(進地下城後秒數) |
| player_down | 心歸零(倒下動畫開始) | dungeon、source(同 player_hit)、cause(原因字串, 同畫面上的「被〔…〕打倒了」)、x、y、elapsed |
| weapon_switch | 換武器視窗按 Z 換上 / 收服用完繩子自動換回 | dungeon、from、to(club / sword / spear / rope)、auto(true = 繩子用完自動換回)、elapsed、pausedFor(視窗開了幾秒; auto 時 0) |
| rope_throw | 丟出的繩子有結果 | dungeon、result(miss / escape / lasso)、species(miss 時 null)、weak(打中時目標是否虛弱)、dist(丟出時和目標的距離, miss 時 null)、elapsed |
| capture | 收服 | dungeon、species、num、elapsed、x、y、ropesLeft |
| lasso_break | 套索斷掉 | dungeon、species、reason(timeout / distance / hit)、x、y |
| fruit_eat | 吃果子回心 | dungeon、heartsAfter、elapsed、x、y |
| kill | 打倒魔物 | dungeon、species、by(weapon / blast / reflect)、x、y |
| object_use | 互動物件被用到 | dungeon、object(bush / fruit / keg / crackwall / portal / fountain)、action(hide / drop / blast / break / teleport / heal; 吃果子另記 fruit_eat)、x、y |
| exit_prompt | 出口詢問框跳出 / 做出選擇 | dungeon、action(show / leave / stay)、elapsed、captures(到這一刻這趟收服數)、heartsLeft |
| dungeon_end | 地下城結束 | day、dungeon、reason(time / down / exit / tutorial)、dur(秒, 不含出口詢問框、換武器視窗的暫停與倒下動畫)、captures(種類陣列)、kills、heartsLost、gold |
| setup_back | 布置中返回 | day、from(setup2 / setup1)、to(setup1 / place) |
| setup_denied | 見習日上台數不對被擋 | day、reason(need2: 不滿 2 隻按下一步 / max2: 想選第 3 隻)、count(當下上台數) |
| setup_done | 開演 | day、roster(上台陣列: species、num)、rows(4 列: cue、program, 空為 "") |
| program_fire | 節目發動 | day、row(0~3)、cue、program、elapsed、targets(作用到的隻數) |
| heat_tier | 熱度換段(含開演時的第一段) | day、tier(quiet / clap / cheer / frenzy)、heat(整數 %)、elapsed |
| mark_peak | 有一隻標記升到 3 以上 | day、species、num、marks、elapsed |
| show_end | 表演結束 | day、reason(time / loose)、dur(秒)、satisfaction、gold、fameGain、bestChain、performs(表演總次數)、angryPerforms、heatAvg(整場熱度平均, 整數)、heatMax、tierSec({quiet, clap, cheer, frenzy} 各段累計秒數, 小數 1 位)、maxMarksPeak(整場「最高標記」的最大值 0~5, 失控為 5)、looseHeat(失控那刻的熱度整數 %, 不是失控為 null)、looseSpecies、looseNum、looseX、looseY(失控時) |
| shop_buy | 商店購買 / 裝備 | day、item、cost、goldLeft |
| dungeon_unlock | 地下城開放 | day、dungeon、fame |
| game_end | 進總結算 | fame、stars、goldEarned、bestChain、days(7 天各去哪)、bankSize |

可算出: 每關(每趟地下城 / 每場表演)通過時間 = dungeon_end.dur、show_end.dur; 失敗次數 = reason 為 down / loose 的次數; 卡關位置 = player_hit、player_down、lasso_break 的座標分布與 show_end 失控時的 elapsed、位置; 每個教學階段出現與完成時間 = tutorial_show / tutorial_done(took); 3 心難度是否合適 = player_down 次數與 dungeon_end.heartsLost; 出口使用率 = exit_prompt(leave / stay)與 dungeon_end reason exit; 熱度與失控的關係 = heat_tier 序列對照 show_end 的失控 elapsed、tierSec、looseHeat(失控時熱度低 = 單隻爆掉, 看最高標記有沒有幫上忙); 鐘塔降坡是否有效 = player_hit source blast 的次數; 新捕捉方式是否看得懂 = 第 3、4 階段 tutorial_done.took 與 rope_throw 裡 escape(沒打虛弱就丟)/ miss 的比例; 換武器多不多、會不會卡在視窗 = weapon_switch 次數與 pausedFor; 死因 = player_down.cause; 果樹回血有沒有被用 = fruit_eat; 見習選上台卡不卡 = setup_denied; 玩家有沒有用返回改主意 = setup_back; 中途離開的局 = finished 為 false 的檔與最後一筆事件。

- **觀眾聲(crowd_clap / crowd_cheer / crowd_frenzy)是循環環境音**: 同一時間最多一種; 換段時 0.4 秒交叉淡入淡出; 安靜段沒有觀眾聲。音量要壓在 perform、ignite 等表演音效之下(底層), 不能蓋過它們。失控、時間到、離開表演場時 0.3 秒淡出。由音效節點提供設定目前觀眾聲的介面(例 `Sound.setCrowd('clap' | 'cheer' | 'frenzy' | '')`), 寫進 sound.md 給 RD

## 範圍邊界
- 只做 7 天 + 見習日、4 張固定地圖; 不做存檔(教學完成記錄只留在本次開啟的網頁; 只有埋點紀錄會暫存在瀏覽器裡供補下載)
- 怪物庫每隻獨立; 不做升級、出售、放生、改名
- 表演中沒有任何操作; 不做馴獸師下場、準星、器材、大招、全場連擊計量; 熱度只顯示, 不影響結算
- 節目只看狀態挑對象, 不點名種類; 暗號只看全場
- 場地上不擺任何設施; 魔物開演位置照固定順序, 不做擺位
- 不做門票與觀眾人數; 金幣只來自表演結算與打倒魔物
- 地下城不做小地圖、迷霧、寶箱
- 不支援滑鼠
- 表演場不加前搖(使用者決定: 怕畫面太亂); 換武器只在地下城
- 捕捉繩只有一種, 不做不同等級的繩子

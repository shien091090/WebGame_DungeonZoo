## 概述
橫向寬畫面(1280×720), 全程只用鍵盤: 方向鍵 + Z、X, 地下城另有**空白鍵**(拋捕捉繩)。一共 **4 天**(另加見習日), 每天固定: **出發準備 → 地下城(抓怪、找寶箱)→ 出發準備 → 表演(賺觀眾滿意度 → 金幣與名聲)**; 兩個出發準備畫面都能先進商店。
地下城: 兩座多層地下城, 每層是一張比畫面大的捲動地圖(6 個房間), 有往下的樓梯; 方向鍵走位, Z 武器普攻、X 武器技(劍 / 長槍; 棍棒沒有); 開局 5 顆心; 魔物出招前有前搖; 把魔物打到虛弱後按**空白鍵**朝牠拋繩, 套上就暈眩不能出招, 繞牠一圈收服——也可以選擇直接打死; 沒虛弱就拋繩, 魔物會掙脫(不扣繩)。地下城裡藏著永久強化的石碑與裝卡片的寶箱。抓到的魔物一隻隻收進**怪物庫**, 表演最多上台 **20 隻**, 同種要放幾隻都行。
表演: 魔物在場上各自隨機亂走, 一律用遠距離技能表演, 打中別隻會惹牠生氣、讓牠冷靜或造成特殊效果(凍住、標靶、變走), 場面像彈幕大亂鬥。每次表演加**觀眾滿意度**, 生氣時表演加倍、連鎖加成; 全場**熱度**顯示在熱度表, 觀眾跟著安靜 / 鼓掌 / 喝采 / 沸騰; 熱度超過熱度表上的失控線就**失控——全場觀眾逃走、表演立刻結束**。收場時觀眾滿意度換成金幣, 同時加進名聲。表演中玩家不操作, 靠事先排好的**節目單**控場: 每列 = 一張看全場狀態的暗號 + 一張表演卡, 暗號成立就演這列的表演卡、換下一列, 依序循環。
本款魔物陣容: 火柴猴、齒輪甲蟲、標靶鸚鵡、爆竹刺蝟(新)、鈴蘭精、冰柱企鵝、戲法狸。第 4 天表演結束後依總名聲評星。
驗證假設: H01、H04~H06、H50、H114~H116、H148、H168、H170~H174、H176、H177、H183~H188、H193、H200~H224(本輪主要回應 H218~H224)。

## 用詞
玩家看得到的文字一律用左欄; 規格與程式也照這個稱呼。
| 用詞 | 意思 |
|---|---|
| 生氣 | 怒氣 ≥ 生氣門檻 80(`angryLow`, 固定 80) |
| 觀眾滿意度 | 一場表演中累積的分數; 收場時換成金幣、並加進名聲 |
| 名聲 | 跨天累計(總名聲), 決定商店上架與評星 |
| 熱度 | 表演中全場的熱度平均(0~100%), 超過失控線(92%)就失控 |
| 上台 | 布置第 1 步選要參加表演的魔物 |
| 表演卡 | 節目單每列右格要演的東西(程式內仍叫 program / 節目) |
| 暗號 | 節目單每列左格, 全場狀態符合就發動這列的表演卡(程式內 cue) |
| 惹生氣 / 冷靜 | 效果分類; 程式內仍叫點燃型 / 澆熄型 |
| 標記 | **只在規格與程式裡用**, 玩家看不到這個字也看不到數字(第 70 條) |

## 核心循環
見習日(選武器 → 教學地下城 → 過場 → 教學表演)→ 第 1~4 天每天: 日曆過場 → 出發準備(可先去商店)→ 選地下城 → 選武器 → 地下城: 一層層往下, 打虛弱、拋繩、繞圈收服, 碰到石碑永久變強、打開寶箱拿到新暗號 / 表演卡 → 收進怪物庫 → 出發準備(可先去商店)→ 布置: 選上台、排節目單 → 開演看大亂鬥, 盯著熱度別超過失控線 → 觀眾滿意度換金幣並加進名聲 → 下一天。名聲讓商店上架更多東西; 第 1 座第 2 層的出口打開第 2 座。

## 新手教學
提示是一個貼著目標物件的對話泡泡(文字一句, 按鍵一律畫成鍵帽), 泡泡尾巴指向目標。泡泡文字裡的 `[Z]` `[空白]` `[↓]` 等標記畫成鍵帽(和文字排在同一行); 第 2 階段的四個方向鍵與第 5 階段的繞圈示意另由 `keys` 畫成一組大鍵帽(第 2 階段按過的亮起)。**大鍵帽排法**(照舊): 照 `keys` 順序排一橫排, 每顆 34×34、間距 12, 以泡泡中心 bx 為中心, 第 i 顆(從 0 起算)中心 x = bx − (34n + 12(n − 1)) / 2 + 17 + 46i、y = by + 22; 每顆只畫一個符號。一次只顯示一個**主階段**; 主階段依「出現時機」第一次成立時出現, 做到「完成條件」就播完成特效(0.6 秒)後消失, **已完成的階段不再出現, 重來(總結算後按 Z)也不重置**(記在本次開啟網頁的記憶裡)。同時有兩個主階段的出現時機成立時, 編號小的先, 大的等前一個完成後才出現(輪到時再看一次條件, 不成立就等下次成立)。標「附註」的階段(第 7、20 階段)不佔主階段的位置, 和主階段同時顯示。表演中玩家沒有操作, 表演中的階段以場上事件或顯示時間當完成條件。

**地下城的教學只在見習草地與第 1 座第 1 層出現**(第 20 階段附註例外: 第一次進正式地下城就是第 1 座第 1 層, 實際上也只在那裡出現)。第 1 座第 2 層之後的爆炸桶、裂牆、傳送陣、回復泉、強化石碑、寶箱不教, 讓玩家自己嘗試(石碑碰到就飄字說明; 寶箱的過場自己會說明是表演用的卡)。武器技不另教(HUD 按鍵提示已畫出「[X] 擊暈 / [X] 突進」)。前搖不教。地下城出口不教。

    - **失控線 92%**(= 全場平均怒氣 100 + 平均 3 層標記): 熱度 ≥ 92 的那一瞬間失控(第 66 條)。任一隻自己滿 5 層**不會**失控
    - 熱度段(`tier`): **安靜** quiet(< 50)、**掌聲** clap(≥ 50)、**喝采** cheer(≥ 75)、**沸騰** frenzy(≥ 85); 85~92 是失控前的危險區。往上跨門檻立刻換段, 往下要低於該段門檻連續 1 秒才降段。開演時直接依開演熱度定段(怒氣 65 → 52% 掌聲; 見習日 75 → 60% 掌聲)
63. **熱度表**(`drawHeatMeter`, 420×42 中心 (640, 25), x 430~850、y 4~46):
    - 左側文字區 x 436~526: 上行「熱度 N%」(y 約 16)、下行段名(安靜 / 掌聲 / 喝采 / 沸騰!, y 約 36)
    - 進度條 x 536~836(300 像素, 每 1% = 3 像素)、y 16~34; 刻度 50 → x 686、75 → x 761、85 → x 791
    - **失控線** 92% → x 812: 一條紅色粗直線 y 8~44, 線頂端一個小骷髏 / 火焰記號(在 y 4~12 內), 不寫數字; 熱度進入沸騰段時失控線閃爍
    - 換段時熱度表彈一下(0.4 秒); 「最高標記」4 格**拿掉**
64. 觀眾反應照舊跟熱度段走(安靜 坐著看 / 掌聲 拍手 / 喝采 站起歡呼 / 沸騰 更激烈但緊張冒汗), 觀眾聲循環 `crowd_clap` / `crowd_cheer` / `crowd_frenzy`; 沸騰時畫面四周紅色脈動邊框(`drawHeatAlert`); 剛進沸騰播 `heat_warn`。段名「歡呼」改叫「**喝采**」(玩家看得到的字)
65. **觀眾滿意度、金幣與名聲**:
    - 每次表演的觀眾滿意度 =(種類滿意度)×(1 + 0.5 × min(4, 打中的其他魔物數))×(生氣時 2, 否則 1)×(1 + 0.25 ×(段數 − 1)), 四捨五入, 最少 1(歡呼 ×1.5 隨表演卡拿掉)
    - 大彩炮另外直接加 10 + 5 × N(第 57 條)
    - 收場時: 金幣 = 20 + round(8 × √觀眾滿意度); 名聲 += 觀眾滿意度
66. **失控 = 表演結束**(收場演出照舊 2.5 秒): 熱度 ≥ 92 的那一幀, 挑**標記最多**的那隻當主角(同數取怒氣高的, 再同取怪物庫順序前的), 牠大吼、衝向最近那側圍欄撞破、觀眾逃走; 其他一切停住; 觀眾滿意度以那一刻為準
67. 時間到: 收場, 進表演結算
68. 接演(即時連鎖, 照舊): 被點燃型**技能**打中後, 若正在生氣、不在凍住、距上次接演已過 1.5 秒 → 0.3 秒後表演, 段數 = 打中牠那招的段數 + 1。定時表演是第 1 段; 衝撞、炸藥桶不是技能, 不引發接演
69. 標記(只在規則與程式裡, 玩家看不到):
    - 怒氣升到 100 的瞬間 → 標記 1; 有標記期間怒氣停在 100、不自然下降
    - 有標記時被點燃型效果升怒(技能、衝撞、炸藥桶)→ 標記 +1, 同一隻每 1 秒最多 +1, **最多 5**(滿 5 只是停在 5, 不失控); 被澆熄型技能打中 → 標記 −1; 下雨 → 標記 −1
    - 標記每 4 秒自動 −1(有增減時重新計時); 減到 0 → 怒氣每秒 −2, 降到 80 以下恢復種類速度
    - **見習日標記最多 2**(熱度最高 80 + 8 = 88 < 92, 見習表演不會失控)
70. **標記隱性化**(本輪): 怪物身上不畫標記符號、不寫數字; 改成**外觀越來越生氣**——0: 照怒氣畫(生氣時生氣臉); 1: 頭上冒一縷蒸氣; 2: 臉漲紅 + 兩縷蒸氣; 3: 全身泛紅光 + 青筋; 4: 紅光脈動 + 咬牙; 5: 身上冒小火焰。`drawShowMonster` 照舊收到 `marks`(0~5), 只拿來畫外觀
71. 效果打中後魔物身上顯示被惹生氣 / 被冷靜 / 特殊效果的反應 0.5 秒; 標靶期間一直顯示標靶記號; 凍住期間顯示冰塊
72. 移動的優先順序: 凍住 > 被撞開(0.25 秒)> 衝撞手 > 表演卡移動(繞場、散場、聚集, 取後發動的)> 自己的模式。表演動作期間照常移動

- 怪物庫每隻獨立; 不做升級、出售、放生、改名
- 表演中沒有任何操作(使用者決定先維持, 教學第 13 階段提示)
- 地下城裡不能換武器; 不做回上一層、小地圖、迷霧
- 寶箱與石碑內容固定, 拿過不再出現(重來恢復); 不做隨機掉落
- 標記不顯示給玩家(只改外觀)
- 表演場不加前搖
- 不支援滑鼠

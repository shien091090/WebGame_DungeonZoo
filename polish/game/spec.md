## 概述
橫向寬畫面(1280×720), 全程只用鍵盤: 方向鍵 + Z、X, 地下城另有**空白鍵**(拋捕捉繩)。一共 **4 天**(另加見習日), 每天固定: **出發準備 → 地下城(抓怪、找石碑變強)→ 出發準備 → 表演(賺觀眾滿意度 → 金幣與名聲)**; 兩個出發準備畫面都能先進商店。
地下城: 兩座多層地下城, 每層是一張比畫面大的捲動地圖(6 個房間), 有往下的樓梯; 方向鍵走位, Z 武器普攻、X 武器技(劍 / 長槍; 棍棒沒有); 開局血量 5; 魔物出招前有前搖; 把魔物打到虛弱後按**空白鍵**朝牠拋繩, 套上就暈眩不能出招, 繞牠一圈收服——也可以選擇直接打死; 沒虛弱就拋繩, 魔物會掙脫(不扣繩)。地下城裡藏著永久強化的石碑, 第 1 座最深層有打開第 2 座的鑰匙寶箱; 暗號與表演卡都在商店買。抓到的魔物一隻隻收進**怪物庫**, 表演最多上台 **20 隻**, 同種要放幾隻都行。
表演: 魔物在場上各自隨機亂走, 一律用遠距離技能表演, 打中別隻會惹牠生氣、讓牠冷靜或造成特殊效果(凍住、標靶、變走), 場面像彈幕大亂鬥。每次表演加**觀眾滿意度**, 生氣時表演加倍、連鎖加成; 全場**熱度**顯示在熱度表, 觀眾跟著安靜 / 鼓掌 / 喝采 / 沸騰; 熱度超過熱度表上的失控線就**失控——全場觀眾逃走、表演立刻結束**。收場時觀眾滿意度換成金幣, 同時加進名聲。表演中玩家不操作, 靠事先排好的**節目單**控場: 每列 = 一張看全場狀態的暗號 + 一張表演卡, 暗號成立就演這列的表演卡、換下一列, 依序循環。
本款魔物陣容: 火柴猴、齒輪甲蟲、標靶鸚鵡、爆竹刺蝟(新)、鈴蘭精、冰柱企鵝、戲法狸。第 4 天表演結束後依總名聲評星。
驗證假設: H01、H04~H06、H50、H114~H116、H148、H168、H170~H174、H176、H177、H183~H188、H193、H200~H231(本輪照 polish-9 回饋把卡片改回商店, 並以 waitMax 埋點觀察 H186)。

## 用詞
玩家看得到的文字一律用左欄; 規格與程式也照這個稱呼。
| 用詞 | 意思 |
|---|---|
| 血量 | 馴獸師的生命值(本輪起玩家看到的字一律叫「血量」, 不再寫「心」; 圖示仍是愛心; 程式內仍叫 hearts) |
| 生氣 | 怒氣 ≥ 生氣門檻 80(`angryLow`, 固定 80) |
| 觀眾滿意度 | 一場表演中累積的分數; 收場時換成金幣、並加進名聲 |
| 名聲 | 跨天累計(總名聲), 決定商店上架與評星 |
| 熱度 | 表演中全場的熱度平均(0~100%), 超過失控線(92%)就失控 |
| 上台 | 布置第 1 步選要參加表演的魔物 |
| 表演卡 | 節目單每列右格要演的東西(程式內仍叫 program / 節目) |
| 暗號 | 節目單每列左格, 全場狀態符合就發動這列的表演卡(程式內 cue) |
| 惹生氣 / 冷靜 | 效果分類; 程式內仍叫點燃型 / 澆熄型 |
| 標記 | **只在規格與程式裡用**, 玩家看不到這個字也看不到數字(第 70 條) |

## 核心循環
見習日(選武器 → 教學地下城 → 過場 → 教學表演)→ 第 1~4 天每天: 日曆過場 → 出發準備(可先去商店)→ 選地下城 → 選武器 → 地下城: 一層層往下, 打虛弱、拋繩、繞圈收服, 碰到石碑永久變強 → 收進怪物庫 → 出發準備(可先去商店買暗號 / 表演卡)→ 布置: 選上台、排節目單 → 開演看大亂鬥, 盯著熱度別超過失控線 → 觀眾滿意度換金幣並加進名聲 → 下一天。名聲讓商店上架更多暗號、表演卡與武器; 第 1 座第 2 層深處的鑰匙寶箱打開第 2 座。

1. 開啟網頁先顯示開始畫面(`drawTitle`): 遊戲名「來馬戲團看一點大場面」、幾隻魔物在背景走動放技能的小場景、下方閃爍「按 [Z] 開始」(Z 畫成鍵帽)。播標題音樂
2. 按 Z: 第一次玩 → 見習日日曆過場 → **選武器畫面**(只有棍棒, 教學第 1 階段)→ 見習草地(先跳任務卡, 第 38 條); 已完成過見習日(同一次開啟網頁內重來)→ 直接播第 1 天日曆過場。開始畫面只接受 Z
3. 打磨沒有說明頁; 規則都由新手教學在第一次碰到時教

## 新手教學
教學有兩種形式:
- **提示泡泡**(`drawTutorial`, 照舊): 貼著目標物件的對話泡泡(文字一句, 按鍵一律畫成鍵帽), 尾巴指向目標, 遊戲照常進行。泡泡文字裡的 `[Z]` `[空白]` `[↓]` 等標記畫成鍵帽(和文字排在同一行); 第 2 階段的四個方向鍵與第 5 階段的繞圈示意另由 `keys` 畫成一組大鍵帽(第 2 階段按過的亮起)。**大鍵帽排法**(照舊): 照 `keys` 順序排一橫排, 每顆 34×34、間距 12, 以泡泡中心 bx 為中心, 第 i 顆(從 0 起算)中心 x = bx − (34n + 12(n − 1)) / 2 + 17 + 46i、y = by + 22; 每顆只畫一個符號
- **暫停式引導卡**(`drawGuide`, 本輪新增): 兩段——**表演引導**(第 13~16 階段, 見習日表演)與**地下城引導**(第 21~25 階段, 第 1 天第一次進正式地下城)。畫面整個暫停, 一張卡講一個區塊, 用聚光燈把目光框到那一小塊; 最後一張是「接下來就做這件事」, 置中大卡 + 盛大特效。規則見表後「暫停式引導」

一次只顯示一個**主階段**(泡泡或引導卡); 主階段依「出現時機」第一次成立時出現, 做到「完成條件」就播完成特效後消失, **已完成的階段不再出現, 重來(總結算後按 Z)也不重置**(記在本次開啟網頁的記憶裡)。同時有兩個主階段的出現時機成立時, 編號小的先, 大的等前一個完成後才出現(輪到時再看一次條件, 不成立就等下次成立)。標「附註」的階段(第 7 階段)不佔主階段的位置, 和主階段同時顯示。表演中玩家沒有操作, 表演中的泡泡階段以場上事件或顯示時間當完成條件。

**地下城的教學只在見習草地與第 1 座第 1 層出現**。第 1 座第 2 層之後的爆炸桶、裂牆、傳送陣、回復泉、強化石碑、鑰匙寶箱不教, 讓玩家自己嘗試(石碑碰到就飄字說明; 鑰匙寶箱的過場自己會說明)。商店第一次買到卡時, 拿到卡的過場提示行會說「這是表演用的卡! 表演前排進節目單」(第 74 條), 不另開教學階段。武器技不另教(HUD 按鍵提示已畫出「[X] 擊暈 / [X] 突進」)。前搖不教。出口只在地下城引導卡講一次「可以中途離開」, 靠近出口不跳提示(polish-3 指定照舊)。

## 範圍邊界
- 只做 4 天 + 見習日、2 座地下城共 5 層 + 見習草地, 地圖固定; 不做存檔(教學記錄只留在本次開啟的網頁; 埋點暫存在 localStorage)
- 怪物庫每隻獨立; 不做升級、出售、放生、改名
- 表演中沒有任何操作(使用者決定先維持, 表演引導第 13 階段卡片小字提示; 引導卡的 Z 換卡是唯一例外)
- 暗號一直不成立時不自動跳下一列(會改到暗號依序推進的規則, 要先問使用者); 本輪只在縮小節目單標出等待中的列
- 地下城裡不能換武器; 不做回上一層、小地圖、迷霧
- 石碑與鑰匙寶箱固定, 拿過不再出現(重來恢復, 含第 2 座關閉); 不做隨機掉落; 地下城不放卡(暗號與表演卡只在商店買, polish-9 使用者指定)
- 標記不顯示給玩家(只改外觀)
- 表演場不加前搖
- 不支援滑鼠

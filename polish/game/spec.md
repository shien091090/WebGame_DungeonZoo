## 概述
橫向寬畫面(1280×720), 全程只用方向鍵 + Z、X。每天開始自己選要去哪: **地下城**(抓怪)、**表演**(賺名聲與金幣)或**商店**(不花時間)。
地下城: 一張比畫面大的捲動地圖, 分成 6 個房間, 每座有兩種互動物件; 方向鍵走位, Z 是武器普攻、X 是武器專屬技能(棍棒 / 劍 / 長槍 / 長鞭); 把魔物打到殘血後站到牠身上, 跑完「準備捕捉」圓圈就套上套索, 被套的魔物暈眩不能出招, 繞牠一圈收服——也可以選擇直接打死。抓到的魔物一隻隻收進**怪物庫**(每隻獨立、可個別升級), 表演最多上場 **20 隻**, 同種要放幾隻都行。
表演: 魔物在場上各自隨機亂走, 一律用遠距離技能表演, 打中別隻會點燃(激怒)、澆熄(冷靜)或造成特殊效果(凍結、標靶、變走), 場面像彈幕大亂鬥。每次表演加名聲, 紅區加倍、連鎖加成; 怒氣滿了開始累積失控標記, 滿 5 個就失控——**全場觀眾逃走、表演立刻結束**。收場時本場名聲換成金幣。表演中玩家不操作, 靠事先排好的**暗號節目單**控場: 每列 = 一塊看全場狀態的暗號牌 + 一個節目, 全場符合目前這列的暗號就演這列的節目、換下一列, 依序循環。
本款魔物陣容: 鈴蘭精、火柴猴、齒輪甲蟲、標靶鸚鵡、冰柱企鵝、戲法狸。第 5 天結束後依總名聲評星。
驗證假設: H01、H04~H06、H50、H114~H117、H148、H168、H170~H177、H183~H188、H193。

## 核心循環
第 0 天見習日(教學地下城 → 教學表演)→ 第 1~5 天每天: 日曆過場 → 今天去哪? → 地下城: 挑一座、探索房間、利用互動物件、把想要的魔物打殘套索繞圈收服 → 收進怪物庫 → 過一天 / 表演: 選上場(每隻獨立)、個別升級、排暗號節目單 → 開演看大亂鬥, 暗號一個個成立、節目接連發動, 別讓任何一隻失控 → 名聲換金幣 → 過一天 / 商店: 買武器、強化、新暗號與節目、升級個別魔物 → 回到今天去哪(不過天)。名聲 + 收服指定魔物解鎖新地下城。

## 關卡
「關卡」= 4 張地下城地圖(見習草地 + 3 座)與每天的表演。地下城依解鎖順序越來越難; 表演沒有固定關卡, 難度來自玩家自己放上場的魔物數與種類(越多越熱鬧、也越容易失控)。

| 關 | 地下城 | 代號 | 魔物(血量 / 施放間隔) | 投射物速度 | 傷害地形 | 互動物件 | 時間 | 開放條件 |
|---|---|---|---|---|---|---|---|---|
| 0 | 見習草地 | meadow | 火柴猴(6 / 4.0 秒) | 火柴 160 | 無 | 無 | 不限時, 收服 2 隻結束 | 只在見習日, 之後不可選 |
| 1 | 鏡湖 | lake | 鈴蘭精(7 / 3.0)、火柴猴(7 / 3.0) | 種類表 | 無 | 草叢、誘餌果樹 | 75 秒 | 見習日後就開放 |
| 2 | 齒輪鐘塔 | tower | 齒輪甲蟲(12 / 3.2)、標靶鸚鵡(12 / 2.6) | 種類表 | 齒輪刃 | 爆炸桶、裂牆 | 75 秒 | 名聲 80 + 收服鈴蘭精 2 次 |
| 3 | 雪境 | snow | 冰柱企鵝(16 / 3.0)、戲法狸(18 / 3.0) | 種類表 | 冰刺 | 傳送陣、回復泉 | 75 秒 | 名聲 300 + 收服標靶鸚鵡 2 次 |

| 表演 | 時間 | 開演怒氣 | 可用暗號 / 節目 | 失控 |
|---|---|---|---|---|
| 見習日表演 | 30 秒 | 75 | 只有 過 6 秒、有人進紅區 / 冰水桶、大合奏 | 不會失控(標記最多到 4) |
| 第 1~5 天表演 | 45 秒 | 60 | 擁有的全部 | 標記滿 5 → 失控、表演結束 |

難度爬升:
- 地下城: 魔物血量 6 → 7 → 12 → 16~18; 第 2 座起有傷害地形; 互動物件從「幫你」(草叢躲、果樹引開)到「雙面刃」(爆炸桶也炸自己)到「要找路」(左右房只能傳送)
- 表演: 第 1 天通常只有 2~4 隻、只有基本暗號; 抓越多、上場越多, 彈幕越密、怒氣升越快, 越需要買冷靜類節目(安撫曲)與更細的暗號(有人標記 3)來壓住失控; 名聲門檻把較強的暗號 / 節目延後到中段才上架
- 名聲同時是地下城開放門檻與商店上架門檻, 前期表演的成敗直接決定中後期能去哪、能買什麼

## 規則

### 流程
4. 開始畫面按 Z → 見習日(第 0 天, 見「開始畫面」第 2 條): 日曆過場 → 見習草地 → 地下城結算 → 表演布置第 1 步 → 第 2 步 → 見習日表演 → 表演結算 → 第 1 天
5. 第 1~5 天每天: 日曆過場(第 80 條)→「今天去哪?」(第 81 條)
   - 地下城: 地下城選擇 → 地下城(75 秒)→ 地下城結算 → 過一天
   - 表演: 布置第 1 步 → 第 2 步 → 表演場(45 秒, 失控會提早結束)→ 表演結算 → 過一天
   - 商店: 商店 → 按「離開」回到「今天去哪?」(同一天)
   - 地下城選擇按 X、布置第 1 步的「返回」: 回到「今天去哪?」(不過天)
6. 第 5 天的地下城或表演結算後按 Z → 總結算
7. 見習日結束時的狀態(= 第 1 天開局): 金幣 30 + 見習日表演換到的金幣、名聲 = 見習日表演的名聲、怪物庫 = 見習草地收服的 2 隻火柴猴(Lv0)、武器棍棒(只擁有棍棒)、擁有的暗號: 過 6 秒、有人進紅區; 擁有的節目: 冰水桶、大合奏

### 地下城的互動物件
17. 草叢(`G`, 鏡湖): 可以走。馴獸師中心所在的格是草叢 →「躲藏」: 魔物把他當成距離 ≥ 300(不瞄準、不對他施放, 已在預警中的照常落下; 移動改成隨機)。投射物照樣打得到他。走出草叢的瞬間算重新進入魔物的 300 範圍(第一次施放等一個完整間隔)。HUD 訊息改「躲藏中」
18. 誘餌果樹(`Y`, 鏡湖): 視同牆。每棵開局結 1 顆果子。被馴獸師的攻擊範圍蓋到樹格中心且樹上有果子 → 果子掉在樹下方那格中心, 樹 15 秒後重新結果
    - 果子掉落時, 同一房間裡的魔物(被套住、暈眩中的除外)不照自己的模式, 以 80 像素/秒走向果子; 離果子 ≤ 30 就停下來吃。走過去與吃的期間不施放技能(預警中的取消)
    - 第一隻開始吃之後 3 秒, 果子吃完消失, 所有魔物恢復原本的行動。馴獸師碰到果子沒有效果
19. 爆炸桶(`K`, 齒輪鐘塔): 擋路(視同半徑 22 的圓形障礙, 馴獸師與投射物都過不去)。被馴獸師的攻擊範圍蓋到桶中心, 或被魔物任何技能打到(投射物碰到、範圍蓋到桶中心)→ 點燃, 0.6 秒後爆炸: 以桶中心為圓心半徑 130(外緣)內的野生魔物各受 4 傷害(被套住的不受傷), 馴獸師在範圍內(馴獸師圓與範圍重疊)扣 1 顆心(無敵中不扣); 範圍蓋到的裂牆格中心 → 裂痕 +1; 範圍內的其他爆炸桶也會被點燃(連環爆)。爆炸後桶消失, 20 秒後在原位重生。被炸死的魔物也算打倒、給金幣

## 埋點
每局(開始畫面按 Z 起到總結算)記錄事件, 進總結算的瞬間自動下載 JSON, 檔名 `gamelog-WebGame_DungeonZoo-<YYYYMMDD-HHMMSS>.json`(時間 = 下載當下的本機時間)。用 Blob + `<a download>` 下載, 不用任何外部服務。
JSON 結構: `{ "game": "WebGame_DungeonZoo", "build": "polish-1", "startedAt": "<ISO 時間>", "events": [ ... ] }`; 每個事件都有 `t`(從開局起的秒數, 小數 2 位)、`type`, 其餘欄位如下:

| type | 何時 | 欄位 |
|---|---|---|
| session_start | 開始畫面按 Z | replay(是否為重來、跳過見習日) |
| tutorial_show | 教學階段出現 | stage(1~24)、day、scene(畫面) |
| tutorial_done | 教學階段完成 | stage、day、took(出現到完成的秒數) |
| day_start | 日曆過場開始 | day(0~5) |
| place_choose | 「今天去哪?」按 Z | day、place(dungeon / show / shop) |
| mute_toggle | 切靜音 | muted |
| dungeon_start | 進地下城 | day、dungeon、weapon、hearts、ropes |
| player_hit | 馴獸師扣心 | dungeon、source(技能代號 / hurt 地形 / blast)、x、y(世界座標)、heartsLeft、elapsed(進地下城後秒數) |
| player_down | 心歸零 | dungeon、x、y、elapsed(見習草地也記, 之後原地補滿) |
| capture | 收服 | dungeon、species、num、elapsed、x、y |
| lasso_break | 套索斷掉 | dungeon、species、reason(timeout / distance / hit)、x、y |
| kill | 打倒魔物 | dungeon、species、by(weapon / blast / reflect)、x、y |
| object_use | 互動物件被用到 | dungeon、object(bush / fruit / keg / crackwall / portal / fountain)、action(hide / drop / blast / break / teleport / heal)、x、y |
| dungeon_end | 地下城結束 | day、dungeon、reason(time / down / tutorial)、dur(秒)、captures(種類陣列)、kills、heartsLost、gold |
| setup_done | 開演 | day、roster(上場陣列: species、num、level)、rows(6 列: cue、program, 空為 "") |
| program_fire | 節目發動 | day、row(0~5)、cue、program、elapsed、targets(作用到的隻數) |
| mark_peak | 有一隻標記升到 3 以上 | day、species、num、marks、elapsed |
| show_end | 表演結束 | day、reason(time / loose)、dur(秒)、fame、gold、bestChain、performs(表演總次數)、redPerforms、looseSpecies、looseNum、looseX、looseY(失控時) |
| shop_buy | 商店購買 / 裝備 | day、item、cost、goldLeft |
| upgrade | 個別升級 | day、where(setup / shop)、species、num、level(升級後)、cost |
| dungeon_unlock | 地下城開放 | day、dungeon、fame |
| game_end | 進總結算 | fame、stars、goldEarned、bestChain、days(5 天各去哪)、bankSize |

可算出: 每關(每趟地下城 / 每場表演)通過時間 = dungeon_end.dur、show_end.dur; 失敗次數 = reason 為 down / loose 的次數; 卡關位置 = player_hit、player_down、lasso_break 的座標分布與 show_end 失控時的 elapsed、位置; 每個教學階段出現與完成時間 = tutorial_show / tutorial_done(took)。

## 範圍邊界
- 只做 5 天 + 見習日、4 張固定地圖; 不做存檔(教學完成記錄只留在本次開啟的網頁)
- 怪物庫每隻獨立、個別升級; 不做出售、放生、改名
- 表演中沒有任何操作; 不做馴獸師下場、準星、器材、大招、全場連擊計量
- 節目只看狀態挑對象, 不點名種類; 暗號只看全場
- 場地上不擺任何設施; 魔物開演位置照固定順序, 不做擺位
- 不做門票與觀眾人數; 金幣只來自表演結算與打倒魔物
- 地下城不做小地圖、迷霧、寶箱
- 不支援滑鼠

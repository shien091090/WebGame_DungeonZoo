# 試玩回饋 polish 第 1 輪

日期: 2026-10-15
使用者選擇: continue

## 用詞: 「紅區」改成「生氣」
- 「"紅區"這個用詞會讓人看不懂」; 「紅區狀態我想直白的形容為"生氣",並且不特別區分 生氣 以及 生氣+有標記這兩種狀態」
- 玩家看得到的文字全部改, 規格與程式內的稱呼一併同步:
  | 原本 | 改成 |
  |---|---|
  | 暗號「有人進紅區」 | 「任一怪物生氣」 |
  | 暗號「三隻進紅區」 | 「三隻怪物生氣」 |
  | 節目「冰水桶」: 紅區又沒標記的全部冷靜一點 | 「讓所有生氣的怪物都冷靜一點」; **效果也改**: 生氣狀態不管有沒有標記都會冷靜(「冰水桶這個效果我想改掉, 改成生氣狀態不管有沒有標記都會冷靜」) |
  | 節目「大合奏」: 紅區的全部立刻表演 | 「生氣的怪物全部立刻表演」 |
  | 升級面板「紅區 70~100 → 65~100」 | 「直接隱含的講"更容易進入生氣狀態"這樣就好,不顯示數值」 |
  | 教學「紅區表演 名聲×2」 | 「生氣時表演, 觀眾滿意度×2」 |

## 名稱、天數、結算
- 標題: 「標題"來動物園看一點大場面"改成"來馬戲團看一點大場面"」
- 天數: 「5天的確太短了,改成10天」
- 「"本場名聲"要換個講法,可以改成觀眾滿意度,結算時,觀眾滿意度時會再轉成金幣並加到名聲中」 → 表演中累積的叫「觀眾滿意度」; 結算時換成金幣, 同時加進名聲

## 難度與關卡(新手教學 / 見習日)
- 「新手教學關卡把怪物改成不會攻擊」
- 「跳出"站在他身上別動"時的新手教學提示,顯示上下左右按鍵有點怪,這邊直接寫文字就好」
- 「收服教學過程中(從準備捕捉第一隻到第二隻捕捉完成的整段過程中),左上的捕捉道具可以有一個提示告訴玩家捕捉會花費道具以及有捕捉次數限制這件事情」
- 「地下城新手關卡接到馬戲團新手關卡時,中間要有個過場告訴玩家"讓剛剛抓到的怪物放到場上表演",主要是突然進到選怪物頁面,跳出提示"讓他上場",玩家會搞不清楚接下來要幹嘛,上場是要上什麼場」
- 「見習日設定暗號和表演的地方我希望只開放讓玩家設定第1個跟第2個」
- 「我原本希望初始暗號如果用在教學,要是無論如何都會觸發的暗號,讓玩家體驗暗號連續觸發的感覺,但是"有人進紅區"這個暗號似乎不一定會觸發到,可能要把這個初始暗號改成別的」
- 「初始的兩個表演冰水桶和大合奏都要求怪物要在紅區,我自己體驗的時候怪物都沒有進紅區,所以玩家根本看不到表演,這個也要改掉,見習日的目的就是要讓玩家真的看到觸發了暗號以及觸發了表演」 → 初始暗號與初始節目都要保證見習日一定觸發、一定看得到表演

## 畫面
- 血量: 「把血量從左上角移除掉,改成顯示在角色上方,平時會以半透明顯示,當血量變動(增加或減少)才會變成不透明,並且出現小特效(扣血跟回血需要有不同特效)讓玩家明白血量出現變更」
- 怪物卡片: 「怪物卡片上直接寫"激怒"感覺會誤解成這隻怪本身的狀態,應該把它拿掉, 改成在卡片說明內文中顯示,例如火柴猴的攻擊說明是"丟出會飛回來的火柴,打中會生氣",則"生氣"兩個字可以做成標籤,如同現在怪物卡片上的"激怒"標籤的設計,其他怪物也比照辦理,把攻擊說明中的特定字眼做成特定標籤」
- 升級面板: 「怪物升級面板需要美化,目前全部都是單一顏色的文字,應該做對齊排版,且花費金額/升級前後效果都要在文字上能方便辨識」

## 操作
- 「在進入排暗號和表演頁面時就不能回上一頁了,如果我到這個時候改變主意想回去商店買東西也不行了,需要改掉,能夠返回上一頁」
- 「地下城場景,右上的按鍵操作提示要寫X鍵的武器技是什麼 例如劍是擊暈,長槍是突進,但棍棒沒有武器技,所以棍棒只需顯示Z攻擊就好,不需顯示X武器技,不然光看文字提示會感覺有X可以按但按了沒反應,玩家會以為是BUG」

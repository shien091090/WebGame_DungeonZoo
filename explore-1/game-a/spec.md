# 大場面動物園: 紅線邊緣(貼著失控邊緣拿捏怒氣的刺激)

## 概述
進地下城打魔物、丟網捕獲, 放進動物園籠子讓牠們靠怒氣表演賺名聲; 怒氣在紅線區收益加倍且越撐越多, 但滿了就失控。三天後結算名聲。
驗證假設: H01~H10。

## 核心循環
地下城點魔物攻擊、丟網捕獲 → 把魔物放進籠子開園 → 盯著怒氣條, 把怒氣撐在紅線區、在滿格前點籠子安撫 → 賺到金幣與名聲 → 商店買強化 → 隔天地下城更強的魔物也打得動、抓得到 → 再開園想撐更久的紅線連段。

## 規則

### 流程
1. 開始畫面顯示說明頁(共 5 頁), 點畫面翻頁, 最後一頁點畫面進入第 1 天
2. 每天依序: 地下城 → 擺放 → 開園表演(45 秒)→ 商店; 第 3 天開園結束後不進商店, 直接進結算
3. 結算後點畫面重來, 回到第 1 天地下城(不再顯示說明頁), 所有數值重置

### 地下城
4. 每天地下城有 2 個房間, 每房 3 隻魔物, 種類隨機(4 種之一)
5. 魔物屬性依種類(見數值表), 第 N 天血量 ×(1 + 0.4×(N−1)) 四捨五入, 攻擊 +(N−1)
6. 回合制: 玩家做一個動作(攻擊或丟網)後, 被選中的那隻魔物若還在場, 立刻反擊一次, 玩家扣該魔物攻擊值的血
7. 攻擊: 點一隻魔物, 造成等於玩家攻擊力的傷害; 血量歸零即打倒, 消失並給 3 金幣
8. 丟網: 先點「捕獲網」按鈕進入丟網模式(網數 > 0 才可按, 再按一次取消), 再點一隻魔物丟網, 消耗 1 張網
9. 捕獲成功率 = 30% + 70% ×(1 − 剩餘血量 / 最大血量)+ 網的強化加成, 上限 95%
10. 捕獲成功: 魔物離場, 進入候展區; 失敗: 魔物留在原地並反擊(同規則 6)。丟完一次自動回到攻擊模式
11. 房內魔物全部離場(打倒或捕獲)1 秒後進下一房; 第 2 房清完進入擺放
12. 「回動物園」按鈕隨時可按, 立即結束地下城進入擺放
13. 玩家血量歸零: 立即撤退進入擺放, 已捕獲的魔物保留
14. 每天出發時玩家血量回滿, 網數補到網數上限

### 擺放
15. 畫面有 4 個籠子(2×2)與底部候展區; 魔物在籠子裡才會表演, 籠子跨天保留裡面的魔物
16. 點候展區的魔物選中它, 再點空籠子放入; 點籠中魔物把它退回候展區
17. 擺放階段 HUD 顯示提示「點魔物, 再點空籠子」
18. 按「開園」按鈕開始表演; 沒有魔物也可以開園

### 開園表演(45 秒)
19. 開園時所有籠中魔物怒氣設為 30
20. 怒氣每秒依種類增加(見數值表)
21. 怒氣 0~39: 不表演
22. 怒氣 40~79: 一般表演, 每 3 秒表演一次, 得金幣 = 種類金幣 ×1 ×(1 + 名聲/100), 名聲 +1
23. 怒氣 80~99(紅線區): 每 2 秒表演一次, 倍率依「連續待在紅線區的秒數」: 0~3.9 秒 ×2、名聲 +2; 4~7.9 秒 ×3、名聲 +3; 8 秒以上 ×4、名聲 +4 並標示「大場面」
24. 怒氣一離開紅線區(低於 80 或失控), 連續秒數歸零
25. 安撫: 開園中點有魔物的籠子, 該魔物怒氣 −15(最低 0)
26. 遊客拍玻璃: 每隔 6~10 秒(隨機)挑一個有魔物的籠子, 先預警 1.5 秒, 時間到該魔物怒氣 +20; 預警期間安撫照常有效
27. 怒氣達 100 失控: 籠子變為破損, 魔物離開籠子成為逃脫魔物, 怒氣條隱藏
28. 逃脫魔物以每秒 120 像素走向最近的遊客, 每 2 秒攻擊一次: 名聲 −3, 被攻擊的遊客嚇跑, 3 秒後在原位補回新遊客
29. 點逃脫魔物 3 下抓回: 回到原籠子, 籠子修好, 怒氣 20; HUD 在有逃脫魔物時顯示提示「點牠 3 下抓回」
30. 開園時間到: 還在逃脫的魔物自動抓回原籠, 每隻名聲 −5; 所有破損籠子修好
31. 遊客區固定 6 名遊客, 純表演對象與逃脫魔物的攻擊目標
32. 名聲最低為 0; 金幣以四捨五入取整

### 商店
33. 商店列 4 項強化, 點項目即購買(金幣不足時不能按), 每項可重複購買, 每買一次價格 +50% 四捨五入
34. 按「出發」按鈕進入下一天地下城

### 結算
35. 顯示總名聲、累計賺得金幣、評價星數(名聲 ≥ 60 一星、≥ 120 二星、≥ 200 三星)
36. 點畫面重來

## 操作
只用滑鼠(點擊)。
| 玩家動作 | 操作 |
|---|---|
| 說明翻頁 / 開始 | 點畫面任意處 |
| 攻擊魔物 | 點地下城的魔物 |
| 進入/取消丟網模式 | 點「捕獲網」按鈕 |
| 丟網 | 丟網模式中點魔物 |
| 提早回動物園 | 點「回動物園」按鈕 |
| 選候展魔物 | 點候展區魔物 |
| 放入籠子 | 選中後點空籠子 |
| 退回候展區 | 擺放時點籠中魔物 |
| 開園 | 點「開園」按鈕 |
| 安撫 | 開園中點有魔物的籠子 |
| 抓回逃脫魔物 | 點逃脫魔物(3 下) |
| 購買強化 | 點商店項目 |
| 前往下一天 | 點「出發」按鈕 |
| 重來 | 結算畫面點任意處 |

## 勝負與結束
- 沒有失敗結局; 第 3 天開園結束後進入結算, 以總名聲換評價星數
- 結算畫面點任意處重來, 從第 1 天地下城開始

## 範圍邊界
- 只做一關(3 天), 不做難度曲線、存檔、音效
- 不做魔物升級、籠子擴建、魔物出售
- 不做玩家在地下城移動, 戰鬥只有點擊攻擊與丟網
- 不做遊客人數變化與門票系統, 收益只來自表演

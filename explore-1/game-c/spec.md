# 大場面動物園: 深入一層(地下城再貪一層、控血捕獲稀有魔物的賭博感)

## 概述
地下城一房一房往下走, 越深越容易遇到高星稀有魔物; 用輕擊把魔物控到殘血再丟網, 但倒下會丟光當天抓到的魔物。抓回來的魔物放進籠子靠怒氣表演賺名聲, 星級越高越賺也越暴躁。三天後結算名聲。
驗證假設: H01~H06、H15~H18。

## 核心循環
地下城每清一房決定「再深入一層」或「撤退」→ 對稀有魔物切輕擊慢慢磨血、抓準時機丟網 → 帶回高星魔物放進籠子, 盯怒氣賺錢 → 買強化 → 隔天能撐得更深、抓到更多星的魔物。

## 規則

### 流程
1. 開始畫面顯示說明頁(共 6 頁), 點畫面翻頁, 最後一頁點畫面進入第 1 天
2. 每天依序: 地下城 → 擺放 → 開園表演(45 秒)→ 商店; 第 3 天開園結束後不進商店, 直接進結算
3. 結算後點畫面重來, 回到第 1 天地下城(不再顯示說明頁), 所有數值重置

### 地下城
4. 每天從第 1 層開始, 每層一個房間, 3 隻魔物, 種類隨機(4 種之一), 星級依層數隨機(見數值表)
5. 魔物血量 = 種類血量 × 星級血量倍率 ×(1 + 0.3×(層數−1))×(1 + 0.3×(天數−1)), 四捨五入; 攻擊 = 種類攻擊 + 取整((層數−1)/2)+(天數−1)
6. 底部三個模式按鈕: 「重擊」「輕擊」「捕獲網」, 同時只有一個啟用; 開局為重擊
7. 回合制: 玩家點一隻魔物執行目前模式的動作後, 那隻魔物若還在場, 立刻反擊一次, 玩家扣該魔物攻擊值的血
8. 重擊: 傷害 = 玩家攻擊力; 輕擊: 傷害 = 攻擊力 ÷ 3 四捨五入, 至少 1
9. 魔物血量歸零即打倒, 消失並給 3 × 星級 金幣; 打倒的魔物抓不到
10. 捕獲網模式(網數 > 0 才可選): 點魔物丟網, 消耗 1 張網; 丟完自動回到前一個攻擊模式
11. 捕獲成功率 = 20% + 80% ×(1 − 剩餘血量 / 最大血量)+ 網的強化加成 −(星級 − 1)× 10%, 限制在 5%~95%
12. 捕獲成功: 魔物離場, 放進「今日戰利品」(HUD 顯示數量); 失敗: 魔物留在原地並反擊
13. 房內魔物全部離場後, 出現兩個按鈕「深入一層」「撤退回園」
14. 深入一層: 層數 +1, 進入新房間; 玩家血量**不回復**
15. 「撤退回園」按鈕在戰鬥中也隨時可按; 撤退時今日戰利品全部移到候展區, 進入擺放
16. 玩家血量歸零 = 倒下: 今日戰利品全部失去, 進入擺放, HUD 顯示「倒下了, 今天抓的都跑了」
17. 每天出發時玩家血量回滿, 網數補到網數上限

### 擺放
18. 畫面有 4 個籠子(2×2)與底部候展區; 魔物在籠子裡才會表演, 籠子跨天保留裡面的魔物; 候展區魔物也跨天保留
19. 點候展區的魔物選中它, 再點空籠子放入; 點籠中魔物把它退回候展區
20. 擺放階段 HUD 顯示提示「點魔物, 再點空籠子」
21. 按「開園」按鈕開始表演; 沒有魔物也可以開園

### 開園表演(45 秒)
22. 開園時所有籠中魔物怒氣設為 30
23. 怒氣每秒增加 = 種類怒氣速度 × 星級怒氣倍率
24. 怒氣 0~39: 不表演
25. 怒氣 40~79: 每 3 秒表演一次, 得金幣 = 種類金幣 × 星級金幣倍率 ×(1 + 名聲/100), 名聲 + 星級
26. 怒氣 80~99: 每 2 秒表演一次, 金幣再 ×2, 名聲 + 星級 × 2
27. 安撫: 開園中點有魔物的籠子, 該魔物怒氣 −25(最低 0)
28. 怒氣達 100 失控: 籠子變為破損, 魔物離開籠子成為逃脫魔物
29. 逃脫魔物以每秒 120 像素走向最近的遊客, 每 2 秒攻擊一次: 名聲 −3 × 星級, 被攻擊的遊客嚇跑, 3 秒後在原位補回新遊客
30. 點逃脫魔物 3 下抓回: 回到原籠子, 籠子修好, 怒氣 20; HUD 在有逃脫魔物時顯示提示「點牠 3 下抓回」
31. 開園時間到: 還在逃脫的魔物自動抓回原籠, 每隻名聲 −5; 所有破損籠子修好
32. 遊客區固定 6 名遊客
33. 名聲最低為 0; 金幣以四捨五入取整

### 商店
34. 商店列 4 項強化, 點項目即購買(金幣不足時不能按), 每項可重複購買, 每買一次價格 +50% 四捨五入
35. 按「出發」按鈕進入下一天地下城

### 結算
36. 顯示總名聲、累計賺得金幣、最深層數、抓過的最高星級、評價星數(名聲 ≥ 60 一星、≥ 120 二星、≥ 200 三星)
37. 點畫面重來

## 操作
只用滑鼠(點擊)。
| 玩家動作 | 操作 |
|---|---|
| 說明翻頁 / 開始 | 點畫面任意處 |
| 切換重擊 / 輕擊 / 捕獲網 | 點對應的模式按鈕 |
| 攻擊或丟網 | 點地下城的魔物 |
| 深入一層 | 清房後點「深入一層」按鈕 |
| 撤退 | 點「撤退回園」按鈕(隨時) |
| 選候展魔物 | 點候展區魔物 |
| 放入籠子 | 選中後點空籠子 |
| 退回候展區 | 擺放時點籠中魔物 |
| 開園 | 點「開園」按鈕 |
| 安撫 | 開園中點有魔物的籠子 |
| 抓回逃脫魔物 | 點逃脫魔物(3 下) |
| 購買強化 | 點商店項目 |
| 前往下一天 | 點「出發」按鈕 |
| 重來 | 結算畫面點任意處 |

## 勝負與結束
- 沒有失敗結局(地下城倒下只失去當天戰利品); 第 3 天開園結束後進入結算, 以總名聲換評價星數
- 結算畫面點任意處重來, 從第 1 天地下城開始

## 範圍邊界
- 只做一關(3 天), 不做難度曲線、存檔、音效
- 不做紅線區連段倍率、接力連鎖(分別是 A、B 款的機制)
- 不做地下城地圖、移動、道具欄; 層與層之間沒有回血點
- 不做魔物升級、出售、籠子擴建

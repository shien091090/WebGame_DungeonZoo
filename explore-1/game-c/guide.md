# 大場面動物園: 深入一層 — 玩家說明

翻頁: 點畫面任意處翻下一頁; 最後一頁點畫面開始遊戲。每頁底部小字「點畫面繼續」。

## 第 1 頁 目標
- 文字: 經營三天, 衝高名聲
- 圖要示意: 動物園裡籠中魔物在表演、遊客圍觀, HUD 的名聲數字往上跳; 角落標「第 1~3 天」

## 第 2 頁 地下城戰鬥
- 文字: 選重擊或輕擊, 再點魔物
- 圖要示意: 底部「重擊」「輕擊」兩個按鈕; 手指點魔物, 重擊那邊血條掉一大截、輕擊那邊只掉一小格

## 第 3 頁 捕獲
- 文字: 血越少越好抓, 打死就沒了
- 圖要示意: 三隻同種魔物並排 — 滿血丟網打叉、殘血丟網打勾、血條歸零倒下的打叉; 「捕獲網」按鈕亮著

## 第 4 頁 深入或撤退
- 文字: 越深越稀有, 倒下全丟光
- 圖要示意: 清完房間後出現的「深入一層」「撤退回園」兩個按鈕; 深入那側畫出帶星星的魔物, 旁邊一個倒下的玩家, 戰利品散掉(打叉)

## 第 5 頁 怒氣與表演
- 文字: 怒氣越高, 表演越賺
- 圖要示意: 兩個籠子對比 — 怒氣條低的魔物趴著不動; 怒氣條高的魔物在放技能、金幣飛出

## 第 6 頁 安撫與失控
- 文字: 點籠子安撫, 滿了會失控
- 圖要示意: 左: 手指點籠子, 怒氣條往下降; 右: 怒氣條全滿的籠子破掉, 魔物衝向遊客(打叉)

## 自查(對照 spec「操作」)
| 動作 | 出現在 |
|---|---|
| 翻頁 / 開始 | 頁首說明 |
| 切換重擊 / 輕擊、攻擊 | 第 2 頁 |
| 切換捕獲網、丟網 | 第 3 頁 |
| 深入一層、撤退 | 第 4 頁 |
| 選候展魔物、放入籠子、退回 | 擺放時 HUD 提示「點魔物, 再點空籠子」 |
| 開園、出發 | 按鈕本身有文字 |
| 安撫 | 第 6 頁 |
| 抓回逃脫魔物 | 失控時 HUD 提示「點牠 3 下抓回」 |
| 購買強化 | 商店畫面項目可點, 遊戲當下可見 |
| 重來 | 結算畫面顯示「點畫面重來」 |
| 結束條件 | 第 1 頁「三天」 |

不寫: 星級對收益與怒氣速度的影響(籠子上看得到星級, 表演時金幣自己會說話)、層與層之間不回血(HUD 血條看得到)、「用輕擊磨到殘血再丟網」這個打法(本款要驗玩家會不會自己想到)。

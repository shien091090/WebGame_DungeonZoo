## 形狀語言
圓角 + 深色描邊 + 扁平填色; 魔物是 Q 版剪影, 每種剪影不同。**白色八角爆星 = 受擊**、**紅色鋸齒外圈 = 危險(全遊戲只有逃脫魔物有)**、**白粗框 + 四角括號 = 選中**、**青色 = 接力**、**薄荷綠內收 = 安撫**。

## 理念落實
- P0 辨識度先於好看: 四種魔物同時用剪影(蜥蜴 / 鳥 / 水母 / 石像鬼)和色相 + 灰階區分; 籠子三種狀態(不表演 / 可表演 / 表演中)姿勢不一樣(趴睡 / 站立 / 撐大)。
- P1 視覺權重跟決策迫切度走: 開園中最該盯的是怒氣條(要不要安撫)和逃脫魔物, 所以只有怒氣 ≥ 80 和逃脫魔物會閃紅; 「大場面」字幕不放畫面正中央, 改放在遊客區那一帶, 不蓋到上排籠子的怒氣條和接力圖。
- P2 規則上存在的東西, 畫面上就必須存在: 表演門檻 50 在每條怒氣條上都畫成白色刻度; 破損籠留著原主的淡影(抓回後會回到這裡); 逃脫魔物底下的 3 顆點 = 還要點幾下。
- P3 一個意義一種長相: 魔物本體在地下城、籠子、候展區、接力圖、逃脫、說明頁全部用同一個畫法; 金幣 = 黃硬幣、名聲 = 粉星, HUD、飄字、結算都一樣。
- P4 關鍵區分至少走兩條感知通道: 可不可以表演 = 姿勢(趴睡 vs 站立) + 聚光燈; 表演中 = 青色粗框 + 第幾棒徽章 + 特效; 危險 = 紅 + 鋸齒或閃爍。
- P7 每個元素都要掙得它的版面: 籠子上不寫怒氣數字(條 + 刻度就夠); 接力連線上不再標第幾棒(籠角已經有)。
- P9 以最混亂的那一刻驗收: 6 籠同時表演 + 接力連線 + 逃脫魔物時, 怒氣條在籠底那一帶有深色襯底, 而且全部疊在特效上面, 讀得到; 特效都剪在各自的籠框內, 不會溢到隔壁籠。
- P13 事件要排隊: 美術只負責單一事件的進場和退場(大場面 1.8 秒、表演特效 1 秒、飄字 1 秒); 同時有多少則由 RD 決定。大場面字幕全畫面只有一份。
- P15 回饋強度跟事件份量成正比: 表演特效的粒子數、光環粗細跟著第幾棒變大, 第 3 棒起多加金色星光; 大場面是全遊戲唯一帶放射光和緞帶的演出。
- P17 進度類資訊圖形與數字分工: 怒氣只畫條不寫數字, 刻度標出決策點(50 會表演、80 起變紅); 開園時間只寫數字(倒數 10 秒起變色)。
- P18 重要資訊不能只存在一瞬間: 金幣 / 名聲飄字一閃就消失, 但數值會留在 HUD 上; 最長連鎖會留到結算畫面。
- P19 資訊盡量貼著它描述的物件: 怒氣條、第幾棒徽章、安撫箭頭都長在籠子身上; 野生魔物的血條在頭頂, 抓回逃脫魔物的點數就在牠腳下。
- P21 示意圖要選對錯理解會分岔的例子: 說明第 3 頁並排「滿血丟網 ✗」和「殘血丟網 ✓」; 第 4 頁並排低怒氣趴睡和過半在表演; 第 5 頁接力圖亮的是雷鳥, 也就是「下一種」, 而不是火蜥蜴本身。

### 說明頁示意圖(page 0 起算)
0. 目標: 兩個籠子在表演 + 6 名遊客; 左上「第 1~3 天」; 右上是 HUD 同款的名聲讀數「48」+ 飄字「+3」

## 取捨說明(給製作人驗收)
- **大場面字幕的位置**: interface.json 寫「畫在畫面中央」, 但畫面正中央 y=640 正好是下排籠子, 上下排之間只有 40px, 放哪裡都會蓋到上排的怒氣條(y 378~394)。大場面發生時正是要盯怒氣、準備安撫的時候(P1), 所以改放在遊客區正中(360, 905): 水平置中、仍在畫面中段, 演出上也像觀眾在歡呼。代價是會短暫(1.8 秒)蓋到遊客和可能經過的逃脫魔物。
- **時長常數**: 表演特效 1.0 秒、接力連線 0.4 秒長滿(對應規格的接力延遲 0.4 秒)+ 留到 1.0 秒、大場面 1.8 秒、飄字 1.0 秒。美術只看 t, 超過就不畫; RD 可以在超過後移除物件。
- **火蜥蜴橘和怒氣橘紅**色相接近(29° vs 15°), 但一個是魔物剪影、一個是籠底的條, 物件類別不同, 不會擺在同一個位置。

# 大場面動物園: 連鎖大場面 — 玩家說明

翻頁: 點畫面任意處翻下一頁; 最後一頁點畫面開始遊戲。每頁底部小字「點畫面繼續」。

## 第 1 頁 目標
- 文字: 經營三天, 衝高名聲
- 圖要示意: 動物園裡籠中魔物在表演、遊客圍觀, HUD 的名聲數字往上跳; 角落標「第 1~3 天」

## 第 2 頁 地下城戰鬥
- 文字: 點魔物攻擊
- 圖要示意: 地下城三隻魔物, 手指點其中一隻, 那隻受擊、血條減少; 下方是玩家角色

## 第 3 頁 捕獲
- 文字: 按捕獲網, 再點魔物
- 圖要示意: 兩格連續畫面 — 「捕獲網」按鈕被按亮 → 網丟向一隻血條很低的魔物, 魔物被收進候展區。旁邊對照: 滿血魔物丟網打叉、殘血魔物丟網打勾

## 第 4 頁 怒氣與表演
- 文字: 怒氣夠高才會表演
- 圖要示意: 兩個籠子對比 — 怒氣條低的魔物趴著不動; 怒氣條過半的魔物在放技能、金幣飛出

## 第 5 頁 接力
- 文字: 照接力圖相鄰, 會接著演
- 圖要示意: 遊戲內的接力圖(四種魔物循環箭頭); 下方兩個左右相鄰的籠子, 火蜥蜴表演後連線傳到隔壁雷鳥也表演

## 第 6 頁 安撫與失控
- 文字: 點籠子安撫, 滿了會失控
- 圖要示意: 左: 手指點籠子, 怒氣條往下降; 右: 怒氣條全滿的籠子破掉, 魔物衝向遊客(打叉)

## 自查(對照 spec「操作」)
| 動作 | 出現在 |
|---|---|
| 翻頁 / 開始 | 頁首說明 |
| 攻擊魔物 | 第 2 頁 |
| 進入丟網模式、丟網 | 第 3 頁 |
| 取消丟網模式、提早回動物園 | 按鈕本身有文字, 遊戲當下可見 |
| 選候展魔物、放入籠子、退回 | 擺放時 HUD 提示「點魔物, 再點空籠子」 |
| 開園、出發 | 按鈕本身有文字 |
| 安撫 | 第 6 頁 |
| 抓回逃脫魔物 | 失控時 HUD 提示「點牠 3 下抓回」 |
| 購買強化 | 商店畫面項目可點, 遊戲當下可見 |
| 重來 | 結算畫面顯示「點畫面重來」 |
| 結束條件 | 第 1 頁「三天」 |

第 5 頁只講接力「是什麼」(規則), 示意圖只畫兩籠; 不畫三籠以上的長連鎖、不提連鎖越長越賺、不提被帶動會漲怒氣 — 排長陣型與「爽完救火」是本款要驗玩家自己發現的行為。

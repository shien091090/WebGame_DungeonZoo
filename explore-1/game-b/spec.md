# 大場面動物園: 連鎖大場面(排陣型後一次引爆連鎖表演的爽快)

## 概述
進地下城打魔物、丟網捕獲, 放進 6 個籠子; 相鄰籠子裡「接得上」的魔物會接力表演, 連得越長賺越多, 但被帶動的魔物怒氣也跟著飆。三天後結算名聲。
驗證假設: H01~H06、H11~H14。

## 核心循環
地下城捕獲各種魔物 → 擺放時想好誰挨著誰 → 開園看一隻表演帶動整排接力「大場面」→ 趕快安撫被帶得太激動的魔物 → 賺金幣買強化 → 隔天抓到更多種類, 回來排出更長的連鎖。

## 規則

### 流程
1. 開始畫面顯示說明頁(共 6 頁), 點畫面翻頁, 最後一頁點畫面進入第 1 天
2. 每天依序: 地下城 → 擺放 → 開園表演(50 秒)→ 商店; 第 3 天開園結束後不進商店, 直接進結算
3. 結算後點畫面重來, 回到第 1 天地下城(不再顯示說明頁), 所有數值重置

### 地下城
4. 每天地下城有 2 個房間, 每房 3 隻魔物, 種類隨機(4 種之一)
5. 魔物屬性依種類(見數值表), 第 N 天血量 ×(1 + 0.4×(N−1)) 四捨五入, 攻擊 +(N−1)
6. 回合制: 玩家做一個動作(攻擊或丟網)後, 被選中的那隻魔物若還在場, 立刻反擊一次, 玩家扣該魔物攻擊值的血
7. 攻擊: 點一隻魔物, 造成等於玩家攻擊力的傷害; 血量歸零即打倒, 消失並給 3 金幣
8. 丟網: 先點「捕獲網」按鈕進入丟網模式(網數 > 0 才可按, 再按一次取消), 再點一隻魔物丟網, 消耗 1 張網
9. 捕獲成功率 = 30% + 70% ×(1 − 剩餘血量 / 最大血量)+ 網的強化加成, 上限 95%
10. 捕獲成功: 魔物離場, 進入候展區; 失敗: 魔物留在原地並反擊(同規則 6)。丟完一次自動回到攻擊模式
11. 房內魔物全部離場 1 秒後進下一房; 第 2 房清完進入擺放
12. 「回動物園」按鈕隨時可按, 立即結束地下城進入擺放
13. 玩家血量歸零: 立即撤退進入擺放, 已捕獲的魔物保留
14. 每天出發時玩家血量回滿, 網數補到網數上限

### 擺放
15. 畫面有 6 個籠子(3 欄 × 2 列)與底部候展區; 籠子跨天保留裡面的魔物
16. 點候展區的魔物選中它, 再點空籠子放入; 點籠中魔物把它退回候展區
17. 擺放階段 HUD 顯示提示「點魔物, 再點空籠子」
18. 籠子區下方常駐「接力圖」: 火蜥蜴 → 雷鳥 → 水母 → 石像鬼 → 火蜥蜴 的循環箭頭, 開園中也顯示
19. 按「開園」按鈕開始表演; 沒有魔物也可以開園

### 開園表演(50 秒)
20. 開園時所有籠中魔物怒氣設為 30
21. 怒氣每秒依種類增加(見數值表)
22. 怒氣 ≥ 50 的魔物會表演: 達到 50 起每 4 秒自己表演一次(各自計時)
23. 接力: 一隻魔物表演時, 檢查上下左右相鄰的籠子, 裡面若是接力圖上「下一種」魔物且怒氣 ≥ 50, 0.4 秒後它也表演, 並以它為起點繼續往下檢查; 同一次連鎖中每隻魔物最多表演一次; 同時有多個相鄰符合時全部接上(分支)
24. 連鎖中第 k 隻表演(起點為第 1 隻)得金幣 = 種類金幣 × k ×(1 + 名聲/100), 名聲 +k
25. 一次連鎖達 3 隻以上, 額外名聲 +5 並標示「大場面」
26. 被接力帶動表演的魔物(第 2 隻起)怒氣 +15; 被接力表演後, 牠自己的 4 秒計時重新開始
27. 安撫: 開園中點有魔物的籠子, 該魔物怒氣 −30(最低 0)
28. 怒氣達 100 失控: 籠子變為破損, 魔物離開籠子成為逃脫魔物; 破損籠子不參與接力
29. 逃脫魔物以每秒 120 像素走向最近的遊客, 每 2 秒攻擊一次: 名聲 −3, 被攻擊的遊客嚇跑, 3 秒後在原位補回新遊客
30. 點逃脫魔物 3 下抓回: 回到原籠子, 籠子修好, 怒氣 20; HUD 在有逃脫魔物時顯示提示「點牠 3 下抓回」
31. 開園時間到: 還在逃脫的魔物自動抓回原籠, 每隻名聲 −5; 所有破損籠子修好
32. 遊客區固定 6 名遊客
33. 名聲最低為 0; 金幣以四捨五入取整

### 商店
34. 商店列 4 項強化, 點項目即購買(金幣不足時不能按), 每項可重複購買, 每買一次價格 +50% 四捨五入
35. 按「出發」按鈕進入下一天地下城

### 結算
36. 顯示總名聲、累計賺得金幣、最長連鎖數、評價星數(名聲 ≥ 60 一星、≥ 120 二星、≥ 200 三星)
37. 點畫面重來

## 操作
只用滑鼠(點擊)。
| 玩家動作 | 操作 |
|---|---|
| 說明翻頁 / 開始 | 點畫面任意處 |
| 攻擊魔物 | 點地下城的魔物 |
| 進入/取消丟網模式 | 點「捕獲網」按鈕 |
| 丟網 | 丟網模式中點魔物 |
| 提早回動物園 | 點「回動物園」按鈕 |
| 選候展魔物 | 點候展區魔物 |
| 放入籠子 | 選中後點空籠子 |
| 退回候展區 | 擺放時點籠中魔物 |
| 開園 | 點「開園」按鈕 |
| 安撫 | 開園中點有魔物的籠子 |
| 抓回逃脫魔物 | 點逃脫魔物(3 下) |
| 購買強化 | 點商店項目 |
| 前往下一天 | 點「出發」按鈕 |
| 重來 | 結算畫面點任意處 |

## 勝負與結束
- 沒有失敗結局; 第 3 天開園結束後進入結算, 以總名聲換評價星數
- 結算畫面點任意處重來, 從第 1 天地下城開始

## 範圍邊界
- 只做一關(3 天), 不做難度曲線、存檔、音效
- 不做紅線區倍率(那是 A 款的機制), 表演只分「表演 / 不表演」
- 不做魔物升級、籠子擴建、籠子拖曳換位(只能退回候展區再放)
- 不做玩家在地下城移動, 戰鬥只有點擊攻擊與丟網

# 彈反引爆秀(表演場彈反反射點燃 + 收服加成)

## 概述
全程只用鍵盤。地下城是有房間與地形的捲動地圖: 方向鍵走位、Z 朝面向揮鞭、X 翻滾、C 在被打中的瞬間彈反; 把魔物打到殘血後, 再揮一鞭套上套索, 要在時限內繞著牠跑一整圈才收服, 繞的途中魔物照樣出招, 被打中套索就斷。表演場上馴獸師下場, Z 揮鞭激怒、X 吹哨安撫, 魔物在場上自由走動、技能互相點燃, 怒氣在 80~99 的紅線區表演金幣加倍。**本款的新機制**: 表演場上抓準時機彈反魔物的技能, 會把那一招的元素反射成一圈衝擊波, 範圍內的魔物依元素升怒或降怒, 夠氣的立刻接著表演——馴獸師站在火場中央親手引爆連鎖; 同種魔物再收服會給馴獸師該種的「收服加成」(火蜥蜴鞭更大、水母哨更大、雷鳥彈反時機更寬、石像鬼心更多)。三天後依名聲評星。
驗證假設: H01~H06、H24、H50、H51、H77、H78、H99~H101、H105~H107。

## 核心循環
在地形房間裡閃招、揮鞭把想要的魔物打到殘血, 套上套索邊閃邊繞一圈收服 → 新種補進陣容, 同種變成馴獸師的加成 → 表演場上用鞭把魔物推進紅線, 走進魔物群中央等技能飛來, 彈反成衝擊波一次點燃整群, 快爆的用哨壓回來 → 賺金幣與名聲 → 買強化 → 隔天抓更硬的魔物、反射出更大的連鎖。

## 規則

### 流程
1. 開始畫面顯示說明頁(共 5 頁), 按 Z 翻頁, 最後一頁按 Z 進入第 1 天
2. 每天依序: 地下城(60 秒)→ 表演場(50 秒)→ 商店; 第 3 天表演結束後不進商店, 直接進結算
3. 地下城與表演場開始前各有一張標題卡(「第 N 天 地下城」/「第 N 天 表演場」), 按 Z 開始
4. 開局陣容: 火蜥蜴; 四種收服加成都是 0 級
5. 結算後按 Z 重來, 回到第 1 天地下城(不再顯示說明頁), 所有數值重置

### 地下城(即時, 60 秒)
9. 方向鍵移動馴獸師, 可斜走(同時按兩個方向, 速度不變); 放開就停。面向 = 最後一次移動的方向(8 方向)
10. 撞牆 / 石柱會被擋住(圓形判定半徑 18, 可沿牆滑動); 站在水上移速減半; 碰到熔岩算被打中一次(熔岩不能彈反, 翻滾中不受傷)
11. 按 Z: 揮鞭——以馴獸師為中心、朝面向張開 120° 的扇形、半徑內的所有魔物都被抽到; 有冷卻。翻滾中、套索中不能揮鞭
12. 按 X: 翻滾——朝面向以高速衝刺一小段, 翻滾期間無敵(不受技能與熔岩傷害); 有冷卻。翻滾中不能揮鞭
13. 按 C: 舉盾——按下起「彈反時機」(基本 0.2 秒, 雷鳥加成每級 +0.05 秒)內; 盾冷卻 0.6 秒(從按下算)。彈反時機內被技能打中 → 彈反: 不扣心、不進受擊無敵, 施放這招的魔物受到反擊傷害(等於鞭力, 但最多扣到剩 1 血; 同一次施放只算一次, 水彈 3 發彈到幾發都只算一次); 畫面出現彈反閃光。舉盾時仍可移動
14. 每個巢穴開局各生 1 隻該種魔物; 魔物被收服或打倒後, 該巢穴 8 秒後再生 1 隻
15. 魔物血量 = 基本血量 ×(1 + 0.5×(天數 − 1)) 四捨五入
16. 魔物在自己的房間內以低速隨機走動(每 2~3 秒換方向), 撞牆轉向, 不會離開房間
17. 馴獸師與魔物距離 < 400 時, 魔物依種類的間隔施放攻擊技能(見「技能表」); 技能與表演場上的表演技能完全相同
18. 魔物血量 ≤ 最大值 30%: 變「殘血」——身上冒出虛弱記號, 繼續走動與施放技能(施放間隔 ×1.5)
19. 被鞭抽到的魔物:
    - 殘血、捕獸繩 > 0、目前沒有別隻被套住 → 套上套索(不扣血, 不消耗繩), 進入「套索中」(見下節)
    - 其他情況 → 扣等於鞭力的血; 有受擊閃白
20. 血量歸零: 打倒, 魔物消失, 得金幣
21. 被技能打中(沒彈反、沒翻滾): 扣 1 顆心, 之後無敵 1 秒(閃爍)
22. 心歸零或 60 秒到: 地下城結束, 進表演場; 已收服的保留
23. 每天出發時心補滿、捕獸繩補到上限, 馴獸師回到起點、面向上

### 套索收服(地下城)
24. 套索中: 馴獸師與被套的魔物之間畫一條繩; 魔物停止隨機走動, 改以 40 像素/秒朝牠房間的中心移動, 到了就停在原地掙扎; 照常施放技能(殘血間隔)
25. 繞圈進度: 每幀計算「馴獸師相對魔物的角度」變化量(取 −180°~180°), 累加成有正負號的總和; 進度 = |總和| / 360°。順時針、逆時針都算, 中途反方向會倒扣
26. 進度達 1(繞滿一圈): 收服——繩 −1, 魔物離場, 飄字「收服!」
27. 以下任一情況套索斷掉(魔物維持殘血, 回到隨機走動; 可再揮鞭重新套, 進度從 0 開始):
    - 套索計時達 5 秒
    - 馴獸師與魔物距離 > 220
    - 馴獸師被技能或熔岩打中(彈反、翻滾無敵時不算)
28. 套索中可以移動、翻滾、彈反, 不能揮鞭
29. 收服時: 陣容裡沒有此種 → 新加入; 已有此種 → 該種的收服加成 +1 級(最多 3), 立刻生效, 飄字加成名稱(如「鞭範圍↑」); 已是 3 級 → 換成金幣 20, 飄字「+20」

### 表演場(即時, 50 秒)
30. 場地與觀眾席: 上下兩側觀眾席, 各一排 6 段圍欄與 6 名觀眾(版面見數值表)
31. 陣容所有魔物都在場內(每種一隻), 開演時隨機分散站位, 各自低速隨機走動(碰邊界轉向); 怒氣全部設為 20
32. 方向鍵移動馴獸師(限場地內), 速度同地下城
33. 按 Z: 揮鞭——以馴獸師為中心的整圈範圍(表演場不分面向), 範圍內的魔物(不含失控中)怒氣增加, 增加量依種類(見種類表); 冷卻同地下城
34. 按 X: 吹哨——以馴獸師為中心、哨音半徑內的魔物怒氣 −30(不含失控中; 失控中的見第 46 條); 有冷卻
35. 按 C: 舉盾——時機與冷卻同地下城
36. **表演場彈反 = 反射衝擊波**: 彈反時機內被技能碰到 → 不暈眩、不扣名聲, 並在馴獸師位置放出一圈反射波(半徑 160), 元素同被彈反的那一招:
    - 範圍內每隻魔物(不含失控中、衝欄中, 含施放者自己)怒氣變化: 火圈、落雷、震波 +15; 水彈 −20
    - 變化後怒氣在 50~99 的魔物 → 立刻表演一次(不等表演間隔, 之後表演計時從 0 重算); 這次表演照常算金幣、會打中別隻造成連鎖
    - 變化後達 100 → 照常失控
    - 每打中 1 隻: 金幣 +2 ×(1 + 名聲/100); 每次反射: 名聲 +1; 飄字「彈反 ×N」(N = 打中隻數)
    - 同一招只會被反射一次(水彈 3 發只算第一發, 其餘碰到盾直接消失)
37. 怒氣每秒自然下降, 下降量依種類; 最低 0、最高 100
38. 怒氣 < 50: 不表演
39. 怒氣 ≥ 50: 定時表演, 間隔從 3 秒(怒氣 50)線性縮短到 1 秒(怒氣 99); 表演時放出該種技能(見技能表), 瞄準對象是馴獸師
40. 怒氣 80~99 是「紅線區」: 怒氣條上標出這一段; 在紅線區表演的金幣 ×2, 飄字加註「紅線 ×2」
41. 每次表演得金幣 = 種類金幣 ×(1 + 0.5 × 這次技能打中的其他魔物數)×(紅線區 2, 否則 1)×(1 + 名聲/100) 四捨五入; 名聲 + 種類名聲
42. 技能打中其他魔物(不含失控中、不含施放者自己), 每次生效改變牠的怒氣: 火圈、落雷、震波 +15; 水彈 −20。同一個技能對同一隻魔物只算一次
43. 技能碰到馴獸師(沒彈反) → 暈眩 1.5 秒(不能揮鞭、吹哨、舉盾, 仍可移動)、名聲 −2, 之後無敵 2 秒(無敵期間技能穿過馴獸師, 不能彈反)
44. 怒氣達 100: 失控——以衝刺速度衝向最近那側觀眾席的圍欄, 撞 1.5 秒後圍欄破掉, 進觀眾席沿座位排左右來回奔跑, 每 1.5 秒攻擊身邊的觀眾一次: 名聲 −3, 被攻擊的觀眾嚇跑, 4 秒後補回
45. 失控魔物(含衝欄中)不表演、不受揮鞭、技能與反射波影響
46. 失控魔物每被哨音罩到一次, 制伏進度 +1(魔物頭上顯示 0/3~3/3); 達 3: 魔物回場地中央、怒氣 30、進度歸零, 該段圍欄修好
47. 有魔物失控時, HUD 訊息顯示「追上去吹哨 3 次」
48. 50 秒到: 仍失控的每隻名聲 −5; 圍欄全部修好
49. 名聲最低 0; 金幣四捨五入取整

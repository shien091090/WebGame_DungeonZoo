# 紅線連擊秀 — 玩家說明

翻頁: 按 Z 翻下一頁; 最後一頁按 Z 開始遊戲。每頁底部小字「按 Z 繼續」。

## 第 1 頁 地下城
- 文字: 方向鍵走, Z 揮鞭, X 翻滾, C 彈反
- 圖要示意: 地下城一角, 馴獸師朝右揮出扇形鞭打中一隻火蜥蜴; 旁邊一個馴獸師殘影翻滾穿過火圈; 另一個馴獸師舉盾, 水彈打在盾上閃光、彈回施放的水母。畫面下方四個鍵帽「方向鍵 / Z / X / C」各對應「走 / 揮鞭 / 翻滾 / 彈反」

## 第 2 頁 收服
- 文字: 殘血時揮鞭套住, 繞牠一圈
- 圖要示意: 一隻帶虛弱記號的魔物被套索連到馴獸師, 馴獸師沿一條繞著魔物的箭頭路線跑, 魔物周圍的進度環填到一半; 角落小圖: 進度環填滿, 魔物被收走(打勾)

## 第 3 頁 表演
- 文字: Z 讓牠生氣, X 讓牠冷靜
- 圖要示意: 表演場上兩個情境並排 — 左: 一圈鞭打範圍, 圈內魔物怒氣條往上、放出技能、金幣飛出; 右: 一圈哨音範圍, 圈內魔物怒氣條往下

## 第 4 頁 紅線
- 文字: 紅線連著演越賺, 一失控就歸零
- 圖要示意: 上: 兩隻魔物的怒氣條都在紅線段, 輪流表演, 畫面底部連擊顯示從「連擊 3」跳到「連擊 4」、倍率變大; 下: 一隻魔物怒氣條全滿、撞破圍欄撲向觀眾(打叉), 連擊顯示變成「連擊中斷」。最下方小字流程「地下城 → 表演場 → 商店, 三天後評星」

## 自查(對照 spec「操作」)
| 動作 | 出現在 |
|---|---|
| 翻頁 / 開始 / 標題卡開始 | 頁首說明; 標題卡顯示「按 Z 開始」 |
| 移動馴獸師 | 第 1 頁(表演場同樣用方向鍵, 第 3 頁圖中示意; 繞圈在第 2 頁) |
| 揮鞭(打魔物) | 第 1 頁 |
| 揮鞭(殘血套索)、繞圈收服 | 第 2 頁 |
| 翻滾 | 第 1 頁 |
| 彈反(地下城、表演場) | 第 1 頁 |
| 揮鞭(激怒)、吹哨(安撫) | 第 3 頁 |

| 商店選項目 / 購買 / 出發 | 第 4 頁流程; 商店畫面底部顯示「↑↓ 選擇 Z 確定」 |
| 重來 | 結算畫面顯示「按 Z 重來」 |
| 結束條件 | 第 4 頁 |

不寫: 套索的時限、長度與被打中會斷(套住後進度環與繩子繃緊看得出來, 斷了當下就懂); 技能會打到其他魔物、改變牠們的怒氣(要驗玩家會不會自己發現並利用連鎖); 連擊計時的秒數與倍率算法(連擊顯示上有計時條與倍率); 同種再收服會提高馴熟度、紅線區變寬(收服當下有「馴熟 +1」飄字, 上場時怒氣條看得出紅線段變長); 各種魔物對揮鞭的反應不同(要驗玩家能否自己感受到差異); 熔岩與水的效果(一踩就懂); 彈反在表演場也能用來免暈(第 1 頁已教彈反, 表演場碰到自然會試); 魔物在地下城的攻擊就是表演技能(要驗玩家會不會自己連起來)。

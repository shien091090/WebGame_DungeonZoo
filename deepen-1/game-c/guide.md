# 習性大招秀 — 玩家說明

翻頁: 按 Z 翻下一頁; 最後一頁按 Z 開始遊戲。每頁底部小字「按 Z 繼續」。

## 第 1 頁 地下城
- 文字: 方向鍵走, Z 揮鞭, X 翻滾, C 彈反
- 圖要示意: 地下城一角, 馴獸師朝右揮出扇形鞭打中一隻火蜥蜴; 旁邊一個馴獸師殘影翻滾穿過火圈; 另一個馴獸師舉盾, 水彈打在盾上閃光、彈回施放的水母。畫面下方四個鍵帽「方向鍵 / Z / X / C」各對應「走 / 揮鞭 / 翻滾 / 彈反」

## 第 2 頁 收服
- 文字: 殘血時揮鞭套住, 繞牠一圈
- 圖要示意: 一隻帶虛弱記號的魔物被套索連到馴獸師, 馴獸師沿一條繞著魔物的箭頭路線跑, 魔物周圍的進度環填到一半; 角落小圖: 進度環填滿, 魔物被收走(打勾)

## 第 3 頁 表演
- 文字: Z 讓牠生氣, X 讓牠冷靜
- 圖要示意: 表演場上兩個情境並排 — 左: 一圈鞭打範圍, 圈內魔物怒氣條往上、放出技能、金幣飛出; 右: 一圈哨音範圍, 圈內魔物怒氣條往下

## 第 4 頁 拿捏
- 文字: 越氣越賺, 滿了就失控
- 圖要示意: 一條怒氣條由左到右, 靠右的紅線段旁一隻魔物放出特別大的技能、飛出大量金幣; 條的最右端(全滿)連到一隻撞破圍欄撲向觀眾的魔物(打叉); 下方小字流程「地下城 → 表演場 → 商店, 三天後評星」

不寫: 各種魔物的移動習性、而且地下城與表演場一致(要驗玩家會不會自己察覺並拿來擺局); 紅線區表演範圍變大(第 4 頁圖中技能畫得特別大, 不另寫字; 打到別隻的後果留給玩家碰到); 技能會打到其他魔物、改變牠們的怒氣(要驗玩家會不會自己發現並利用連鎖); 上場名額與後台替補、冷掉下場(第一天只有一兩隻用不到; 後台畫面底部看得到排隊, 換人當下有「上場 / 下場」飄字); 套索的時限、長度與被打中會斷(套住後進度環與繩子繃緊看得出來); 各種魔物對揮鞭的反應不同(要驗玩家能否自己感受到差異); 熔岩與水的效果(一踩就懂)。

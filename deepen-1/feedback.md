# 試玩回饋 deepen-1

日期: 2026-10-13
使用者選擇: continue

## 使用者指定的改動(下一輪每款都必須有)

### 1. 操作: 方向鍵 + Z、X 兩鍵
- 「基本上我希望讓這整個遊戲,除了上下左右方向鍵以外,控制在2個鍵就能做全部的事情,就是z跟x, 這兩個鍵在戰鬥過程中用於武器上, 所以我希望捕捉這個過程不要用z或x來觸發」

### 2. 武器(商店可購買), 翻滾 / 彈反改成武器專屬技能
- 「我希望追加"武器"到商店裡變成可購買的選項,而原本翻滾跟彈反這些動作改成武器裡的特有技能」
  1. 棍棒: 「範圍短, 按z普通攻擊, 按x無反應, 預設武器」
  2. 劍: 「範圍短, 按z普通攻擊, 如果攻擊揮到怪物的投射物(例如水母的子彈)可以打回去, 打回去的子彈如果打到怪, 怪會扣血, 至於火龍那種範圍攻擊就不能用劍打回去了, 劍按x可以擊暈怪物一小段時間」(「火龍」應指火蜥蜴類範圍攻擊, 推論)
  3. 長槍: 「範圍長, 按z普通攻擊, 按x往前衝刺, 穿過敵人也會造成傷害」
  4. 長鞭: 「範圍攻擊, 按z普通攻擊, 按x則是往前方扇形區域大力甩鞭,可以把怪打飛一段距離」

### 3. 捕捉流程
- 喜歡套索繞圈捕捉: 「這個捕捉方式我喜歡」
- 「玩家按攻擊鍵是捕捉,也就是玩家不能選擇把牠打死,應該改成玩家有選擇空間,捕捉改成踩在怪物身上會提示"準備捕捉"並跑一小段時間的圓圈進度條,跑完之後開始進入捕捉模式」
- 「在怪物被捕捉的過程中應該要是暈眩狀態,不能發起攻擊,不然太容易被中斷了,玩家在捕捉過程中會被其他怪干擾,原本就已經容易被中斷」

### 4. 失控標記(取代怒氣滿即失控)
- 「怪物在怒氣條達最滿時會出現失控標記,每次被再次觸發怒氣值提升(可能是被攻擊或其他原因)時標記都會+1, 標記到5個的時候才會失控, 而標記會以一定頻率慢慢減少, 標記減到0的時候原本滿的怒氣條則會緩慢縮短」
- 理由: 「這個設計讓失控多一點門檻, 因為我覺得現在太容易失控了」
- 「怒氣條多一小段紅區, 紅區有特別加乘這件事情可以保留, 但我覺得不需要放大招的機制」

### 5. 表演時玩家不上場, 改成布置階段
- 「表演過程中我覺得玩家不要上場, 改成在表演前多一段"布置階段", 玩家可以購買機關(例如激怒用的機關、冷靜用的機關、把怪吸引到某個區域的機關...等等),玩家能夠對場上產生干涉的手段只有布置機關, 表演過程中無法干涉表演」
- 理由: 「因為我發現當場上的怪物一多,基本上就是一直被怪打,有些怪的攻擊還是範圍的,就只能無力的一直降名聲,反而完全沒辦法控制場面」
- 布置階段同時選上場魔物: 「C我覺得可以改成, 再新加的布置階段時, 玩家可以選擇要放哪隻怪到場上」

### 6. 3 座地下城 + 解鎖
- 「幫我做3個地下城, 每個地下城都有不同的怪物, 一開始只有一個地下城可選, 解鎖其他地下城的手段可以是金幣加上捕捉指定怪物達幾隻」
- 動機: 「提升怪的價值這件事情我想要更進階一點」

### 7. 天數 7 天
- 「現在規模如果只有3天好像玩不完, 可以改成7天看看」

## 喜歡
- A 同種馴熟度(紅線區變寬)、B 同種收服加成(馴獸師加成): 「我覺得A跟B都不錯, 兩者都能沿用」 → 兩者都保留
- C 魔物習性(地下城與表演場移動方式一致): 「魔物習性的設計也不錯, 但目前玩家已經不會在表演場上了, 還要想想看該如何沿用習性的設計」 → 保留, 但需重新設計在表演場(玩家不在場、靠機關)如何發揮(推論: 例如機關布置需考慮各種魔物的移動習性)

## 不喜歡 / 先拿掉
- A 全場紅線連擊: 「我覺得全場紅線連擊雖然不錯, 但我希望玩家更放心思在"如何讓場上的怪物產生連鎖反應", 連擊是達成這件事情的回饋, 雖然有回饋不錯, 但我怕畫面太混亂, 或是玩家會容易患得患失, 可以先拿掉試試看」
- C 紅線大招: 「不需要放大招的機制」
- C 後台替補(表演中自動輪替): 改成布置階段由玩家選上場魔物
- 表演場上玩家下場操作(揮鞭 / 吹哨 / 彈反): 魔物多時被範圍攻擊壓制, 無法控制場面(見上方理由)
- B 表演場彈反反射引爆: 玩家不上場後不再適用; 彈反改為劍的地下城技能(推論)

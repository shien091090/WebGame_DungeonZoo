# 怪獸夜場節目單(節目卡 2.0: 免費排卡、商店賣新卡、節目操控舞台裝置)

## 概述
橫向寬畫面(1280×720), 全程只用方向鍵 + Z、X。白天進地下城: 方向鍵走位, Z 是武器普攻、X 是武器專屬技能(棍棒 / 劍 / 長槍 / 長鞭, 商店購買切換); 把魔物打到殘血後站到牠身上, 跑完「準備捕捉」圓圈就套上套索, 被套的魔物暈眩不能出招, 繞牠一圈收服——也可以選擇直接打死。晚上表演前是「布置階段」: 選要上場的魔物、排節目表。表演場上每種魔物都會主動去找別隻, 身體相撞會互相挑釁, 技能互相點燃 / 澆熄, 被點燃進紅區的魔物會立刻接著表演。怒氣在紅區表演金幣加倍; 怒氣滿了不會馬上失控, 而是開始累積失控標記, 滿 5 個才失控。
**本款的新機制——節目卡 2.0**: 玩家不上場, 靠一張 45 秒的**節目表**(9 個時段, 每段 5 秒)在表演進行中控場。
- 節目卡**排進節目表免費**, 擁有的卡可以重複排; 商店改賣**新種類的卡**(買一次永久擁有)
- 卡分兩類: **點名卡**(激將、冰鎮、集合、安可、橫衝直撞)時段一到讓被點名的那種魔物做事; **不點名卡**不指定魔物, 對象由**發動當下的場面**決定——操控舞台裝置(彩帶砲轟最擠的地方、灑水車沿最氣那隻的那一列開過去、旋轉舞台把全場捲向中央), 或在場上隨機落下抽獎氣球
- 舞台裝置平常不動、碰到也沒事, **只在節目叫到它的時候**才作用
本款魔物陣容: 菇菇球、露水蛙、鑽沙鼴、風滾草、冰晶蝶、礦石蟹。7 天後依名聲評星。
驗證假設: H01、H04、H05、H06、H50、H114~H117、H119、H120、H134、H135、H139、H147~H153。

## 核心循環
挑一座地下城 → 用手上武器閃招、看清每種魔物的技能與動法, 把想要的打到殘血, 站上去套索、繞一圈收服(不要的就打死換金幣)→ 新種加入陣容, 同種提高等級(紅區變寬 + 馴獸師加成), 收服數累積解鎖新地下城 → 布置階段挑魔物、排節目表(點名誰在什麼時候做什麼, 什麼時候叫裝置出場)→ 開演看節目一段段在即時場面上發動、連鎖即時展開, 賺金幣與名聲 → 商店買武器、強化、新節目卡 → 隔天。

## 規則

### 流程
1. 開始畫面顯示說明頁(共 5 頁), 按 Z 翻頁, 最後一頁按 Z 進入第 1 天的地下城選擇
2. 每天依序: 地下城選擇 → 地下城(60 秒)→ 布置階段 → 表演場(45 秒)→ 商店; 第 7 天表演結束後不進商店, 直接進結算
3. 開局: 金幣 30、名聲 0、武器棍棒(只擁有棍棒)、陣容菇菇球與露水蛙(都是等級 0、收服數 0)、擁有的節目卡: 激將、冰鎮、集合、安可
4. 結算後按 Z 重來, 回到第 1 天地下城選擇(不再顯示說明頁), 所有數值重置

### 地下城選擇
5. 畫面橫排 3 張地下城卡(由左到右: 菇菇林、沙丘巢、冰晶礦坑), ←→ 移動選擇框, 按 Z:
   - 已開放 → 進入該地下城
   - 未開放且條件達成 → 扣金幣、開放(卡片變成已開放), 不進入; 再按一次 Z 才進入
   - 未開放且條件未達成 → 不反應
6. 卡片顯示: 名稱、住的兩種魔物、未開放時顯示條件與進度(例「金幣 60 + 收服露水蛙 1/2」)
7. 解鎖條件(收服數 = 該種累計收服次數, 含升級與換金幣的那幾次):
   | 地下城 | 代號 | 魔物 | 開放條件 |
   |---|---|---|---|
   | 菇菇林 | forest | 菇菇球、露水蛙 | 一開始就開放 |
   | 沙丘巢 | dune | 鑽沙鼴、風滾草 | 金幣 60 + 收服露水蛙 2 次 |
   | 冰晶礦坑 | mine | 冰晶蝶、礦石蟹 | 金幣 120 + 收服風滾草 2 次 |

### 地下城(即時, 60 秒)
17. 方向鍵移動馴獸師, 可斜走(速度不變); 放開就停。面向 = 最後一次移動的方向(8 方向)。撞牆 / 石柱擋住(圓形判定半徑 18, 可沿牆滑動); 站在減速地形上移速減半(魔物不受地形影響); 碰到傷害地形算被打中一次
18. 地下城裡習性的對象是馴獸師。馴獸師距離 ≥ 300 時, 所有魔物改在自己房間內隨機走動(40 像素/秒, 每 2~3 秒換方向), 風滾草照常滾動(重新朝對象滾改成隨機方向); 鑽沙鼴照常鑽地, 冒出點改成房間內隨機地板
19. 馴獸師距離 < 300 時, 魔物依間隔施放技能, 瞄準對象是馴獸師; 進入 300 範圍後的第一次施放在一個完整間隔之後(不會一靠近就出招)。施放預警期間照常移動
20. 魔物身體碰到馴獸師不會造成傷害, 只有技能與傷害地形會
21. 每個巢穴開局各生 1 隻該種魔物; 魔物被收服或打倒後, 該巢穴 8 秒後再生 1 隻
22. 武器(見武器表): Z 普攻、X 武器技; 各自有冷卻。攻擊判定朝面向
23. 魔物被攻擊命中: 扣血(武器傷害 + 攻擊力強化等級), 受擊閃白 0.1 秒。被套索套住、鑽地中的魔物不受傷害
24. 魔物血量 ≤ 最大值 30%: 「殘血」——身上冒虛弱記號, 移動速度 ×0.5、施放間隔 ×1.5
25. 血量歸零: 打倒, 魔物消失, 得該種打倒金幣
26. 被技能或傷害地形打中(突進無敵中除外): 扣 1 顆心, 之後無敵 1.2 秒(閃爍); 被旋風打中另被推開 80 像素
27. 心歸零或 60 秒到: 地下城結束, 進布置階段; 已收服的保留
28. 每天進地下城時: 心補滿、捕獸繩補到上限、所有冷卻歸零, 馴獸師在起點、面向上

31. 攻擊特效每次 0.2 秒(突進 0.25 秒)

### 捕捉
32. 準備捕捉: 馴獸師中心與一隻殘血魔物中心距離 ≤ 40、捕獸繩 > 0、目前沒有套索時, 那隻魔物身上出現「準備捕捉」字樣與圓圈進度條, 在 0.8 秒內填滿(露水蛙加成會縮短, 最低 0.35 秒); 離開 40 範圍或被打中就歸零。同時有多隻符合時取最近的一隻。準備期間魔物照常移動與施放(鑽沙鼴鑽地中不算在範圍內)
33. 圓圈填滿 → 套上套索: 被套的魔物「暈眩」——停止移動、不施放技能(預警中的取消)、不受傷害、不鑽地; 馴獸師與牠之間畫一條繩
34. 繞圈進度: 每幀計算「馴獸師相對魔物的角度」變化量(取 −180°~180°), 累加成有正負號的總和; 進度 = |總和| / 360°。順時針、逆時針都算, 中途反方向會倒扣
35. 進度達 1: 收服——繩 −1, 魔物離場, 飄字「收服!」, 該種收服數 +1, 該巢穴 8 秒後再生
36. 套索斷掉(魔物維持殘血、解除暈眩; 要重新準備捕捉, 進度從 0 開始)的情況:
    - 套索計時達時限(5 秒, 冰晶蝶加成會延長)
    - 馴獸師與魔物距離 > 220
    - 馴獸師被其他魔物的技能或傷害地形打中(長槍突進無敵中不算)
37. 套索中可以移動與使用 Z、X 攻擊其他魔物
38. 收服的結果: 陣容沒有此種 → 加入陣容, 等級 0; 已有 → 該種等級 +1(最多 3), 飄字「等級 +1」; 已是 3 級 → 金幣 +20, 飄字「+20」
39. 等級的兩個效果, 收服當下立刻生效:
    - 紅區變寬: 該種在表演場的紅區下限 = 80 − 5 × 等級(80 / 75 / 70 / 65)
    - 馴獸師加成(地下城用, 每級疊加):
      | 種類 | 加成 | 每級 |
      |---|---|---|
      | 菇菇球 | 孢力 | Z 普攻範圍(半徑或長度)+10% |
      | 露水蛙 | 蛙舌 | 準備捕捉時間 −0.15 秒 |
      | 鑽沙鼴 | 掘進 | X 武器技冷卻 −15% |
      | 風滾草 | 乘風 | 移速 +25 |
      | 冰晶蝶 | 凍結 | 套索時限 +1 秒 |
      | 礦石蟹 | 硬殼 | 心 +1 |

### 布置階段
40. 第 1 步「選上場」: 陣容每種一張卡(種類、等級), ←→ 移動選擇框, 按 Z 切換選 / 不選(最多 4 種上場); 按 ↓ 移到「下一步」按鈕(按 ↑ 回卡片), 在「下一步」上按 Z 進第 2 步(至少選 1 種才反應)
41. 第 2 步「排節目」: 畫面左側是節目表, 由上到下 9 個時段列(第 i 段 = 開演後 5i ~ 5i+5 秒, i = 0~8), 每列顯示時段、放的卡與點名的魔物(不點名卡顯示「全場」; 空的顯示「—」)。↑↓ 移動游標, 從第 9 列再按 ↓ 移到「開演」按鈕(按 ↑ 回時段列)

## 範圍邊界
- 只做這 7 天、三張固定地圖, 不做難度曲線、存檔、音效
- 陣容每種最多一隻(同種再收服變等級), 不做出售、放生
- 節目卡只在布置階段排, 表演中不能有任何操作; 不做馴獸師下場、吹哨、揮鞭激怒、大招、全場連擊計量
- 舞台裝置只由節目卡驅動; 不做魔物碰到就觸發的設施、不做定時自動脈衝的範圍機關、不做會被技能觸發的機關
- 魔物開演位置固定, 不做擺位
- 不做門票與觀眾人數, 收益只來自表演與打倒魔物
- 不支援滑鼠

# 口令牌馴獸秀(口令牌: 掛在魔物身上「當…就…」, 表演中依魔物狀態自動觸發)

## 概述
橫向寬畫面(1280×720), 全程只用方向鍵 + Z、X。白天進地下城: 方向鍵走位, Z 是武器普攻、X 是武器專屬技能(棍棒 / 劍 / 長槍 / 長鞭, 商店購買切換); 把魔物打到殘血後站到牠身上, 跑完「準備捕捉」圓圈就套上套索, 被套的魔物暈眩不能出招, 繞牠一圈收服——也可以選擇直接打死。晚上表演前是「布置階段」: 選要上場的魔物、幫每隻掛口令牌。表演場上每種魔物都會主動去找別隻, 身體相撞會互相挑釁, 技能互相點燃 / 澆熄, 被點燃進紅區的魔物會立刻接著表演。怒氣在紅區表演金幣加倍; 怒氣滿了不會馬上失控, 而是開始累積失控標記, 滿 5 個才失控。
**本款的新機制——口令牌**: 玩家不上場, 也不在表演中按鍵; 控場靠布置時掛在魔物身上的**口令牌**。每塊牌是一條「**當**(這隻 / 別隻的狀態到了某個點)**就**(做某件事)」, 表演中**一直在看場面**, 條件一到就自動發動, 發動完冷卻一段時間再繼續看。
- 每隻上場魔物有 2 個牌位; 每種牌有 2 塊, 要決定掛在誰身上
- 條件看的是魔物自己的狀態(怒氣掉到門檻下、進紅區、失控標記到 3、被點燃、一招打中好幾隻), 有的看**別隻**(場上有誰快失控了)
- 動作有降溫(冷靜鈴)、加溫(打氣鈴、炒熱令)、把火傳出去(傳火令)、去救火(滅火令)、再演一次(安可令)、把大家叫過來(嘲諷令)
- 時機不是用時間猜, 而是「到那個狀態就做」; 掛在誰身上、搭哪兩條, 是玩家設計的控場規則
本款魔物陣容: 發條鼠、油壺蝸牛、河豚、章魚、南瓜燈、棉花糖羊。7 天後依名聲評星。
驗證假設: H01、H04、H05、H06、H50、H114~H117、H119、H120、H134、H135、H147~H149、H159~H162。

## 核心循環
挑一座地下城 → 用手上武器閃招、看清每種魔物的技能與動法, 把想要的打到殘血, 站上去套索、繞一圈收服(不要的就打死換金幣)→ 新種加入陣容, 同種提高等級(紅區變寬 + 馴獸師加成), 收服數累積解鎖新地下城 → 布置階段挑魔物、幫每隻掛兩塊口令牌(誰負責點火、誰負責救火、誰快爆了自己冷靜)→ 開演看口令牌在即時場面上一條條發動、連鎖即時展開, 賺金幣與名聲 → 商店買武器、強化、新口令牌 → 隔天。

## 規則

### 流程
1. 開始畫面顯示說明頁(共 5 頁), 按 Z 翻頁, 最後一頁按 Z 進入第 1 天的地下城選擇
2. 每天依序: 地下城選擇 → 地下城(60 秒)→ 布置階段 → 表演場(45 秒)→ 商店; 第 7 天表演結束後不進商店, 直接進結算
3. 開局: 金幣 30、名聲 0、武器棍棒(只擁有棍棒)、陣容發條鼠與油壺蝸牛(都是等級 0、收服數 0)、擁有的口令牌: 冷靜鈴、打氣鈴、傳火令(各 2 塊)
4. 結算後按 Z 重來, 回到第 1 天地下城選擇(不再顯示說明頁), 所有數值重置

### 地下城選擇
5. 畫面橫排 3 張地下城卡(由左到右: 發條工坊、珊瑚海窟、南瓜墓園), ←→ 移動選擇框, 按 Z:
   - 已開放 → 進入該地下城
   - 未開放且條件達成 → 扣金幣、開放(卡片變成已開放), 不進入; 再按一次 Z 才進入
   - 未開放且條件未達成 → 不反應
6. 卡片顯示: 名稱、住的兩種魔物、未開放時顯示條件與進度(例「金幣 60 + 收服油壺蝸牛 1/2」)
7. 解鎖條件(收服數 = 該種累計收服次數, 含升級與換金幣的那幾次):
   | 地下城 | 代號 | 魔物 | 開放條件 |

   | 發條工坊 | workshop | 發條鼠、油壺蝸牛 | 一開始就開放 |

### 地下城(即時, 60 秒)
17. 方向鍵移動馴獸師, 可斜走(速度不變); 放開就停。面向 = 最後一次移動的方向(8 方向)。撞牆 / 石柱擋住(圓形判定半徑 18, 可沿牆滑動); 站在減速地形上移速減半(魔物不受地形影響); 碰到傷害地形算被打中一次
18. 地下城裡習性的對象是馴獸師。馴獸師距離 ≥ 300 時, 所有魔物改在自己房間內隨機走動(40 像素/秒, 每 2~3 秒換方向); 發條鼠照常上發條衝刺, 衝刺方向改成隨機
19. 馴獸師距離 < 300 時, 魔物依間隔施放技能, 瞄準對象是馴獸師(發條鼠的火花不瞄準); 進入 300 範圍後的第一次施放在一個完整間隔之後(不會一靠近就出招)。施放預警期間照常移動
20. 魔物身體碰到馴獸師不會造成傷害, 只有技能與傷害地形會。油壺蝸牛黏在馴獸師身上時不影響馴獸師移動; 章魚的觸手會把馴獸師拉近 80 像素(撞牆停), 不扣心
21. 每個巢穴開局各生 1 隻該種魔物; 魔物被收服或打倒後, 該巢穴 8 秒後再生 1 隻
22. 武器(見武器表): Z 普攻、X 武器技; 各自有冷卻。攻擊判定朝面向
23. 魔物被攻擊命中: 扣血(武器傷害 + 攻擊力強化等級), 受擊閃白 0.1 秒。被套索套住的魔物不受傷害
24. 魔物血量 ≤ 最大值 30%: 「殘血」——身上冒虛弱記號, 移動速度 ×0.5、施放間隔 ×1.5
25. 血量歸零: 打倒, 魔物消失, 得該種打倒金幣
26. 被技能或傷害地形打中(突進無敵中除外): 扣 1 顆心, 之後無敵 1.2 秒(閃爍)
27. 心歸零或 60 秒到: 地下城結束, 進布置階段; 已收服的保留
28. 每天進地下城時: 心補滿、捕獸繩補到上限、所有冷卻歸零, 馴獸師在起點、面向上

31. 攻擊特效每次 0.2 秒(突進 0.25 秒)

### 捕捉
32. 準備捕捉: 馴獸師中心與一隻殘血魔物中心距離 ≤ 40、捕獸繩 > 0、目前沒有套索時, 那隻魔物身上出現「準備捕捉」字樣與圓圈進度條, 在 0.8 秒內填滿(油壺蝸牛加成會縮短, 最低 0.35 秒); 離開 40 範圍或被打中就歸零。同時有多隻符合時取最近的一隻。準備期間魔物照常移動與施放
33. 圓圈填滿 → 套上套索: 被套的魔物「暈眩」——停止移動、不施放技能(預警中的取消)、不受傷害、不甩觸手、不黏附; 馴獸師與牠之間畫一條繩
34. 繞圈進度: 每幀計算「馴獸師相對魔物的角度」變化量(取 −180°~180°), 累加成有正負號的總和; 進度 = |總和| / 360°。順時針、逆時針都算, 中途反方向會倒扣
35. 進度達 1: 收服——繩 −1, 魔物離場, 飄字「收服!」, 該種收服數 +1, 該巢穴 8 秒後再生
36. 套索斷掉(魔物維持殘血、解除暈眩; 要重新準備捕捉, 進度從 0 開始)的情況:
    - 套索計時達時限(5 秒, 章魚加成會延長)
    - 馴獸師與魔物距離 > 220
    - 馴獸師被其他魔物的技能或傷害地形打中(長槍突進無敵中不算)
37. 套索中可以移動與使用 Z、X 攻擊其他魔物
38. 收服的結果: 陣容沒有此種 → 加入陣容, 等級 0; 已有 → 該種等級 +1(最多 3), 飄字「等級 +1」; 已是 3 級 → 金幣 +20, 飄字「+20」
39. 等級的兩個效果, 收服當下立刻生效:
    - 紅區變寬: 該種在表演場的紅區下限 = 80 − 5 × 等級(80 / 75 / 70 / 65)
    - 馴獸師加成(地下城用, 每級疊加):
      | 種類 | 加成 | 每級 |
      |---|---|---|
      | 發條鼠 | 發條 | 移速 +25 |
      | 油壺蝸牛 | 潤滑 | 準備捕捉時間 −0.15 秒 |
      | 河豚 | 鼓脹 | 心 +1 |
      | 章魚 | 纏繞 | 套索時限 +1 秒 |
      | 南瓜燈 | 南瓜 | Z 普攻範圍(半徑或長度)+10% |
      | 棉花糖羊 | 綿軟 | X 武器技冷卻 −15% |

### 布置階段
40. 第 1 步「選上場」: 陣容每種一張卡(種類、等級), ←→ 移動選擇框, 按 Z 切換選 / 不選(最多 4 種上場); 按 ↓ 移到「下一步」按鈕(按 ↑ 回卡片), 在「下一步」上按 Z 進第 2 步(至少選 1 種才反應)

### 表演場(即時, 45 秒, 玩家不能操作)
47. 場地與觀眾席: 上下兩側觀眾席, 各 8 段圍欄與 8 名觀眾(版面見數值表)。所有魔物的中心點限制在 x 100~1180、y 186~526(魔物活動範圍); 魔物之間可以重疊, 不互相推擠
48. 上場魔物從開演位置開始(第 i 隻上場魔物, 依第 1 步陣容順序, 站在數值表「開演位置」第 i 點); 怒氣全部 60; 每隻的第一次表演計時隨機 0.5~2 秒, 之後照第 51 條間隔; 所有口令牌開演時冷卻歸零
49. 開演後玩家沒有任何操作; 表演自動進行到 45 秒結束
50. 怒氣每秒自然下降, 下降量依種類(種類表); 最低 0、最高 100
51. 怒氣 < 50: 不定時表演。怒氣 ≥ 50: 定時表演, 間隔從 4 秒(怒氣 50)線性縮短到 1.5 秒(怒氣 100); 任何一次表演(定時、接演、滅火令、安可令)都重設這個計時
52. 表演 = 放出該種技能, 表演動作 0.5 秒。技能的形狀與預警同地下城(種類表); 瞄準對象 = 最近的其他魔物(失控中除外), 沒有就瞄準場地中央 (640, 356); 火花固定射 4 個斜方向; 膨脹刺、棉花雲以自身為中心; 滅火令的那次表演瞄準指定的那隻
53. 技能打中其他魔物(不含失控中、施放者自己), 改變牠的怒氣: 火花 +10, 膨脹刺、南瓜炸彈 +15(點燃型); 冷卻液 −20, 墨汁 −15, 棉花雲 −10(澆熄型)。同一次施放對同一隻只算一次
54. 紅區: 怒氣從「紅區下限」(第 39 條)到 100; 怒氣條上標出這一段。在紅區表演, 金幣 ×2
55. 每次表演: 金幣 = 種類金幣 ×(1 + 0.5 × 這次打中的其他魔物數)×(紅區 2, 否則 1)×(1 + 0.25 ×(段數 − 1))× min(3, 1 + 名聲/200), 四捨五入, 最少 1; 名聲 + 種類名聲。「打中數」在技能判定結束時(範圍技能生效結束、投射物全部消失)結算, 金幣與名聲在那時入帳。飄字顯示金幣, 紅區加註「×2」, 段數 ≥ 2 加註「連鎖 N」
56. 相撞挑釁: 兩隻魔物(都不在失控中)中心距離 ≤ 80 → 兩隻怒氣各 +8; 同一對 2 秒內只算一次。怒氣已是 100 的那隻不受相撞影響(不加怒氣也不加標記)。油壺蝸牛黏著的那一對, 黏上的瞬間算一次, 黏住期間照「2 秒一次」繼續算
57. 失控標記:
    - 怒氣升到 100 的瞬間 → 失控標記 1 個; 有標記期間怒氣停在 100、不自然下降
    - 有標記時, 每次被點燃型效果升怒(技能、傳火令衝撞、打氣鈴、炒熱令; 相撞挑釁除外)→ 標記 +1; 被澆熄型技能打中 → 怒氣不變, 標記 −1; 冷靜鈴 → 標記歸 0、怒氣 70
    - 標記每 4 秒自動 −1(標記有增減時重新計時)
    - 標記減到 0 → 怒氣開始以每秒 2 緩慢下降; 降到紅區下限以下後恢復該種的自然下降速度。緩慢下降期間再升回 100 → 重新從 1 個標記開始
    - 標記達 5 → 失控
58. 接演(即時連鎖): 魔物被點燃型**技能**(種類技能、傳火令衝撞)打中後, 若怒氣 ≥ 自己的紅區下限、不在失控中、且距離上次接演已過 1.5 秒 → 0.3 秒後立刻表演一次; 這次表演的段數 = 打中牠那招的段數 + 1。定時表演與滅火令的表演是第 1 段; 打氣鈴、炒熱令、相撞挑釁不是技能, 不引發接演
59. 「點燃型」= 讓怒氣上升的效果; 「澆熄型」= 讓怒氣下降的效果。效果打中後魔物身上顯示被點燃 / 被澆熄的反應 0.5 秒
60. 失控: 以 160 像素/秒衝向最近那側觀眾席(魔物 y < 356 衝上側, 否則下側)正前方的那段圍欄, 撞 1.5 秒後圍欄破掉, 進觀眾席沿座位排左右來回奔跑 6 秒(140 像素/秒), 每 1.5 秒攻擊身邊最近的觀看中觀眾一次: 名聲 −3, 被攻擊的觀眾嚇跑, 4 秒後補回。6 秒後累倒: 瞬間回到場地中央, 怒氣 30、標記 0, 恢復移動; 圍欄維持破損到收場
61. 失控中(含衝欄)不表演、不受技能、相撞與其他魔物口令牌的影響, 也不是任何技能、觸手、黏附、嘲諷的對象與移動對象; 失控時若正在衝刺、被叫過去、被拉, 立刻結束
62. 45 秒到: 仍失控的每隻名聲 −5; 圍欄全部修好; 進商店(第 7 天進結算)。名聲最低 0

## 範圍邊界
- 只做這 7 天、三張固定地圖, 不做難度曲線、存檔、音效
- 陣容每種最多一隻(同種再收服變等級), 不做出售、放生
- 口令牌只在布置階段掛, 表演中不能有任何操作; 不做馴獸師下場、吹哨、揮鞭激怒、大招、全場連擊計量
- 不做玩家自組條件與動作(每塊牌的條件與動作是固定一組)
- 場地上不擺任何設施; 不做魔物碰到就觸發的機關、不做定時自動脈衝的範圍機關
- 魔物開演位置固定, 不做擺位
- 不做門票與觀眾人數, 收益只來自表演與打倒魔物
- 不支援滑鼠

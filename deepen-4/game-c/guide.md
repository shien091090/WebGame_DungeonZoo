# 口令牌馴獸秀 — 玩家說明

翻頁: 按 Z 翻下一頁; 最後一頁按 Z 開始遊戲。每頁底部小字「按 Z 繼續」。

## 第 1 頁 地下城
- 文字: 方向鍵走, Z 攻擊, X 武器技
- 圖要示意: 發條工坊的一角, 馴獸師拿棍棒朝右敲中一隻發條鼠(扇形攻擊特效、發條鼠受擊閃白); 另一隻發條鼠朝四個斜方向射出火花, 馴獸師的移動箭頭從火花之間的空隙走開。畫面下方三個鍵帽「方向鍵 / Z / X」各對應「走 / 攻擊 / 武器技」

## 第 2 頁 收服
- 文字: 殘血時站上去, 再繞牠一圈
- 圖要示意: 左右兩格。左: 馴獸師站在一隻帶虛弱記號的油壺蝸牛身上, 蝸牛頭上「準備捕捉」字樣與圓圈進度條填到一半; 右: 套索連著頭頂冒暈眩星星的蝸牛, 馴獸師沿一條繞著牠的箭頭路線跑, 魔物周圍的進度環填到一半。角落小圖: 「收服!」飄字(打勾)

## 第 3 頁 掛口令牌
- 文字: 幫魔物掛牌, 條件到了自己會做
- 圖要示意: 上: 布置第 2 步的兩列——「發條鼠 [冷靜鈴][傳火令]」「油壺蝸牛 [打氣鈴][空牌位]」, 選擇框停在蝸牛的空牌位上。下: 一個小箭頭指向開演後的表演場縮圖——油壺蝸牛的怒氣條剛從門檻下方跳回門檻上方, 頭上冒出「打氣鈴!」、身上是被點燃的反應, 身下的打氣鈴圖示在閃

## 第 4 頁 紅區
- 文字: 紅區最賺, 標記滿 5 個就失控
- 圖要示意: 上: 一隻魔物的怒氣條指在紅區段, 正在表演, 飛出「×2」金幣。下: 左邊一隻魔物怒氣條全滿、頭上排著 4 個失控標記; 箭頭指向右邊同一隻魔物衝去撞觀眾席的圍欄(頭上已沒有標記), 打叉

## 第 5 頁 目標
- 文字: 7 天內賺到越多名聲越好
- 圖要示意: 一圈流程箭頭「地下城 → 布置 → 表演 → 商店」回到地下城, 圈中央寫「×7 天」; 表演那一格旁有名聲星星往上加, 終點是結算的評價星數

## 驗算(圖中狀態對照規則)
- 第 3 頁下圖: 打氣鈴在怒氣 < 50 時發動, 怒氣 +25, 所以怒氣條從 50 線下跳到 50 線上(約 70 多)✓; 牌名浮字 0.8 秒、被點燃反應 0.5 秒、圖示閃光 0.3 秒, 發動後 0.3 秒內三者同時成立 ✓。打氣鈴不是技能, 不引發接演, 圖裡不畫蝸牛接著表演 ✓
- 第 3 頁上圖: 開局三種牌各 2 塊; 圖中冷靜鈴、傳火令、打氣鈴各用 1 塊, 不超過 ✓; 同一隻沒掛兩塊同種的牌 ✓
- 第 4 頁: 標記數 0~4 時才顯示在頭上, 滿 5 的瞬間就變成失控、不再顯示標記, 所以畫「4 個標記 → 衝圍欄(沒有標記)」✓; 有標記期間怒氣停在 100 ✓。圖中這隻沒畫口令牌(這頁只講紅區與標記)
- 第 2 頁: 準備捕捉期間魔物沒暈, 套索中才暈 ✓
- 第 1 頁: 發條鼠的火花固定射 45°、135°、225°、315° 四個斜方向, 正上下左右是空的, 箭頭沿空隙走 ✓

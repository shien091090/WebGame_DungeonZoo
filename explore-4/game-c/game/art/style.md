> index.html 必須宣告 `<meta charset="utf-8">`(art.js 內含中文字串)。
> 載入方式: 一般 `<script src="game/art/art.js">`, 全域 `window.Art`。所有 x, y 都是**物件中心的畫面座標**(地下城已扣掉鏡頭); 只有 `drawButton` 的 x, y 是左上角。

## 3. 形狀語言
生物(馴獸師、魔物、觀眾)= 圓潤實心 + 3px 深色描邊 + 腳下影子; 地形 = 平塗、無描邊、無影; 技能 = 半透明色面 + 亮邊; 鋸齒只給「失控」, 虛線只給「預警 / 範圍」。

## 4. 理念落實
- **P0 辨識度先於好看**: 地板全壓在灰階 ≤ 50 的暗色, 魔物用高飽和實心 + 深描邊浮在上面; 熔岩做成「暗地殼 + 細發光裂縫」, 不和同區的火蜥蜴(整塊實心橘)搶。
- **P1 視覺權重跟著決策迫切度**: 全場最強的元素是技能危險區(大面積亮色)與失控魔物的紅色鋸齒圈; 地板、看台、草地條紋都是低對比; 舞台字樣只 45% 不透明。
- **P2 規則上存在的東西畫面上要存在**: 判定邊界 = 畫面邊界: 馴獸師身體圓半徑 18、火圈 / 落雷外緣 = 半徑、震波外緣 = 當下半徑、舞台區邊界線與水池池緣都畫在區內側; 殘血門檻(30%)與表演門檻(怒氣 50)都在條上畫刻度; 繩子最舊的 1/4 淡出, 表示「會從這端被刪」。
- **P3 一個意義一種長相**: 綠 = 可收服 / 收服(記號、殘血血條、閃光、捕獸繩圖示、飄字共用); 紅 = 壞事; 種類色 = 該種魔物與牠的技能(地下城與牧場同一個色、同一個函式); 虛線外緣 + 由內長大的填色 = 預警, 長滿 = 生效。
- **P4 關鍵區分走兩條通道**: 殘血 = 綠色血條 + 頭上套索記號; 失控 = 紅色 + 鋸齒外圈(全場唯一鋸齒); 收服閃光 vs 勒傷閃光 = 綠 vs 白 + 邊線粗細; 預警 vs 生效 = 虛線 + 半透明 vs 實線 + 實色。
- **P7 每個元素都要掙得版面**: 魔物身上不放數字(血量、怒氣只畫條); 繩長只畫條不寫數字; 牧場魔物數只用色點 + 數量。
- **P9 以最混亂的那一刻驗收**: 牧場可能同時十幾隻魔物 + 幾個技能疊在一起, 所以怒氣條帶深色底與描邊、失控鋸齒圈閃爍、表演中加放射光, 在技能色面上仍讀得到。
- **P13 事件要排隊**: 飄字由 RD 依序產生; 美術讓飄字 1 秒內上浮淡出, 名聲減幾乎不上浮(只淡出), 和同時出現的金幣飄字上下錯開。
- **P15 回饋強度與事件份量成正比**: 收服(綠色粗邊閃光 + 36px 飄字放大彈出)> 勒傷(白色細邊閃光)> 金幣 / 名聲飄字(26px)。
- **P17 進度圖形與數字分工**: 剩餘秒數只用數字; 繩長、血量、怒氣只用條, 條上只畫決策刻度(30% / 50)。
- **P18 重要資訊不能只閃一下**: 收服數常駐在 HUD 右側的色點計數; 金幣、名聲常駐右上; 結算畫面列出全部。
- **P19 資訊貼著物件**: 血條、怒氣條、捕捉記號都在魔物框內; 被點燃 / 被澆熄長在魔物外緣(光暈 + 火舌 / 水滴), 不另掛圖示。
- **P21 示意圖選分岔的例子**: 第 2 頁並排「殘血被圈 → 收服」與「滿血被圈 → 只勒傷」; 第 4 頁加一隻吠叫範圍外、沒被推的魔物當對照。

| 圍圈閃光 | 0.6 秒 | 美術自訂 |
| 繩子被切 | 0.5 秒 | 美術自訂 |
| 吠叫範圍 | 0.4 秒 | 美術自訂 |
| 飄字 | 1.0 秒 | 美術自訂 |

RD 在 t 超過總長後可以停止呼叫; 函式自己也會在 t ≥ 總長時不畫(火圈 active 例外: 只要 RD 呼叫就畫, 因為生效 0.5 秒由 RD 控制)。若之後規格改預警秒數, 請把總長加進 state(建議欄位 `dur`), 否則填色會提早或延後長滿。

## 7. 繪製層級(由下到上)
地下城: 背景 → 格子 → 繩子 → 圍圈閃光 → 野生魔物 → 馴獸師 → 技能(預警 / 生效)→ 繩子被切 → 飄字 → HUD。
牧場: 背景 → 牧場底圖 → 觀眾 → 牧場魔物(y 小的先畫)→ 馴獸師 → 技能 → 吠叫範圍 → 飄字 → HUD。
技能畫在魔物之上是刻意的: 危險區要蓋在任何東西上都看得到; 色面只有 35~55% 不透明, 底下的魔物仍可見。
全畫面: 標題卡、商店(按鈕 / 項目 + HUD)、結算面板各自在最上層。

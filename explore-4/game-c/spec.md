# 魔物牧場(繞圈圍捕的技術感, 把魔物趕成一團引爆)

## 概述
全程只用鍵盤。地下城是一座開闊的捲動洞窟: 馴獸師用方向鍵走, 身後拖著一條繩, 繞一圈把魔物圈住——滿血的只會被勒傷, 殘血的才會被收服; 魔物的攻擊打到繩子會把繩子切斷, 要邊閃招邊繞。表演場是一片牧場, 馴獸師沒有鞭子, 像牧羊犬一樣靠近逼魔物走、按空白鍵吠叫把附近的魔物推開: 魔物被趕進看台前的舞台區就會越來越氣、夠氣就朝馴獸師表演, 技能打到身邊的同伴會互相點燃; 趕進中央水池才會冷靜。怒氣滿了衝進看台咬觀眾, 要繞到牠後面把牠吠回場內、一路趕進水池。收服的魔物全部上場, 沒有名額。三天後依名聲評星。
驗證假設: H01~H06、H88~H94。

## 核心循環
在洞窟裡邊閃招邊拖繩繞圈, 把魔物勒到殘血再圈一次收服 → 牧場上的魔物越來越多 → 把一群魔物趕進舞台區擠在一起, 讓技能互相點燃, 快爆的趕回水池 → 賺金幣與名聲 → 買強化(更長的繩、更大的吠聲)→ 隔天圈得更快、牧場更熱鬧也更難趕。

## 規則

### 流程
1. 開始畫面顯示說明頁(共 5 頁), 按空白鍵翻頁, 最後一頁按空白鍵進入第 1 天
2. 每天依序: 地下城(60 秒)→ 牧場表演(50 秒)→ 商店; 第 3 天表演結束後不進商店, 直接進結算
3. 地下城與表演開始前各有一張標題卡(「第 N 天 地下城」/「第 N 天 牧場」), 按空白鍵開始
4. 開局牧場: 火蜥蜴 1 隻、水母 1 隻
5. 結算後按空白鍵重來, 回到第 1 天地下城(不再顯示說明頁), 所有數值重置

### 地下城(即時, 60 秒)
9. 方向鍵移動馴獸師, 可斜走(同時按兩個方向, 速度不變); 放開就停。撞牆 / 石柱會被擋住(圓形判定半徑 18, 可沿牆滑動); 站在水上移速減半; 碰到熔岩算被打中一次
10. 拖繩: 馴獸師每移動 12 像素就在腳下留一個繩點, 繩點依序連成繩子; 繩子總長超過繩長上限時, 從最舊的一端刪掉
11. 圍圈: 最新一段繩子與較舊的繩段(不含最新 4 段)相交 → 從相交處到馴獸師的這段繩子圍成一個圈; 圈的面積 < 6000 平方像素則不算(繩子保留)
12. 圈成立時, 中心點在圈內的每隻魔物:
    - 殘血且捕獸繩 > 0 → 收服(繩 −1, 魔物離場)
    - 其他 → 勒傷: 扣等於勒力的血, 受擊閃白
    然後整條繩子清空, 畫面閃一下圈的形狀
13. 魔物技能的生效範圍碰到任何繩點 → 繩子斷在那裡: 該繩點與比它更舊的繩點全部刪掉; 水彈碰到繩點後消失
14. 每個巢穴開局各生 1 隻該種魔物; 魔物被收服或打倒後, 該巢穴 8 秒後再生 1 隻
15. 魔物血量 = 基本血量 ×(1 + 0.5×(天數 − 1)) 四捨五入
16. 魔物在自己的區內以低速隨機走動(每 2~3 秒換方向), 撞牆轉向, 不會離開自己的區
17. 馴獸師與魔物距離 < 400 時, 魔物依種類的間隔施放攻擊技能(見「技能表」); 技能與牧場表演的技能完全相同
18. 魔物血量 ≤ 最大值 30%: 變「殘血」, 頭上出現捕捉記號; 照常走動, 施放間隔 ×1.5
19. 血量歸零: 打倒, 魔物消失, 得金幣
20. 收服的魔物全部加入牧場, 同種可以有好幾隻, 沒有數量上限; 收服時飄字「收服!」
21. 被技能打中: 扣 1 顆心, 之後無敵 1 秒(閃爍)
22. 心歸零或 60 秒到: 地下城結束, 進牧場; 已收服的保留
23. 每天出發時心補滿、捕獸繩補到上限, 繩子清空, 馴獸師回到起點

### 技能表(地下城攻擊 = 牧場表演技能)
| 種類 | 技能 | 範圍與時序 | 施放間隔 |
|---|---|---|---|
| 火蜥蜴 | 火圈 | 以自身為中心半徑 120, 預警 0.5 秒後生效 0.5 秒 | 2.4 秒 |
| 水母 | 水彈 | 朝馴獸師當下位置射 3 發扇形水彈(夾角 20°), 速度 300, 判定半徑 12; 在地下城會被牆擋下, 牧場飛出場地邊界消失 | 1.6 秒 |
| 雷鳥 | 落雷 | 在馴獸師當下位置標出半徑 70 的圓, 0.8 秒後落雷(瞬間判定) | 2.6 秒 |
| 石像鬼 | 震波 | 以自身為中心的圓環, 1 秒內半徑 0 → 220, 環寬 30 | 3 秒 |

### 牧場表演(即時, 50 秒)
24. 版面: 上下兩側看台各 6 名觀眾; 中間是牧場。牧場內靠上看台的一條是「上舞台區」、靠下看台的一條是「下舞台區」, 中央是圓形「水池」, 其餘是草地(版面見數值表)
25. 方向鍵移動馴獸師, 速度同地下城; 馴獸師可走在牧場與看台(看台裡可穿過觀眾), 不能出畫面左右邊界
26. 開演時所有魔物隨機散在草地上, 怒氣全部設為 20
27. 魔物平時在牧場內低速隨機走動(碰邊界轉向, 不會自己進看台)
28. 逃開: 馴獸師距離某隻魔物 < 該種的「逃開距離」時, 牠以該種的「逃開速度」直線遠離馴獸師(限牧場內, 碰邊界沿邊滑)
29. 按空白鍵: 吠叫——馴獸師周圍吠叫半徑內的每隻魔物, 被朝遠離馴獸師的方向推一下(推力 × 該種的「推動倍率」, 0.4 秒內線性減速到 0); 未失控的怒氣 +8; 有冷卻
30. 怒氣每秒變化(依魔物所在位置): 舞台區 + 該種漲怒速度; 水池 −25; 草地 −3。最低 0、最高 100
31. 表演: 魔物在舞台區且怒氣 ≥ 50 → 定時表演, 間隔從 3 秒(怒氣 50)線性縮短到 1 秒(怒氣 99); 表演時放出該種技能(見技能表), 瞄準對象是馴獸師。不在舞台區不表演
32. 每次表演得金幣 = 種類金幣 ×(1 + 0.5 × 這次技能打中的其他魔物數)×(1 + 名聲/100) 四捨五入; 名聲 + 種類名聲
33. 技能打中其他魔物(不含失控中、不含施放者自己), 每次生效改變牠的怒氣: 火圈、落雷、震波 +15; 水彈 −20。同一個技能對同一隻魔物只算一次
34. 技能碰到馴獸師 → 暈眩 1.2 秒(不能移動、不能吠叫)、名聲 −2, 之後無敵 2 秒
35. 怒氣達 100: 失控——以衝刺速度衝向較近那側看台, 進看台後沿座位排左右來回奔跑, 每 1.5 秒攻擊身邊的觀眾一次: 名聲 −3, 被攻擊的觀眾嚇跑, 4 秒後補回
36. 失控魔物不表演、不受技能影響、不逃開馴獸師; 被吠叫推到時改為被推得更遠(推力 × 1.5, 不乘種類倍率)並且愣住 1 秒(這 1 秒不移動)
37. 失控魔物愣住結束後: 若在看台裡 → 繼續在看台奔跑攻擊; 若在牧場裡、不在水池 → 衝回較近那側看台; 若在水池 → 停在水池裡, 怒氣照水池規則下降
38. 失控魔物怒氣降到 60 以下: 恢復正常(回到第 27、28 條的行為), 怒氣保留
39. 有魔物失控時, HUD 訊息顯示「繞到牠後面吠叫, 趕進水池」
40. 50 秒到: 仍失控的每隻名聲 −5
41. 名聲最低 0; 金幣四捨五入取整

## 範圍邊界
- 只做一關(3 天、一張地圖), 不做難度曲線、存檔、音效
- 不做籠子、星級、合併、魔物出售; 收服的全部上場
- 牧場沒有鞭子、沒有圍欄; 馴獸師只有走位與吠叫
- 不做 Boss、寶箱、門票與觀眾人數, 收益只來自表演
- 不支援滑鼠

# 紅線馴獸場 — 玩家說明

翻頁: 按 Z 翻下一頁; 最後一頁按 Z 開始遊戲。每頁底部小字「按 Z 繼續」。

## 第 1 頁 地下城
- 文字: 方向鍵走, Z 揮鞭, X 翻滾
- 圖要示意: 地下城一角, 馴獸師朝右揮出扇形鞭打中一隻火蜥蜴(血條掉一截); 旁邊另一個馴獸師殘影示意翻滾穿過火圈預警範圍; 畫面下方三個鍵帽圖示「方向鍵 / Z / X」各自對應「走 / 揮鞭 / 翻滾」

## 第 2 頁 收服
- 文字: 打到殘血, 圈亮綠時揮鞭
- 圖要示意: 左右兩格 — 左: 殘血魔物身上的捕捉圈正亮綠, 一鞭揮下, 魔物被繩子套走(打勾); 右: 同一隻魔物捕捉圈是暗的, 一鞭揮下, 魔物倒地消失(打叉)

## 第 3 頁 表演
- 文字: Z 讓牠生氣, X 讓牠冷靜
- 圖要示意: 表演場上馴獸師兩個情境並排 — 左: 一圈鞭打範圍, 圈內魔物怒氣條往上、放出技能、金幣飛出; 右: 一圈哨音範圍, 圈內魔物怒氣條往下

## 第 4 頁 拿捏
- 文字: 越氣越賺, 滿了就失控
- 圖要示意: 一條怒氣條由左到右, 靠右的紅線段旁飛出大量金幣; 條的最右端(全滿)連到一隻撞破圍欄撲向觀眾的魔物(打叉); 下方小字流程「地下城 → 表演場 → 商店, 三天後評星」

## 自查(對照 spec「操作」)
| 動作 | 出現在 |

| 移動馴獸師 | 第 1 頁(表演場同樣用方向鍵, 第 3 頁圖中示意) |
| 揮鞭(打魔物) | 第 1 頁 |
| 揮鞭(亮綠時收服) | 第 2 頁 |
| 翻滾 | 第 1 頁 |
| 揮鞭(激怒)、吹哨(安撫) | 第 3 頁 |
| 吹哨制伏失控魔物 | 失控時 HUD 提示「追上去吹哨 3 次」 |
| 商店選項目 / 購買 / 出發 | 第 4 頁流程; 商店畫面底部顯示「↑↓ 選擇 Z 確定」 |
| 重來 | 結算畫面顯示「按 Z 重來」 |
| 結束條件 | 第 4 頁 |

不寫: 技能會打到其他魔物、改變牠們的怒氣(要驗玩家會不會自己發現並利用連鎖); 紅線區的確切範圍與倍率(怒氣條上標得出來, 表演時飄「紅線 ×2」); 越殘血亮綠越久(要驗玩家會不會自己摸出來); 同種再收服會升星(收服當下有「升星」飄字); 各種魔物對揮鞭的反應不同(要驗玩家能否自己感受到差異); 熔岩與水的效果(一踩就懂); 魔物在地下城的攻擊就是表演技能(要驗玩家會不會自己連起來)。

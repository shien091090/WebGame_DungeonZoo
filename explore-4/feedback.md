## game-a 紅線馴獸場
- 「我比較喜歡a款的戰鬥節奏」 → 對應機制: 鍵盤走位 + Z 揮鞭 + X 翻滾的即時戰鬥(推論)
- 「但可惜的是a款沒有做出殘血時要做某種比較有技術門檻的操作才能捕捉怪的設計」 → 對應機制: 捕捉圈一明一滅、亮綠瞬間揮鞭收服——只有按鍵時機, 技術門檻不足(推論)
- 「揮鞭激怒跟吹哨安撫我覺得都不錯,都是玩家控制場面的一種手段」 → 對應機制: 表演場 Z 揮鞭激怒、X 吹哨安撫
- 「怒氣卡在紅線區金幣加倍的設計我覺得更棒,這讓我會一直想設法去控制場面在"失控邊緣",如果控制的好,一直跳出加倍會很爽快」 → 對應機制: 怒氣 80~99 紅線區表演金幣加倍、滿 100 失控

## game-b 連鎖總機
- 「我喜歡彈反的感覺,但用來抓怪我覺得不搭,彈反可以設計成是戰鬥或表演過程中的一環,讓玩家有迴避攻擊的手段」 → 對應機制: 舉盾彈反; 使用者要的是把彈反當迴避 / 戰鬥手段, 不當捕捉手段
- 「B款選台座 點名表演 也有做出連鎖的感覺但就沒有那麼喜歡,可能是因為沒有那種怪物即時在場面上活動,場面隨時要失控的刺激感」 → 對應機制: 台座固定站位、總機式點名表演(推論)

- 戰鬥節奏最喜歡 A; 表演場最喜歡 A(揮鞭 / 吹哨 + 紅線加倍), 勝過 B 的點名式與 C 的驅趕式

## 不好的體驗
- A: 「a款沒有做出殘血時要做某種比較有技術門檻的操作才能捕捉怪的設計」 → 可能來源: 捕捉只靠單一按鍵時機
- B: 「彈反...用來抓怪我覺得不搭」 → 可能來源: 彈反同時是唯一攻擊與捕捉手段
- C: 「c款的表演模式我不喜歡,因為要控制怪只能在某個區域這件事情需要玩家一直不斷去把怪趕去某個地方,基本上只能看好一隻怪,要兼顧到兩隻就已經很困難了,這會讓我不想去抓更多怪」 → 可能來源: 表演 / 冷靜依賴把魔物趕到特定區域, 管理負擔隨魔物數線性上升, 反過來抑制捕捉動機

# 連鎖機關秀 — 玩家說明

翻頁: 按 Z 翻下一頁; 最後一頁按 Z 開始遊戲。每頁底部小字「按 Z 繼續」。

## 第 1 頁 地下城
- 文字: 方向鍵走, Z 攻擊, X 武器技
- 圖要示意: 地下城一角, 馴獸師拿棍棒朝右敲中一隻火蜥蜴(扇形攻擊特效); 旁邊一圈火圈預警, 馴獸師的移動箭頭繞開它。畫面下方三個鍵帽「方向鍵 / Z / X」各對應「走 / 攻擊 / 武器技」

## 第 2 頁 收服
- 文字: 殘血時站上去, 再繞牠一圈
- 圖要示意: 左右兩格。左: 馴獸師站在一隻帶虛弱記號的水母身上, 水母頭上「準備捕捉」字樣與圓圈進度條填到一半; 右: 套索連著頭頂冒暈眩星星的水母, 馴獸師沿一條繞著牠的箭頭路線跑, 魔物周圍的進度環填到一半。角落小圖: 進度環填滿, 魔物被收走(打勾)

## 第 3 頁 布置
- 文字: 開演前擺好魔物與機關, 開演後只能看
- 圖要示意: 表演場疊著 3×4 的格子, 其中幾格放著魔物、一格放著戰鼓; 游標框在一個空格上, 旁邊打開選擇面板(列出魔物與機關); 右下「開演」按鈕。下方一個小箭頭指向同一場地開演後的縮圖, 魔物在場上走動、放技能

## 第 4 頁 紅區
- 文字: 紅區最賺, 標記滿 5 個就失控
- 圖要示意: 上: 一隻魔物的怒氣條指在紅區段, 表演時飛出「×2」金幣; 下: 一隻魔物怒氣條全滿, 頭上排著 5 個失控標記, 撞破圍欄撲向觀眾(打叉)

## 第 5 頁 目標
- 文字: 7 天內賺到越多名聲越好
- 圖要示意: 一圈流程箭頭「地下城 → 布置 → 表演 → 商店」回到地下城, 圈中央寫「×7 天」; 表演那一格旁有名聲星星往上加, 終點是結算的評價星數

| 移動馴獸師 | 第 1 頁 |
| 武器普攻 / 武器技 | 第 1 頁 |

| 商店選項目 / 購買或裝備 / 出發 | 第 5 頁流程; 商店 HUD「↑↓ 選擇 Z 購買/裝備」 |

不寫: 「開演」上按 X 回第 1 步(游標移到「開演」時 HUD 會提示「Z 開演 X 回上一步」); 各武器的 X 技能內容(商店項目上有說明, 第一次買到就會試); 各機關的效果, 特別是火藥桶、水車、銅鑼會被技能觸發(選擇面板每項都有一句說明; 要驗玩家會不會自己排出連鎖路線); 技能會打到其他魔物、改變牠們的怒氣(要驗玩家會不會自己發現並利用); 各種魔物的移動習性與表演場上跟誰走(要驗玩家能否從地下城自己連起來); 同種再收服的等級效果(收服當下有「等級 +1」飄字, 上場時怒氣條紅區變長); 標記會自己慢慢消、被澆熄會少一個(場上看得到); 地下城解鎖條件(卡上寫著); 熔岩與水的效果(一踩就懂)。

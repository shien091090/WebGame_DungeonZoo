# 美術經驗提案(WebGame_DungeonZoo 打磨第 11 輪)

## 提案 1 — 放進「與規格的分界」, 新增一條經驗(掛 P2)

- 美術為了版面自己替規則清單設了顯示上限(例: `monsters.slice(0, 6)`), 規格沒寫上限; 之後規格把同一個欄位的意思改成「長度不限、一律全部畫」, 舊上限就悄悄把規則上存在的東西吃掉, 而且自測只餵規格當時的典型值(固定 3 隻)抓不到(大場面動物園 polish-11: 過場從「見習日固定 3 隻」改成「這趟收服幾隻就跟幾隻」, 製作人在欄位對照裡特別點名要拿掉 slice; 屬交接檢查, 非老闆回饋) → 「放不下」是美術自己的版面判斷, 卻做成了規則層的截斷, 也沒寫進 style.md, RD 和製作人都看不到 → 規格沒寫上限的清單一律全部畫, 放不下就改版面(捲動、縮小、排隊走進畫面), 不截斷; 真的要截, 用規格給的收合規則(例:「+N」)並寫進 style.md 的物件表; 自測要餵 0 個、規格典型值、和遠超版面的長度(本作餵 0 / 1 / 3 / 9 / 20)〔P2〕

# 音效經驗提案(DungeonZoo 打磨第 7 輪, 音效節點)

本輪沒有老闆的音效回饋, 以下兩條都是建置時的做法, 不是回饋修正, 聽感都待試玩; 由製作人判斷要不要收、或等試玩確認後再收。

## 提案 1 → 放進「素材來源」分類(新條目)

- `辨識` **一組成對的「目標出現 / 目標達成」音要約 1 秒, 現成短樂句不是全音階跑動就是太悶, 找不到彼此呼應的一對** → Kenney 音樂短樂句包上揚的撥弦 / 鋼鼓多是全音階跑動(聽起來像魔法, 不像收尾), 薩克斯起音 40~90 毫秒太慢; 勝利號角多半是好幾小節(10 秒以上) → OpenGameArt 上 Fupi 的「Win Jingle」(CC0, `https://opengameart.org/content/win-jingle`)同一段 2.1 秒的旋律附 17 種樂器的 WAV, 可以自己挑銅管 / 鋼鼓 / 撥弦分軌混音, 配合遊戲既有音色。成對事件取同一段旋律: 「出現」只放前兩個和弦、原速, 停在未解決的和弦; 「達成」放整句, 用視窗化 sinc 重新取樣加速 2 倍壓到約 1 秒, 收在主和弦, 前後呼應。要「比某音更大」時照「最響 50 毫秒響度」換算音量。(DungeonZoo 打磨第 7 輪的任務卡 / 任務完成, 效果待試玩)

## 提案 2 → 放進「技術」分類, 合併到「本機沒有 ffmpeg, Python 與 npm 又被權限擋住」那一條的(續)

- (續)權限設定下, 暫存資料夾的 `mkdir`、`cd`、複合指令(`;`、`&&`)和指令前的環境變數(`X=1 node ...`)都可能要人工核准, 無頭模式等於直接失敗 → 一行只放一個指令; 下載用 `curl --create-dirs -o <暫存資料夾>/<新子資料夾>/檔名` 順便建資料夾; 量測腳本用 Write 工具寫進暫存資料夾, 參數用命令列旗標傳(例 `-p`), 不用環境變數; 讀暫存資料夾的內容用 Glob / Grep 工具而不是 `ls`。上一輪抓下來的解碼器(暫存資料夾的 `node_modules`)沒被清掉時可以直接沿用, 先用 Glob 找 `**/ogg-vorbis/package.json`。(DungeonZoo 打磨第 7 輪 build)

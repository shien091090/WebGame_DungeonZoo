# 魔物大遊行 — 玩家說明

翻頁: 點畫面任意處翻下一頁; 最後一頁點畫面開始遊戲。每頁底部小字「點畫面繼續」。

## 第 1 頁 帶隊
- 文字: 隊伍會跟著游標走
- 圖要示意: 地下城走道裡, 馴獸師在前、身後一隻火蜥蜴、再後面一串繩子; 游標在前方轉角, 虛線箭頭示意隊頭朝游標轉彎、整條隊伍沿同一條路跟上

## 第 2 頁 圍圈
- 文字: 繞一圈圍住魔物, 削牠體力
- 圖要示意: 隊伍繞成一個圈, 隊頭碰到自己的繩子, 圈的形狀亮起; 圈中央一隻野生魔物頭上的體力格少了一格

## 第 3 頁 收服
- 文字: 體力歸零, 牠就加入隊伍
- 圖要示意: 左右兩格 — 左: 野生魔物體力格只剩最後一格, 被圈住; 右: 牠戴上項圈、排到隊伍魔物的最後面, 隊伍變長一節

## 第 4 頁 遊行
- 文字: 夠氣就表演, 太氣會脫隊
- 圖要示意: 遊行園區, 隊伍經過看台, 一隻怒氣條過半的魔物朝看台放技能、觀眾歡呼、金幣飛出; 另一隻怒氣條全滿的魔物離開隊伍衝向看台(打叉); 底部小字流程「地下城 → 遊行 → 商店, 三天後評星」

## 自查(對照 spec「操作」)
| 動作 | 出現在 |
|---|---|
| 翻頁 / 開始 / 標題卡開始 | 頁首說明; 標題卡顯示「點畫面開始」 |
| 帶隊伍前進、轉彎 | 第 1 頁 |
| 圍圈(削體力、收服) | 第 2、3 頁 |
| 圍回失控魔物 | 失控時 HUD 提示「繞一圈把牠圍回來」 |
| 購買強化 / 出發 | 第 4 頁流程; 商店項目與「出發」按鈕本身有文字 |
| 重來 | 結算畫面顯示「點畫面重來」 |
| 結束條件 | 第 4 頁 |

不寫: 每種魔物生氣的原因不同(要驗玩家能否自己察覺並據此規劃路線); 地下城被打到的隊伍魔物會帶怒氣回園(要驗玩家會不會自己發現); 表演技能會打到同伴; 項圈用完就只能打倒(HUD 有項圈數, 用完時一圍就懂); 魔物在地下城的攻擊就是表演技能(要驗玩家會不會自己連起來)。

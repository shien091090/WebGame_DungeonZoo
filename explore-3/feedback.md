## game-a 怒火連鎖馴獸場
- 「a款表演場上當怪物攻擊到怪物會產生連鎖反應這點我覺得很驚喜,感覺可以玩出很多花樣」 → 對應機制: 表演場上魔物技能互相命中, 點火 / 澆熄造成即時連鎖(推論)

## game-b 幕間連鎖秀
- 「b款怪物有連鎖反應的表現我很喜歡,但同樣是怪物間的連鎖我更喜歡a款那種即時一點的」 → 對應機制: 排站位後自動演出的接力連鎖; 使用者偏好 A 的即時連鎖勝過 B 的預排自動連鎖(推論)

## game-c 魔物大遊行
- 「用繩索繞一圈捕捉的設計我很喜歡,因為我覺得"捕捉"這件事情可以做出一點技術門檻,不用太難,比起直接丟一個道具捕捉,我更喜歡透過某種操作後捕捉,且我覺得可以加上殘血更容易捕捉或是一定要殘血才能捕捉的機制,讓捕捉除了要有一點技術以外還要抓準時機」 → 對應機制: 繞圈圍住捕捉(操作型捕捉); 使用者提議加上殘血門檻 / 殘血加成, 讓捕捉同時要技術與時機

## 跨款比較
- 「所有用滑鼠操作的體驗我都不喜歡,操作起來很卡很不好操作,我比較喜歡用鍵盤操作的感覺」
- 連鎖: 「同樣是怪物間的連鎖我更喜歡a款那種即時一點的」

## 不好的體驗
- 全部滑鼠操作款(A、C): 「操作起來很卡很不好操作」 → 可能來源: 角色跟著游標移動 / 滑鼠甩鞭
- B 地下城: 「不太喜歡,因為我基本上躲在角落等到怪暈再過去就好了,等待的時間就是在發呆,完全沒有"因為我做了什麼而成功捕捉"的成就感和投入感」 → 可能來源: 讓魔物放空招累暈才能裝籠, 最佳策略是躲角落等待; 捕捉成功與玩家操作無關
- C 遊行經營: 「不太喜歡,因為我無法控制怪不生氣,怒氣一定會滿=一定會脫隊,我不喜歡這種無法控制怪物怒氣值的感覺」 → 可能來源: 怒氣只會上升、玩家沒有降怒手段, 脫隊是必然
- C 遊行經營: 「而且脫隊只要繞一圈就能圈回來,表示我可以一直在遊客前原地繞圈就好,一生氣就圈回來,這樣操作很無腦,不喜歡」 → 可能來源: 圍回脫隊魔物的代價太低, 最佳策略是在看台前原地繞圈

# 怒火連鎖馴獸場 — 玩家說明

翻頁: 點畫面任意處翻下一頁; 最後一頁點畫面開始遊戲。每頁底部小字「點畫面繼續」。

## 第 1 頁 地下城
- 文字: 馴獸師跟著游標走
- 圖要示意: 地下城一角(走道接到熔岩洞), 游標箭頭在前方, 馴獸師朝它走去; 旁邊一隻火蜥蜴的火圈預警範圍, 虛線箭頭示意馴獸師繞開火圈

## 第 2 頁 收服
- 文字: 點一下甩鞭, 虛弱時再甩就收服
- 圖要示意: 左右兩格 — 左: 馴獸師身邊一圈甩鞭範圍, 圈內魔物血條往下掉; 右: 同一隻魔物血條很低、標著虛弱, 再一圈甩鞭, 魔物被繩子套走(打勾)

## 第 3 頁 表演
- 文字: 甩鞭讓魔物生氣, 夠氣就表演
- 圖要示意: 表演場上馴獸師身邊一圈甩鞭範圍, 圈內魔物怒氣條升到過半、放出技能、金幣與名聲飛出; 圈外一隻怒氣條低、沒動作

## 第 4 頁 別讓牠爆掉
- 文字: 怒氣滿了會衝去咬觀眾
- 圖要示意: 一隻怒氣條全滿的魔物撞破圍欄撲向觀眾(打叉); 下方小字流程「地下城 → 表演場 → 商店, 三天後評星」

## 自查(對照 spec「操作」)
| 動作 | 出現在 |
|---|---|
| 翻頁 / 開始 / 標題卡開始 | 頁首說明; 標題卡顯示「點畫面開始」 |
| 移動馴獸師 | 第 1 頁(表演場同樣跟游標, 第 3 頁圖中示意) |
| 甩鞭(打魔物 / 收服) | 第 2 頁 |
| 甩鞭(激怒) | 第 3 頁 |

| 重來 | 結算畫面顯示「點畫面重來」 |
| 結束條件 | 第 4 頁 |

不寫: 技能會打到其他魔物、改變牠們的怒氣(本款要驗玩家會不會自己發現並利用連鎖); 同種再收服會升星(收服當下有「升星」飄字, 遊戲自己會提示); 各種魔物對甩鞭的反應不同(要驗玩家能否自己感受到差異); 熔岩與水的效果(一踩就懂); 魔物在地下城的攻擊就是表演技能(要驗玩家會不會自己連起來)。

## 形狀語言
扁平填色 + 深色細描邊; 生物圓潤有眼睛, 場景(地板、牆、步道)平塗無描邊無眼; 危險一律用**尖鋸齒 / 爪痕 + 紅色**, 可行一律用**綠色圓圈 / 勾**, 選中一律用**白粗框**。

## 理念落實
- P0 辨識度先於好看: 四種魔物用完全不同的剪影(蜥蜴有尾火、水母有觸手、雷鳥有翅與閃電冠、石像鬼方身帶角), 縮小到候展卡也分得出; 背景一律低彩低亮。
- P1 視覺權重跟決策迫切度: 最亮最飽和的只留給要做決定的東西 — 疲憊的綠圈(現在可以引牠踩夾)、失控的紅鋸齒、閘門鍵帽; 草地、地板、步道全壓在暗色。
- P2 規則上存在就畫出來: 疲憊門檻在魔物血條上畫 50% 刻度、怒氣條在 40 畫白刻度(表演門檻); 暈住畫白星 + 漩渦眼; 閘門上直接畫它對應的按鍵(← ↓ →); 怒氣 <40 的魔物畫成趴著睡(不表演)。
- P3 一本字典: 紅 = 危險 / 傷你、綠 = 可行 / 成功、金 = 錢、粉星 = 名聲、白粗框 = 選中, 全畫面(地下城、動物園、商店、結算、說明頁)共用; 說明頁的物件全部直接呼叫遊戲內函式。
- P4 兩條通道: 開 / 關閘門 = 綠色門板 + 中間空出 vs 灰白斜紋橫桿擋住; 夾住 / 夾壞 = 綠勾 + 外擴圈 vs 紅叉 + 兩半裂開; 你打到魔物(白閃 + 白劍弧)vs 魔物打到你(紅爪痕 + 你身體變紅); 名聲增減 = 粉 / 紅 + 往上飄 / 往下沉。
- P7 每個元素掙版面: 廣場人數只出一個數字(不另畫格子條重述); 魔物頭上不放種類字樣; HUD 不放捕獲數。
- P9 最混亂的那一刻: 遊客衣服用低彩四色, 觀賞區擠滿人時仍讓魔物、怒氣條與紅鋸齒跳出來; 所有飄字有 6px 深色外描。
- P13 事件排隊: 本作事件回饋都長在各自的物件上(夾子、魔物、飄字), 不共用中央版位; 失控訊息固定在 HUD 第二列, 不與其他事件疊。
- P15 強度對份量: 表演 = 四顆小金幣(小); 夾住 = 綠勾 + 外擴圈(中); 失控 = 整隻紅鋸齒光環 + 圍欄紅鋸齒框 + 破口(大)。
- P17 圖形與數字分工: 魔物血條不寫數字, 圖形的任務是「離 50% 疲憊刻度還多遠」; 怒氣條同理只標 40 表演線, 精確值不顯示; 玩家血量 HUD 才給精確數字。
- P18 不只一瞬間: 金幣與名聲的累計常駐 HUD 右上, 結算再列總名聲與累計金幣; 飄字只是當下回饋。
- P19 資訊貼著物件: 疲憊圈畫在魔物腳下、怒氣條畫在每隻魔物身下、按鍵畫在閘門上、廣場人數畫在廣場下緣(y 1020)而非 HUD。
- P21 選分岔的例子: 說明第 2 頁並排「疲憊 → 夾住」與「滿血 → 夾壞」, 只差血量那一項; 第 5 頁三欄只差觀看人數。

### HUD 版面(`drawHud`)
- `phase` 為 `guide` 或 `result` 時**什麼都不畫**
- 其餘: y 0~140 深色帶。第一列(y 42): 左「第 N 天」+ 階段名(地下城 · 第 F 層 / 擺放魔物 / 開園中 / 商店); 右金幣(x 466 起)、名聲(x 600 起)
- `dungeon`: 第二列(y 100)血條 + 「hp/maxHp」、夾子圖示(實 = 剩、空圈 = 用掉, 共 trapMax 個); `message` 畫在下方訊息區膠囊(y 1060~1120); 下方 y 1180~1235 常駐按鍵提示(方向鍵 移動 / 撞魔物攻擊、空白 放夾子)
- `open`: 第二列左剩餘秒數(≤10 變紅); 有 `message` 時第二列右側紅框膠囊(x 160~696, 失控警告用); 廣場人數「廣場 n/max」畫在廣場下緣 (40, 1020), 達 max−2 變紅
- `place` / `shop`: `message` 畫在第二列整條膠囊; `place` 另在 (24, 1024) 畫「候展區」小標
- RD 不需另畫任何 HUD 文字

### 說明頁內容(每頁的示意)
0 地下城: 5×5 格地圖, 上方樓梯, 你往上撞火蜥蜴(受擊、血條少), 你身旁三個方向箭頭, 右邊水母虛線箭頭「牠也走一步」
1 捕獲: 左「疲憊(血 ≤ 一半)」→ 夾住 ✓; 右「滿血」→ 夾壞 ✕ 且牠暈住
2 擺放: 三展區中間選中 + ← → 鍵帽; 候展區最前那隻綠箭頭「↑ 放入」; 灰虛線「↓ 取回」; Enter 開園
3 閘門: 入口 → 廣場遊客 → 三閘門(左關)→ 綠虛線只往中、右
4 人潮與怒氣: 沒人看(趴著、條低)/ 幾個人看(表演、金幣 +6)/ 擠滿(失控、圍欄破、兩個嚇跑遊客打叉)
5 流程: 地下城 → 擺放 → 開園 → 商店 一圈, 中央「第 1~3 天」, 開園指向「結算」粉星

### 取捨說明(給製作人驗收)
- 圍欄線: spec 寫 y 510, 介面判定框到 y 500; 依「畫面邊界 = 判定邊界」畫在框內。
- 閘門「關」不用紅色: 紅在本作只代表危險 / 傷你, 關閘門是玩家的調度手段, 改用灰白斜紋橫桿 + 擋滿全寬表達「過不去」。
- 動態只用在有意義處: 受擊與失控的抖動、夾子事件 0.5 秒、飄字; 沒有任何常駐呼吸 / 背景動畫。抖動以系統時間決定, 不需 RD 傳參數。

# 人潮閘門動物園(設局誘導的聰明感)

## 概述
地下城是網格回合制: 玩家走一步魔物就走一步, 撞魔物就是攻擊; 捕獲靠放捕獸夾, 把魔物打到疲憊後引牠自己踩上去。動物園不直接碰魔物: 開園後遊客自己逛, 玩家只能開關三道閘門調度人潮——圍觀的人越多魔物越氣、表演越賺, 人太多就失控傷人, 要把人流導開才能讓牠冷靜。三天後依名聲評星。
驗證假設: H01~H06、H31~H35。

## 核心循環
在地下城算好魔物的走法, 打一下、退一步、讓牠踩夾子 → 抓到的魔物放進三個展區 → 開園後看人潮與怒氣, 開關閘門把遊客往該去的展區送 → 賺金幣與名聲 → 買強化 → 隔天地下城魔物更硬也抓得到, 展區陣容更強、要調度的更多。

## 規則

### 流程
1. 開始畫面顯示說明頁(共 6 頁), 按 Enter 翻頁, 最後一頁按 Enter 進入第 1 天
2. 每天依序: 地下城(2 層)→ 擺放 → 開園(60 秒)→ 商店; 第 3 天開園結束後不進商店, 直接進結算
3. 結算後按 Enter 重來, 回到第 1 天地下城(不再顯示說明頁), 所有數值重置

### 地下城(網格回合制)
4. 每層是 7 欄 × 9 列的格子; 隨機 6 格牆壁; 玩家起點在最下列中間, 樓梯在最上列隨機一格; 生成後檢查起點到樓梯有路, 沒路就重生
5. 每層魔物數: 第 1 天 3 隻、第 2~3 天 4 隻; 種類隨機, 放在上方 5 列的空格(不放樓梯上)
6. 魔物血量 + 2×(天數 − 1)
7. 方向鍵: 往該方向走一格。目標是牆或邊界 → 不動、不算一回合; 目標有魔物 → 不移動, 改為攻擊牠(扣攻擊力的血), 算一回合
8. 空白鍵: 在腳下放一個捕獸夾(夾數 > 0 且腳下沒有夾子才可放, 每放 −1), 算一回合; 玩家自己踩夾子不會觸發
9. 玩家每做完一回合, 所有魔物依序行動一次(依種類):
   | 種類 | 行動 |
   |---|---|
   | 火蜥蜴 | 走 1 格靠近玩家 |
   | 雷鳥 | 最多走 2 格靠近玩家 |
   | 石像鬼 | 每 2 回合才行動一次, 走 1 格 |
   | 水母 | 玩家在曼哈頓距離 3 格內才靠近, 否則隨機走 1 格(四方向擇一可走的, 都不能走就不動) |
10. 魔物行動開始時若與玩家上下左右相鄰 → 攻擊玩家(扣魔物攻擊力的血), 不移動; 雷鳥走完第 1 格後相鄰就停下, 不再走第 2 格
11. 「靠近玩家」: 優先走能讓與玩家曼哈頓距離變小、且差距較大那一軸的方向; 被牆、魔物、樓梯擋住就試另一軸; 都不行就不動。魔物看不到夾子, 會照走
12. 魔物走進有捕獸夾的格子: 立即停止該次行動, 然後
    - 魔物血量 ≤ 最大值的 50%(疲憊)→ 捕獲成功: 魔物離場, 加入候展區; 夾子消失
    - 否則 → 夾子壞掉消失, 魔物下 1 次行動跳過(暈住)
13. 魔物血量 ≤ 50% 時顯示疲憊標記
14. 魔物血量歸零: 打倒, 消失並得金幣
15. 玩家走上樓梯: 第 1 層 → 生成第 2 層(血量與夾數延續); 第 2 層 → 結束地下城進入擺放
16. 玩家血量歸零: 立即結束地下城進入擺放, 已捕獲的魔物保留
17. 每天出發時血量回滿、夾數補到上限
18. 地下城 HUD 顯示提示「走到樓梯前往下一層」

### 擺放
19. 動物園有左、中、右 3 個展區, 每區最多 2 隻魔物; 已放好的魔物跨天保留
20. 畫面下方候展區排著還沒放的魔物(依捕獲順序)
21. ← →: 切換選中的展區
22. ↑: 把候展區最前面一隻放進選中展區(展區已滿或候展區空則無效)
23. ↓: 把選中展區最後放的一隻取回候展區最前面
24. Enter: 開園(展區全空也可以開園); 沒放的魔物今天不上場
25. 擺放時 HUD 顯示提示「←→選區 ↑放入 ↓取回 Enter開園」

### 開園(即時, 60 秒)
26. 版面由下往上: 入口 → 廣場 → 3 道閘門(對應 3 個展區)→ 各展區的觀賞區 → 展區圍欄
27. 遊客每隔一段時間從入口進來, 走到廣場, 再從開著的閘門中隨機挑一道走過去; 所有閘門都關著就留在廣場等
28. 遊客到觀賞區隨機一個位置停下觀看 8 秒, 然後從展區上方出口離開(不經過閘門)
29. 閘門只擋「還沒通過」的遊客; 已經在觀賞區的遊客不受閘門開關影響, 看完才走
30. 廣場等待遊客超過 12 人時, 最早到的那位直接離開, 名聲 −1
31. 開園時 3 道閘門都開; ← / ↓ / →: 切換左 / 中 / 右閘門的開關
32. 「觀看人數」= 該展區觀賞區正在觀看的遊客數
33. 展區內每隻魔物怒氣每秒 + 觀看人數 × 1.0 × 種類怒氣係數; 觀看人數為 0 時每秒 −5; 開園起始怒氣 20, 範圍 0~100
34. 怒氣 ≥ 40: 每 2.5 秒表演一次; 得金幣 = 種類金幣 ×(1 + 0.2 × 觀看人數)×(1 + 名聲/100) 四捨五入; 觀看人數 ≥ 1 時名聲 +1
35. 怒氣達 100: 魔物失控, 該段圍欄破掉; 每 1 秒嚇跑該展區觀賞區 1 名遊客(遊客跑掉), 名聲 −2; 失控魔物不表演
36. 失控中的展區連續 4 秒沒有遊客觀看 → 魔物冷靜: 怒氣 30, 圍欄修好
37. 有魔物失控時, HUD 訊息顯示「把人潮導開, 牠才會冷靜」
38. 60 秒到: 仍失控的魔物每隻名聲 −5; 全部恢復
39. 名聲最低 0

### 商店
40. 列 4 項強化; ↑↓ 選項目, 空白鍵購買(金幣不足無效), 每項可重複買, 每買一次價格 ×1.5 四捨五入
41. Enter: 出發進入下一天
42. 商店 HUD 顯示提示「↑↓選 空白鍵買 Enter出發」

### 結算
43. 顯示總名聲、累計賺得金幣、評價星數(門檻見數值表)
44. 按 Enter 重來

## 操作
只用鍵盤。
| 玩家動作 | 操作 |
|---|---|
| 說明翻頁 / 開始 | Enter |
| 移動 / 攻擊 | 方向鍵(撞魔物即攻擊) |
| 放捕獸夾 | 空白鍵 |
| 下一層 / 離開地下城 | 走上樓梯 |
| 選展區 | ← → |
| 放入魔物 | ↑ |
| 取回魔物 | ↓ |
| 開園 | Enter |
| 開關左 / 中 / 右閘門 | ← / ↓ / → |
| 商店選項目 | ↑ ↓ |
| 購買強化 | 空白鍵 |
| 前往下一天 | Enter |
| 重來 | 結算畫面按 Enter |

## 勝負與結束
- 沒有失敗結局; 第 3 天開園結束後進入結算, 以總名聲換評價星數
- 結算畫面按 Enter 重來, 從第 1 天地下城開始

## 範圍邊界
- 只做一關(3 天), 不做難度曲線、存檔、音效
- 不做地下城視野、道具撿取、多種夾子
- 不做直接碰魔物的經營動作(安撫、餵食); 動物園只有閘門
- 不做遊客種類、門票、展區擴建
- 不做魔物升級與出售

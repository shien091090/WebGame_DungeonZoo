# 怪獸夜場節目單 — 美術規格(RD 只讀這份)

> `index.html` 必須宣告 `<meta charset="utf-8">`, 否則 art.js 裡的中文會變亂碼。
> `art.js` 用一般 `<script src="art/art.js">` 載入(非 module), 產生全域 `window.Art`。每個函式自己 save / restore。

## 邏輯畫布尺寸

**720 × 1280**(直式)。`Art.canvas = { width: 720, height: 1280 }`。所有座標都是邏輯像素。

## 形狀語言

圓角卡片 + 粗深色外描的扁平幾何; **可點 / 選中 = 象牙白粗框**, **危險 = 紅 + 鋸齒**(敵方底座、失控外圈、失控卡內圈), 我方 = 藍色平滑橢圓底座; 箭頭一律圓頭線段, 不用尖刺三角。

## 理念落實

- **P0 辨識度先於好看**: 魔物種類用輪廓 + 色相兩條通道; 敵我用位置 + 底座形狀(藍平滑 vs 紅鋸齒)+ 敵方皺眉紅瞳三條; 背景全部壓暗低飽和, 不跟物件搶。
- **P1 視覺權重跟著決策迫切度走**: 排節目時玩家要決定的是「誰的怒氣到哪了」, 所以後台卡上怒氣條是卡片上最亮最粗的元素(14px 高、帶 40/80 刻度); 戰鬥時敵人的血條在敵人頭上最顯眼(決定丟不丟籠)。
- **P2 規則上存在的東西畫面上就要存在**: 40(能演)/ 80(大場面)兩個門檻直接畫成怒氣條上的象牙白刻度; 失控(100)整條變紅並寫「爆」; 冷場有自己的灰色結果條; 本格加成有 ×2 徽章; 已用掉的籠子在 HUD 變暗。
- **P3 一個意義一種長相**: 象牙白只代表「可點 / 選中」(編隊卡、後台卡、可放的節目格、可按按鈕); 金色只代表金幣與「現在演到這格」; 紅只代表危險與損失; 怒氣三段色在編隊卡、戰鬥中的魔物、後台卡、說明頁全部同一套。說明頁示意圖全部直接呼叫遊戲內畫法。
- **P4 關鍵區分至少兩條通道**: 成功 = 綠色 + 勾, 冷場 = 灰色 + 「冷場」字 + 魔物轉灰; 捕獲 = 綠環 + 勾, 破掉 = 籠子裂成兩半 + 紅叉; 失控卡 = 紅底 + 鋸齒內圈 + 「失控!」; 選中 = 象牙白框 + 底色變亮 (+ 編隊卡「出戰」帶)。
- **P7 每個元素都要掙得版面**: 敵人不另標捕獲率(血條已表達), 英雄不掛名牌(輪廓已表達), 我方魔物只留血條 + 怒氣條 + 怒氣數字。
- **P9 以最混亂的那一刻驗收**: 所有文字都帶深色外描; 演出中同時有舞台動畫、技能名牌、飄字、後台怒氣變化時, 技能的區域演出只走卡片之間的縫、不壓怒氣條。
- **P13 事件要排隊**: 技能名牌固定在舞台上簷下方(y 172~228), 「大場面!」固定在舞台前緣(y≈462), 兩者同一刻觸發也不疊; 飄字由 RD 依序產生, 美術讓每則 1.3 秒內淡出。
- **P15 回饋強度跟事件份量成正比**: 冷場(名聲 −1)只把舞台調冷、觀眾打呵欠; 成功 = 聚光 + 舉手; 大場面 = 再加旋轉金光、彩紙、「大場面!」; 失控(名聲 −8)= 全舞台紅閃 + 鋸齒紅圈 + 觀眾四散。
- **P17 進度圖形與數字分工**: 怒氣條負責「離 40 / 80 / 100 還差多遠」(刻度), 數字負責精確值; HUD 演出時數字給「第幾格」, 圓餅只畫**這一格**剩下的 4 秒。
- **P18 重要資訊不能只閃一下**: 每格的成敗留在節目格底部(勾 / 冷場)直到當晚結束; 金幣與名聲常駐 HUD。
- **P19 資訊貼著物件**: 血條、怒氣條都長在單位本身底下; 本格加成的 ×2 貼在那一格的角上; 炒熱 / 鎮定的箭頭畫在後台區, 暖場的火光掃過節目表那一列。
- **P21 示意圖選分岔的例子**: 說明第 2 頁並排「血很少 → 收進籠子」與「滿血 → 籠子破掉」; 第 5 頁三張同一隻魔物只差怒氣, 對照冷場 / 成功 / 失控。

## 繪製層級(建議 RD 照這個順序)

1. `drawBackground`
2. 場景: `drawBattleField`(戰鬥)或 `drawStage`(排節目 / 演出)
3. 物件: 敵人 → 英雄 / 我方魔物 → 捕獸籠; 或 節目格 → 後台卡; 或 編隊卡 / 商店項目
4. `drawButton`
5. `drawSkillEffect`
6. `drawFloatText`
7. `drawHud`
8. `drawResultPanel`(結算時, 蓋全畫面)
9. 說明頁: RD 的頁面底 → `drawGuidePage` → RD 的文字

## 取捨說明(給製作人驗收)

- HUD 的操作提示(「點敵人丟籠」「點魔物, 再點格子」等)由美術依 phase 直接畫; RD 若把同一句放進 `message` 也不會重複(message 會取代提示)。
- 技能演出介面沒給位置: 名牌放在舞台上簷下方(事件當下沒有決策資訊), 區域演出長在被影響的地方(暖場 → 節目表、炒熱 / 鎮定 → 後台區、壓軸 → 舞台), 炒熱 / 鎮定的箭頭只走後台卡之間的縫(x = 20 / 190 / 360 / 530 / 700), 不壓怒氣條。
- 技能名牌寫出效果(例「後台怒氣 +20」): guide 刻意不教技能, 但觸發當下寫出來是讓玩家「發現」順序組合的唯一途徑, 這是演出, 不是說明頁。

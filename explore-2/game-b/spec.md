# 怪獸夜場節目單(排好節目、看整場大場面自動展開)

## 概述
地下城是自動戰鬥配隊: 玩家只挑誰跟英雄一起出戰、看準時機對敵人丟捕獸籠; 出戰的魔物打越多越生氣, 帶著怒氣回園。動物園是排節目表: 把魔物排進一晚的節目格子, 按開演後整場自動演出——後台等越久越氣、上台表演會消氣、物種技能會影響後面的節目, 排錯就有魔物在後台爆掉。三天後依名聲評星。
驗證假設: H01~H06、H25~H30。

## 核心循環
挑隊出戰 → 看自動戰鬥, 挑敵人丟籠捕獲 → 回園看每隻魔物的怒氣, 排出演順序 → 開演, 看整晚節目一格一格自動展開, 好的順序連成大場面 → 賺金幣與名聲 → 買強化(英雄、籠子、加場、隊伍名額)→ 隔天抓更多魔物、排更長更賺的節目單。

## 規則

### 流程
1. 開始畫面顯示說明頁(共 6 頁), 點畫面翻頁, 最後一頁點畫面進入第 1 天
2. 每天依序: 編隊 → 地下城(3 場戰鬥)→ 排節目 → 演出 → 商店; 第 3 天演出結束後不進商店, 直接進結算
3. 開局名單上有 1 隻火蜥蜴
4. 結算後點畫面重來, 回到第 1 天編隊(不再顯示說明頁), 所有數值重置

### 編隊
5. 畫面列出名單上所有魔物卡片(種類、血量、目前怒氣); 點卡片切換「出戰 / 不出戰」, 出戰數不超過隊伍名額
6. 英雄固定出戰, 不佔名額
7. 點「出發」進入地下城; 沒選魔物也能出發

### 地下城(自動戰鬥)
8. 每天 3 場戰鬥, 敵人數依序 2、3、3 隻, 種類隨機(4 種之一); 敵人血量 ×(1 + 0.4×(天數 − 1)) 四捨五入、攻擊 +(天數 − 1)
9. 我方(英雄 + 出戰魔物)排在下排, 敵人排在上排
10. 每個單位依自己的攻擊間隔自動攻擊一次: 目標從對面存活單位中隨機挑一個, 扣等於攻擊力的血
11. 出戰魔物每攻擊一次怒氣 +8, 每被打一次怒氣 +5(上限 99)
12. 敵人血量歸零: 打倒, 消失並得金幣
13. 我方魔物血量歸零: 倒下, 當天不再參戰(當晚仍可上節目), 怒氣 +30(上限 99)
14. 捕獸籠: 點一隻敵人即丟籠(籠數 > 0 才丟得出, 每丟 −1); 成功率 = 1 − 剩餘血量 / 最大血量 + 籠子強化加成, 最低 10%、最高 95%
15. 捕獲成功: 敵人離場加入名單(名單已滿則籠子不丟出, HUD 訊息「名單滿了」); 失敗: 籠子破掉, 敵人不受影響
16. 戰鬥中 HUD 顯示提示「點敵人丟籠」
17. 敵人全部離場: 1 秒後自動進下一場; 第 3 場結束進入排節目
18. 英雄血量歸零或按「撤退」按鈕: 立即結束地下城進入排節目; 已捕獲的魔物保留
19. 英雄與魔物血量在當天戰鬥間不回復; 每天出發時全部回滿, 籠數補到上限
20. 新抓到的魔物怒氣為 20, 血量全滿

### 排節目
21. 進入排節目時, 未出戰魔物怒氣設為 20; 出戰魔物保留地下城累積的怒氣
22. 畫面上方是節目表(格數 = 場次數), 下方是後台名單卡片(顯示種類與怒氣)
23. 點名單卡片選中, 再點一個節目格把牠排進去(格子原本有魔物則替換); 點已排好的格子清空
24. 同一隻魔物可以排進多個格子
25. 空格也能開演
26. 點「開演」按鈕開始演出; 開演後不能再改節目表
27. 排節目時 HUD 顯示提示「點魔物, 再點格子」

### 演出(自動, 每格 4 秒)
28. 依節目表從第 1 格開始, 每格輪到時, 該格的魔物上台:
    - 該魔物怒氣 ≥ 40 → 表演成功: 得金幣 = 種類金幣 × 怒氣 / 50 × 本格加成 ×(1 + 名聲/100) 四捨五入; 名聲 +2(怒氣 ≥ 80 時名聲 +4, 標示「大場面」); 接著觸發種類技能
    - 怒氣 < 40、或空格、或該魔物已失控 → 冷場: 名聲 −1
29. 種類技能(只在表演成功時觸發):
    | 種類 | 技能 | 效果 |
    |---|---|---|
    | 火蜥蜴 | 暖場 | 下一格的金幣 ×2 |
    | 雷鳥 | 炒熱 | 後台所有魔物怒氣 +20 |
    | 水母 | 鎮定 | 後台所有魔物怒氣 −25 |
    | 石像鬼 | 壓軸 | 本格金幣再 ×(1 + 0.5 × 本晚之前已成功的格數) |
30. 每格結束時: 剛表演的魔物怒氣 −35(最低 0); 這格沒上台的所有魔物(後台)怒氣 +12
31. 「後台」= 名單上這一格沒在台上、也沒失控的魔物
32. 每次怒氣變動後, 後台有魔物怒氣 ≥ 100 → 該魔物失控: 衝出後台攻擊觀眾, 名聲 −8, 本晚剩下排到牠的格子都冷場; 失控魔物不再增減怒氣
33. 演出中節目表標出目前演到第幾格; 後台卡片即時顯示怒氣
34. 全部格子演完, 進入商店; 失控魔物隔天恢復正常
35. 名聲最低 0

### 商店
36. 列 5 項強化, 點項目即購買(金幣不足不能按), 每項可重複買(有上限的到上限後不能按), 每買一次價格 ×1.5 四捨五入
37. 點「出發」按鈕進入下一天編隊

### 結算
38. 顯示總名聲、累計賺得金幣、評價星數(門檻見數值表)
39. 點畫面重來

## 操作
只用滑鼠。
| 玩家動作 | 操作 |
|---|---|
| 說明翻頁 / 開始 | 點畫面任意處 |
| 選出戰魔物 / 取消 | 編隊時點魔物卡片 |
| 出發 | 點「出發」按鈕 |
| 丟捕獸籠 | 戰鬥中點敵人 |
| 撤退 | 點「撤退」按鈕 |
| 選後台魔物 | 排節目時點名單卡片 |
| 排進節目格 | 選中後點節目格 |
| 清空節目格 | 點已排好的節目格(沒選中魔物時) |
| 開演 | 點「開演」按鈕 |
| 購買強化 | 點商店項目 |
| 重來 | 結算畫面點任意處 |

## 勝負與結束
- 沒有失敗結局; 第 3 天演出結束後進入結算, 以總名聲換評價星數
- 結算畫面點任意處重來, 從第 1 天編隊開始

## 範圍邊界
- 只做一關(3 天), 不做難度曲線、存檔、音效
- 不做戰鬥中手動攻擊、技能、站位; 戰鬥只有丟籠與撤退
- 不做演出中途介入(暫停、換節目、安撫)
- 不做魔物升級、出售、技能在戰鬥中的效果
- 不做演出結果預覽, 怒氣變化由玩家自己推想

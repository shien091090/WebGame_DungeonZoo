# 鞭響大場面(親自下場的即時驚險)

## 概述
地下城是即時閃避彈幕: 角色跟著游標移動、自動射擊, 把魔物打到虛弱後親手丟球捕獲; 動物園沒有籠子, 魔物全放進一座表演場自由走動, 馴獸師親自下場揮鞭把牠們激怒來表演, 同時閃開牠們表演時放出的技能、制伏失控衝向觀眾的魔物。三天後依名聲評星。
驗證假設: H01~H06、H19~H24。

## 核心循環
地下城閃彈幕、射擊, 看準虛弱的魔物丟球 → 抓到的魔物進表演場 → 在魔物群裡穿梭揮鞭, 讓牠們夠生氣而表演、邊閃技能邊顧著別讓誰爆掉 → 賺到金幣與名聲 → 買強化 → 隔天彈幕更密的魔物也打得過、抓得到, 表演場的陣容更大、場面更亂更賺。

## 規則

### 流程
1. 開始畫面顯示說明頁(共 5 頁), 點畫面翻頁, 最後一頁點畫面進入第 1 天
2. 每天依序: 地下城(45 秒)→ 表演場(50 秒)→ 商店; 第 3 天表演結束後不進商店, 直接進結算
3. 地下城與表演場開始前各有一張標題卡(「第 N 天 地下城」/「第 N 天 表演場」), 點畫面開始
4. 結算後點畫面重來, 回到第 1 天地下城(不再顯示說明頁), 所有數值重置

### 地下城(即時)
5. 玩家角色每幀朝游標位置移動, 最高速度見數值表; 角色活動範圍限在地下城下半部(見版面)
6. 角色自動朝正上方連續射擊; 子彈命中第一隻碰到的魔物, 造成等於攻擊力的傷害
7. 魔物在上半部左右來回飄移, 碰到邊界反彈; 依種類定時發射彈幕(見數值表)
8. 開場同時有 2 隻魔物; 場上魔物少於 3 隻時, 2 秒後在上半部隨機位置補 1 隻, 種類隨機(4 種之一)
9. 魔物血量 ×(1 + 0.5×(天數 − 1)) 四捨五入
10. 魔物血量降到最大值的 30% 以下(含)時變為「虛弱」: 停止發射彈幕、停止左右飄移, 改以固定速度往上逃; 逃到地下城上緣即消失(沒抓到)
11. 虛弱的魔物仍會被子彈打到; 血量歸零即打倒, 消失並得金幣
12. 點滑鼠: 從角色位置往正上方丟出一顆捕獲球(球數 > 0 才丟得出, 每丟一顆 −1)
13. 捕獲球碰到第一隻魔物時: 若是虛弱魔物 → 捕獲成功, 魔物離場加入表演場名單; 若不是虛弱魔物 → 球碎掉, 魔物不受影響; 飛出上緣沒碰到 → 球消失
14. 表演場名單已滿(上限見數值表)時, 點滑鼠不丟球, HUD 訊息顯示「表演場滿了」
15. 角色被彈幕打中: 扣 1 顆心, 之後無敵 1 秒(閃爍); 敵彈打中後消失
16. 心歸零或 45 秒到: 地下城結束, 進表演場; 已捕獲的魔物保留
17. 每天出發時心補滿、捕獲球補到上限

### 表演場(即時)
18. 表演場是一塊長方形場地, 上下兩側是觀眾席, 每側一排圍欄與 6 名觀眾
19. 名單上的所有魔物都在場內, 開演時隨機分散站位, 各自以低速隨機走動(碰到場地邊界轉向); 怒氣全部設為 20
20. 馴獸師每幀朝游標位置移動(活動範圍限場地內), 最高速度同地下城
21. 點滑鼠: 在游標位置揮鞭, 半徑內所有在場魔物(不含失控中)怒氣 +25(上限 100); 揮鞭有冷卻時間
22. 怒氣每秒自然下降(見數值表), 最低 0
23. 怒氣 < 50: 不表演
24. 怒氣 ≥ 50: 定時表演, 間隔依怒氣從 3 秒(怒氣 50)線性縮短到 1 秒(怒氣 99); 每次表演得金幣 = 種類金幣 ×(1 + 名聲/100) 四捨五入, 名聲 + 種類名聲
25. 每次表演同時在場上放出該種類的技能危險區(見下表); 危險區碰到馴獸師 → 馴獸師暈眩
   | 種類 | 技能 | 危險區 |
   |---|---|---|
   | 火蜥蜴 | 火圈 | 以魔物為中心半徑 120 的圓, 預警 0.4 秒後生效 0.6 秒 |
   | 水母 | 水彈 | 朝馴獸師當下位置射出 3 發扇形水彈(夾角 20°) |
   | 雷鳥 | 落雷 | 在馴獸師當下位置標出半徑 70 的圓, 0.8 秒後落雷(瞬間判定) |
   | 石像鬼 | 震波 | 以魔物為中心的圓環, 1 秒內半徑 0→220, 環寬 30 |
26. 暈眩: 1.5 秒內不能揮鞭、名聲 −2, 結束後無敵 2 秒(無敵期間不會再暈)
27. 怒氣達 100: 魔物失控 — 以較快速度衝向離牠最近那側觀眾席的圍欄, 撞 1.5 秒後圍欄破掉, 魔物進到觀眾席, 每 1.5 秒攻擊一次: 名聲 −3, 被攻擊的觀眾嚇跑, 4 秒後在原座位補回
28. 失控魔物不表演、不受揮鞭影響
29. 制伏: 馴獸師中心與失控魔物中心距離 < 60, 連續維持 1.5 秒 → 制伏成功, 魔物回到場地中央、怒氣 30, 該段圍欄修好; 中途離開或暈眩, 進度歸零
30. 有魔物失控時, HUD 訊息顯示「游標停在牠身上制伏」, 並顯示制伏進度
31. 50 秒到: 仍失控的魔物每隻名聲 −5, 自動回到場內; 圍欄全部修好
32. 名聲最低 0; 金幣四捨五入取整
33. 魔物跨天保留在名單上, 每天開演怒氣重設為 20

### 商店
34. 列 4 項強化, 點項目即購買(金幣不足不能按), 每項可重複買, 每買一次價格 ×1.5 四捨五入
35. 點「出發」按鈕進入下一天

### 結算
36. 顯示總名聲、累計賺得金幣、評價星數(門檻見數值表)
37. 點畫面重來

## 操作
只用滑鼠。
| 玩家動作 | 操作 |
|---|---|
| 說明翻頁 / 開始 / 標題卡開始 | 點畫面任意處 |
| 移動角色 / 馴獸師 | 移動游標 |
| 射擊 | 自動 |
| 丟捕獲球 | 地下城中點滑鼠 |
| 揮鞭 | 表演場中點滑鼠 |
| 制伏失控魔物 | 把游標停在失控魔物身上 |
| 購買強化 | 點商店項目 |
| 前往下一天 | 點「出發」按鈕 |
| 重來 | 結算畫面點任意處 |

## 勝負與結束
- 沒有失敗結局; 第 3 天表演結束後進入結算, 以總名聲換評價星數
- 結算畫面點任意處重來, 從第 1 天地下城開始

## 範圍邊界
- 只做一關(3 天), 不做難度曲線、存檔、音效
- 不做籠子、擺放位置; 名單上的魔物全部上場
- 不做魔物升級、出售、名單調整
- 不做 Boss、地下城地圖與房間
- 不做觀眾人數與門票, 收益只來自表演

# 玩法驗證文件

## 核心玩法(使用者指定, 每款都必須有)
- 遊戲名稱: 來動物園看一點大場面
- 玩家攻略地下城, 與魔物戰鬥, 並使用道具捕獲魔物
- 捕獲的魔物放進動物園; 不同種類魔物有各自的技能
- 魔物使用技能「表演」給遊客看, 提高動物園名聲, 獲得收益
- 魔物要持續表演, 前提是怒氣值高
- 怒氣過高魔物會失控: 破壞牢籠, 甚至攻擊遊客; 玩家要在不失控的前提下最大化收益
- 收益用來強化角色與裝備, 挑戰更強的怪物與地下城, 捕獲更強的魔物
- 主循環: 地下城探索 → 捕獲魔物 → 動物園經營 → 收益 → 解鎖新要素或提升能力 → 地下城探索
- deepen-1 檢討後追加指定(下一輪起每款都必須有):
  - 操作只用方向鍵 + Z、X; Z、X 在戰鬥中給武器用, 捕捉不用 Z、X 觸發
  - 商店可買武器, 翻滾 / 彈反改成武器專屬技能: 棍棒(預設, 範圍短, Z 普攻、X 無反應)、劍(範圍短, Z 普攻並可把投射物打回去傷怪, 範圍攻擊打不回; X 擊暈魔物一小段時間)、長槍(範圍長, Z 普攻, X 往前衝刺、穿過的敵人受傷)、長鞭(範圍攻擊, Z 普攻, X 朝前方扇形大力甩鞭把怪打飛)
  - 捕捉: 踩在魔物身上提示「準備捕捉」並跑一小段圓圈進度條, 跑完才進入套索繞圈捕捉; 被捕捉中的魔物暈眩、不能攻擊; 玩家可選擇打死或捕捉
  - 失控標記: 怒氣滿時出現失控標記, 之後每次再被觸發升怒標記 +1, 滿 5 個才失控; 標記定時遞減, 減到 0 後滿的怒氣條緩慢縮短。怒氣條保留紅區加乘, 不做大招
  - 表演中玩家不上場; 表演前加「布置階段」: 選要上場的魔物、購買並布置機關(激怒、冷靜、吸引到某區域等), 機關是玩家唯一的干涉手段, 表演中不能干涉
  - 3 座地下城, 各有不同魔物; 一開始只開放 1 座, 用金幣 + 捕捉指定魔物達一定數量解鎖其他座
  - 天數 7 天

## 已確認的體驗
### 想要
- 同一輪的三款, **地下城戰鬥的形式彼此不同**, **動物園經營的形式也彼此不同**(explore-1 原話:「我希望三款能作出不一樣的地下城戰鬥以及不一樣的動物園經營」)
- 地下城是**即時戰鬥**, 有靠走位躲攻擊的操作空間; 不一定要彈幕(explore-2 原話:「地下城戰鬥我更喜歡即時性的戰鬥體驗,a款彈幕遊戲蠻即時的但我覺得不一定要彈幕」)
- 地下城是**一張能直接在上面移動的地圖**(explore-2 原話:「像c款那樣有一個地圖可以直接在上面移動我覺得很棒」)
- 魔物在地下城的攻擊方式與在表演場的表演一致, 抓怪時就能預想牠上場的樣子, 有策略地挑想要的魔物(explore-2 原話:「這種一致性可以讓我預期怪物在表演時會是什麼樣子,在戰鬥時我就可以更有策略性的去捕捉我想要的怪物」)
- 能**控制場面**、精準決定哪些魔物表演; 捕捉與表演串起短期與長期策略(explore-2 原話:「揮鞭因為有範圍所以我可以精準控制哪些怪物要表演,兼顧短期與長期策略性」)。deepen-1 起改成**表演前布置機關**來控制, 玩家不下場(deepen-1 原話:「玩家能夠對場上產生干涉的手段只有布置機關, 表演過程中無法干涉表演」)
- 「排節目」式的經營概念, 前提是做出策略深度(explore-2 原話:「B款排節目這個概念我喜歡,如果做得好的話也是蠻有策略深度的」); 經營形式上 A(下場揮鞭)與 B(排節目)都喜歡。explore-4 的 B 款「選台座點名表演」則不那麼喜歡, 輸給 A 款的即時場面(見下條)
- 每種魔物要有明顯的差異性(explore-2: B、C 的缺點都點名「沒有做出各怪物的差異性」)
- 每次捕捉都有價值, 就算這隻不打算放上場(explore-2 原話:「如果每次捕捉時就算我預期他沒有要放在場上,也還是會有一定的價值,才會讓我覺得捕捉這個玩法更有意思」)
  - deepen-1: 同種再收服讓紅線區變寬(馴熟度)、同種收服給馴獸師加成, 兩者都要沿用(原話:「我覺得A跟B都不錯, 兩者都能沿用」); 而且想讓魔物的價值「更進階一點」: 不同地下城有不同魔物, 捕捉指定魔物達幾隻是解鎖新地下城的條件
- 表演場上魔物互相影響的連鎖反應, 而且是**即時發生**的連鎖, 勝過排好後自動演出的連鎖(explore-3 原話:「a款表演場上當怪物攻擊到怪物會產生連鎖反應這點我覺得很驚喜,感覺可以玩出很多花樣」「同樣是怪物間的連鎖我更喜歡a款那種即時一點的」)
  - deepen-1: 玩家的心思要放在「如何讓場上的怪物產生連鎖反應」, 連鎖本身就是目標, 回饋只是附帶(原話:「我希望玩家更放心思在"如何讓場上的怪物產生連鎖反應",連擊是達成這件事情的回饋」)
- 捕捉要**透過某種操作**完成、有一點技術門檻但不要太難, 不要直接丟道具就抓到; 想加上殘血才更容易抓 / 一定要殘血才能抓, 讓捕捉同時要技術與抓時機(explore-3 原話:「"捕捉"這件事情可以做出一點技術門檻,不用太難,比起直接丟一個道具捕捉,我更喜歡透過某種操作後捕捉,且我覺得可以加上殘血更容易捕捉或是一定要殘血才能捕捉的機制」)
  - explore-4 補充: 殘血後只按準一個時機(A 款捕捉圈亮綠揮鞭)技術門檻不夠(原話:「可惜的是a款沒有做出殘血時要做某種比較有技術門檻的操作才能捕捉怪的設計」)
  - deepen-1: 套索繞圈捕捉這個方式喜歡(原話:「這個捕捉方式我喜歡」); 打死或捕捉要由玩家選擇, 捕捉由玩家主動發起(原話:「應該改成玩家有選擇空間」)
- 用**鍵盤**操作(explore-3 原話:「我比較喜歡用鍵盤操作的感覺」); deepen-1 起全遊戲只用方向鍵 + Z、X 兩鍵(原話:「除了上下左右方向鍵以外,控制在2個鍵就能做全部的事情,就是z跟x」)
- 魔物各有移動習性的設計(deepen-1 原話:「魔物習性的設計也不錯」); 玩家不在場上後, 習性要怎麼在表演場發揮還要重新想
- 失控要有一點門檻, 不要太容易失控; 紅區加乘保留(deepen-1 原話:「這個設計讓失控多一點門檻, 因為我覺得現在太容易失控了」「紅區有特別加乘這件事情可以保留」)
- 一局的規模要玩得完: 3 天太短, 改 7 天(deepen-1 原話:「現在規模如果只有3天好像玩不完」)
- A 款的地下城戰鬥節奏: 鍵盤走位 + 揮鞭 + 翻滾(explore-4 原話:「我比較喜歡a款的戰鬥節奏」)
- 表演場有**激怒與安撫兩種**控制場面的手段(explore-4 原話:「揮鞭激怒跟吹哨安撫我覺得都不錯,都是玩家控制場面的一種手段」); deepen-1 起改由布置階段的激怒 / 冷靜機關提供
- 怒氣在失控邊緣有額外收益, 讓人想把場面控制在「失控邊緣」, 控制得好一直跳加倍很爽快(explore-4 原話:「這讓我會一直想設法去控制場面在"失控邊緣",如果控制的好,一直跳出加倍會很爽快」)
- 表演場上魔物**即時在場上活動**、場面隨時可能失控的刺激感(explore-4 原話, 說明為何不那麼喜歡 B 款:「沒有那種怪物即時在場面上活動,場面隨時要失控的刺激感」)
- 彈反的手感, 但要當成戰鬥或表演中**迴避攻擊**的手段, 不當捕捉手段(explore-4 原話:「我喜歡彈反的感覺,但用來抓怪我覺得不搭,彈反可以設計成是戰鬥或表演過程中的一環,讓玩家有迴避攻擊的手段」); deepen-1 起翻滾 / 彈反改成武器專屬技能(劍把投射物打回去)
### 不要
- 三款玩起來很像、只差一個特色機制(explore-1 原話:「我看三款遊戲都很像」)
- 玩家動一步、魔物動一步的回合制戰鬥: 沒有靠走位躲攻擊的操作空間(explore-2 原話)
- 自動戰鬥搭配控血捕獲: 想把怪打殘血來抓, 自動戰鬥讓它不可控(explore-2 原話:「加入自動戰鬥就多了很多不可控性,這個體驗我覺得不好」)
- 間接微調怒氣條的經營(explore-2 原話:「這種微調怒氣條的玩法第一我覺得不好玩,第二是完全沒有辦法做出怪物的差異性」)
- 地下城只是一個單純戰鬥場地, 沒有地下城的感覺, 換地城體驗也差不多(explore-2 原話)
- 玩法單調、一看就知道最佳解(explore-2 原話:「目前版本玩法太單調,一看就知道該怎麼排」)
- 抓很多、場上只放少數幾隻, 溢出的魔物沒有價值(explore-2 原話)
- 滑鼠操作: 卡、不好操作(explore-3 原話:「所有用滑鼠操作的體驗我都不喜歡,操作起來很卡很不好操作」)
- 捕捉成功與自己的操作無關, 只是在等(explore-3 原話:「躲在角落等到怪暈再過去就好了,等待的時間就是在發呆,完全沒有"因為我做了什麼而成功捕捉"的成就感和投入感」)
- 無法控制魔物的怒氣, 失控是必然(explore-3 原話:「我無法控制怪不生氣,怒氣一定會滿=一定會脫隊,我不喜歡這種無法控制怪物怒氣值的感覺」)
- 補救失控的代價太低, 重複同一個動作就能無腦應付(explore-3 原話:「我可以一直在遊客前原地繞圈就好,一生氣就圈回來,這樣操作很無腦」)
- 彈反拿來抓怪(explore-4 原話:「用來抓怪我覺得不搭」)
- 要一直把魔物趕到某個區域才能表演 / 冷靜, 只顧得了一隻, 讓人不想抓更多(explore-4 原話:「要控制怪只能在某個區域這件事情需要玩家一直不斷去把怪趕去某個地方,基本上只能看好一隻怪,要兼顧到兩隻就已經很困難了,這會讓我不想去抓更多怪」)
- 表演中玩家下場: 魔物一多就一直被打(還有範圍攻擊), 只能無力地掉名聲、完全控制不了場面(deepen-1 原話:「當場上的怪物一多,基本上就是一直被怪打,有些怪的攻擊還是範圍的,就只能無力的一直降名聲,反而完全沒辦法控制場面」)
- 捕捉過程太容易被中斷: 被捕捉的魔物還能攻擊、其他魔物也會干擾(deepen-1 原話:「在怪物被捕捉的過程中應該要是暈眩狀態,不能發起攻擊,不然太容易被中斷了」)
- 攻擊鍵就是捕捉、玩家不能選擇把魔物打死(deepen-1 原話:「玩家按攻擊鍵是捕捉,也就是玩家不能選擇把牠打死」)
- 太容易失控(deepen-1 原話:「我覺得現在太容易失控了」)
- 大招機制(deepen-1 原話:「我覺得不需要放大招的機制」)
- 把注意力拉去「別讓連擊斷」的全場回饋: 擔心畫面太混亂、玩家患得患失(deepen-1 原話:「我怕畫面太混亂, 或是玩家會容易患得患失, 可以先拿掉試試看」; 是使用者的顧慮, 非實際體驗)

## 機制清單
### 保留
- 動物園沒有籠子, 魔物在表演場自由走動(H21 的場地部分; 馴獸師下場已推翻, 見修訂紀錄)
- 魔物在地下城的攻擊模式與表演技能對應一致(H36)
- 地下城即時戰鬥、可靠走位閃躲(H37)
- 地下城是能自由移動的地圖(H38)
- 表演技能打中其他魔物會改變牠的怒氣, 點火 / 澆熄造成連鎖(H49)
- 連鎖在表演場上即時發生, 而非固定站位排好後自動接力(H67); deepen-1 起引發連鎖的手段從玩家當下操作改為布置階段的機關
- 操作型捕捉: 繞一圈圍住魔物來削體力與收服(H60); 殘血後套索繞一圈收服(H99)
- 地下城鍵盤動作戰鬥: 8 向走位、朝面向攻擊(H72); deepen-1 起攻擊範圍與技能由武器決定
- 激怒 + 安撫雙向控制怒氣(H75); deepen-1 起由布置階段的機關提供
- 怒氣越高收益越高、滿了失控, 紅線區金幣加倍, 讓玩家貼著失控邊緣拿捏(H02、H03、H76); deepen-1 起失控改由失控標記累積到 5 才發生(回應 H112)
- 彈反的手感(H79); deepen-1 起改成劍的技能: 揮到投射物把它打回去
- 同種再收服提高馴熟度、紅線區變寬(H104)
- 同種再收服給馴獸師該種的收服加成(H107)
- 各種魔物有自己的移動習性, 地下城與表演場一致(H109)
### 避開
- explore-1 共用的那套形式, 下一輪不再沿用(使用者明確要求, 非試玩後的體驗判定):
  - 地下城: 回合制點擊攻擊 + 丟網捕獲
  - 動物園: 籠子格狀擺放 + 點籠子扣怒氣條安撫
- 地下城只是一塊無地形、無特色的戰鬥場地(H39)
- 自動戰鬥搭配看剩餘血量的捕獲(H40)
- 玩家一步、魔物一步的網格回合制(H41)
- 動物園只靠間接手段(閘門調人潮)微調怒氣, 怒氣只由單一共通因素驅動(H42)
- 規則簡單、最佳解一眼可見的排程(H43)
- 魔物只有「上場表演」一種用途(H44)
- 滑鼠操作: 角色跟著游標走、點擊甩鞭、隊伍朝游標轉向(H68)
- 捕捉靠等魔物自己累倒, 最佳策略是躲角落等(H69)
- 怒氣只往上漲、玩家沒有有效的降怒手段, 失控必然發生(H70)
- 失控的補救代價太低, 原地重複同一動作就能應付(H71)
- 捕捉只靠殘血後按準單一時機(H95)
- 彈反當捕捉手段(H96)
- 表演場魔物固定站位、總機式點名表演(H97)
- 表演 / 降怒都要把魔物趕進特定區域, 管理負擔隨魔物數上升(H98)
- 套索繞圈時被套的魔物照樣出招、其他魔物也會干擾(H100)
- 表演中馴獸師下場, 魔物多時一直被(範圍)技能打中(H111)
- 怒氣一滿就立刻失控(H112)
- 殘血魔物被攻擊鍵打到就自動進入捕捉, 玩家無法選擇打死(H113)

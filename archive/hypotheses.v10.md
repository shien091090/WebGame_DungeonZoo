# 玩法驗證文件

## 核心玩法(使用者指定, 每款都必須有)
- 遊戲名稱: 來動物園看一點大場面
- 玩家攻略地下城, 與魔物戰鬥, 並使用道具捕獲魔物
- 捕獲的魔物放進動物園; 不同種類魔物有各自的技能
- 魔物使用技能「表演」給遊客看, 提高動物園名聲, 獲得收益
- 魔物要持續表演, 前提是怒氣值高
- 怒氣過高魔物會失控: 破壞牢籠, 甚至攻擊遊客; 玩家要在不失控的前提下最大化收益
- 收益用來強化角色與裝備, 挑戰更強的怪物與地下城, 捕獲更強的魔物
- 主循環: 地下城探索 → 捕獲魔物 → 動物園經營 → 收益 → 解鎖新要素或提升能力 → 地下城探索
- deepen-1 檢討後追加指定(下一輪起每款都必須有):
  - 操作只用方向鍵 + Z、X; Z、X 在戰鬥中給武器用, 捕捉不用 Z、X 觸發
  - 商店可買武器, 翻滾 / 彈反改成武器專屬技能: 棍棒(預設, 範圍短, Z 普攻、X 無反應)、劍(範圍短, Z 普攻並可把投射物打回去傷怪, 範圍攻擊打不回; X 擊暈魔物一小段時間)、長槍(範圍長, Z 普攻, X 往前衝刺、穿過的敵人受傷)、長鞭(範圍攻擊, Z 普攻, X 朝前方扇形大力甩鞭把怪打飛)
  - 捕捉: 踩在魔物身上提示「準備捕捉」並跑一小段圓圈進度條, 跑完才進入套索繞圈捕捉; 被捕捉中的魔物暈眩、不能攻擊; 玩家可選擇打死或捕捉
  - 失控標記: 怒氣滿時出現失控標記, 之後每次再被觸發升怒標記 +1, 滿 5 個才失控; 標記定時遞減, 減到 0 後滿的怒氣條緩慢縮短。怒氣條保留紅區加乘, 不做大招
  - 表演中玩家不上場; 表演前加「布置階段」: 選要上場的魔物、購買並布置機關(激怒、冷靜、吸引到某區域等), 機關是玩家唯一的干涉手段, 表演中不能干涉
  - 3 座地下城, 各有不同魔物; 一開始只開放 1 座, 用金幣 + 捕捉指定魔物達一定數量解鎖其他座
  - 天數 7 天
- deepen-2 檢討後追加指定(上面 deepen-1 的指定照舊保留):
  - 「布置機關」三款用不同形式: 機關種類、觸發方式、作用對象都不同, 不共用戰鼓 / 噴泉 / 肉塊這組基礎機關
  - 魔物在表演場要主動走動、彼此相遇, 隨手擺也會自然產生連鎖與收益, 不能只有精準擺位才有事發生
- deepen-3 檢討後追加指定(上面的指定照舊保留):
  - 目標體驗改寫: 玩家不上場, 但要能**在表演過程中透過某種間接方式控場**(選時機讓魔物生氣或冷靜、能微調)。這取代 deepen-1「機關是唯一干涉手段」的寫法: 布置階段照舊有, 但布置的東西必須在表演進行中持續起作用, 不能是放了就固定、沒被觸發就沒事的設施
  - 三款用**三種不同的間接控場方式**; 節目表(B 款)是其中一種可行解, 不必三款都是
  - 改成橫向寬畫面
  - 三款的魔物陣容與魔物設計各自不同, 不再沿用水母 / 火蜥蜴 / 雷鳥 / 刺蝟 / 石像鬼 / 幽靈這組
  - 初期地下城戰鬥降低難度
- deepen-4 檢討後追加指定(上面的指定照舊保留, 衝突處以這裡為準):
  - 控場 = **節目表 + 掛牌結合**, 每款都要有; 掛牌改成**以全場怪物為對象**, 不再一隻一隻掛。這取代 deepen-3「三款三種不同控場方式」的寫法
  - 抓到的魔物**不自動升級**, 直接放進**怪物庫**(無上限); 表演場**上場上限 20 隻**。取代 deepen-1 起的「同種收服提高等級(馴熟度 / 馴獸師加成)」
  - 魔物升級改成**花金幣**, 升級面板寫明每次升級的變化; 表演前的選魔物階段與商店兩處都能升級
  - 放置魔物時標示牠的攻擊效果: 激怒、冷靜, 或其他特殊效果(例: 黑洞吸引、擊退, 可再發想)
  - 魔物攻擊**一律遠距離**, 場面做成像彈幕遊戲, 但不限彈幕(隨機召喚的隕石、指向性射線等, 可再發想)
  - 表演場**取消習性, 一律隨機亂走**; 各種的移動頻率、速度、模式(亂跳、瞬移等, 可再發想)不同; 讓魔物靠近或遠離其他魔物改由節目表或掛牌控制。取代 deepen-2「表演場主動走動、彼此相遇」裡「以其他魔物為對象」的做法
  - 天數 **5 天**(取代 7 天)
  - 商店分頁, 至少「角色 / 表演 / 怪物」3 頁
  - 地下城解鎖條件改成**名聲 + 捕捉指定魔物**(取代金幣 + 收服數)
  - 地下城地圖加大、多一點探索感, 地圖上放玩家可互動的物件(三款各自發想不同物件; 不放寶箱)
- deepen-5 檢討後追加指定(打磨底版 = deepen-5 B 款暗號節目單; 上面的指定照舊保留, 衝突處以這裡為準):
  - 控場 = **暗號節目單**(全場暗號牌 + 節目, 達成暗號才演、依序推進); 不做按鍵換段, 不做伸縮擂台
  - 怪物庫**每隻獨立顯示、個別升級**(取代 deepen-5 的「同種共用等級」); 同種上場**不設上限**, 總上限仍 20
  - **每日選場所**: 每天開始選地下城 / 表演 / 商店; 地下城或表演結束就過一天, 都不接商店; 商店購買不推進時間。仍 5 天(= 5 次地下城或表演行動)
  - 每天開始播**日曆過場動畫**, 顯示第幾天 / 共幾天
  - 收益改成**名聲換算**: 表演中只累積名聲, 結算時依本場提升的名聲用公式換成金幣, 收入不可極端太少或暴增(公式由設計決定)
  - **失控重罰**: 任一隻失控 → 全場觀眾逃走、表演立刻結束, 以失控前累積的名聲結算
  - **第 0 天教學**: 教學地下城(之後不可選, 很簡單、沒有互動物件)引導捕捉 2 隻同種、激怒屬性的魔物; 接著表演教學, 只有 2 種暗號 + 2 種節目可選、暗號條件簡單到一定接得下去, 教玩家設定暗號與節目、開演、看兩隻互打 → 觸發暗號 → 觸發節目。其他暗號與節目要之後解鎖(方式由設計決定)
  - 地下城互動物件: 爆炸桶、回復泉、傳送陣、裂牆、草叢、果樹全保留, 分散在 3 座地下城

## 已確認的體驗
### 想要
- 同一輪的三款, **地下城戰鬥的形式彼此不同**, **動物園經營的形式也彼此不同**(explore-1 原話:「我希望三款能作出不一樣的地下城戰鬥以及不一樣的動物園經營」)
- 地下城是**即時戰鬥**, 有靠走位躲攻擊的操作空間; 不一定要彈幕(explore-2 原話:「地下城戰鬥我更喜歡即時性的戰鬥體驗,a款彈幕遊戲蠻即時的但我覺得不一定要彈幕」)
- 地下城是**一張能直接在上面移動的地圖**(explore-2 原話:「像c款那樣有一個地圖可以直接在上面移動我覺得很棒」)
- 魔物在地下城的攻擊方式與在表演場的表演一致, 抓怪時就能預想牠上場的樣子, 有策略地挑想要的魔物(explore-2 原話:「這種一致性可以讓我預期怪物在表演時會是什麼樣子,在戰鬥時我就可以更有策略性的去捕捉我想要的怪物」)
- 能**控制場面**、精準決定哪些魔物表演; 捕捉與表演串起短期與長期策略(explore-2 原話:「揮鞭因為有範圍所以我可以精準控制哪些怪物要表演,兼顧短期與長期策略性」)。deepen-1 起改成**表演前布置機關**來控制, 玩家不下場(deepen-1 原話:「玩家能夠對場上產生干涉的手段只有布置機關, 表演過程中無法干涉表演」); deepen-3 起再修正: 玩家仍不上場, 但要有在表演過程中間接控場的方式(見下方)
- 「排節目」式的經營概念, 前提是做出策略深度(explore-2 原話:「B款排節目這個概念我喜歡,如果做得好的話也是蠻有策略深度的」); 經營形式上 A(下場揮鞭)與 B(排節目)都喜歡。explore-4 的 B 款「選台座點名表演」則不那麼喜歡, 輸給 A 款的即時場面(見下條)
- 每種魔物要有明顯的差異性(explore-2: B、C 的缺點都點名「沒有做出各怪物的差異性」)
- 每次捕捉都有價值, 就算這隻不打算放上場(explore-2 原話:「如果每次捕捉時就算我預期他沒有要放在場上,也還是會有一定的價值,才會讓我覺得捕捉這個玩法更有意思」)
  - deepen-1: 同種再收服讓紅線區變寬(馴熟度)、同種收服給馴獸師加成, 兩者都要沿用(原話:「我覺得A跟B都不錯, 兩者都能沿用」); 而且想讓魔物的價值「更進階一點」: 不同地下城有不同魔物, 捕捉指定魔物達幾隻是解鎖新地下城的條件
  - deepen-4: 不要自動升級, 抓到的魔物進怪物庫(無上限)、上場上限 20, 升級改成自己花金幣、面板寫明升級變化, 選魔物階段與商店都能升級(原話:「玩家抓到的怪不會自動升級, 而是改成直接放進怪物庫, 怪物庫無上限, 而放在表演場上的怪物上限可以提高到20」「怪物升級改成需要花費金幣, 每次升級會有什麼改變要寫在升級面板上」)
